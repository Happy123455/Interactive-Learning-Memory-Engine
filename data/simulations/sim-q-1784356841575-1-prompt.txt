Act as an expert educational software developer. Your task is to build a high-fidelity, interactive HTML/JS/CSS simulation for the Engineering Hydrology concept: "Infiltration Capacity and Runoff Generation." 

### 1. Visual Simulation Strategy
- **Canvas Environment:** Create a 2D side-view cross-section of a soil profile (Surface level vs. Subsurface layers).
- **Rain Cloud:** A floating, animated cloud at the top that releases particles representing raindrops.
- **Infiltration Dynamics:** Use a particle system (small blue circles) to show water moving downward into the soil (infiltration) or pooling on the surface (runoff).
- **Horton’s Curve Overlay:** Display a real-time, side-by-side SVG line chart showing the Infiltration Capacity curve ($f_t$ vs time). As the simulation runs, a moving dot should track the current state on the graph.

### 2. Interactive Controls & UI
- **Dashboard:** Create a glassmorphic floating control panel with:
    - **Sliders:** 
        - Rainfall Intensity ($i$): 0–20 mm/hr.
        - Infiltration Capacity ($f$): 0–15 mm/hr.
        - Soil Saturation State: (Dry to Saturated).
    - **Toggle:** "Visual Debug Mode" to toggle the display of vector arrows representing flow velocity.
- **Dynamic Feedback:** As sliders move, the rain particle density must update, and the "Runoff" layer (blue water sheet on the surface) must expand if $i > f$.
- **Real-time Equations:** Display the logic $f_a = i$ (if $i < f$) or $f_a = f$ (if $i > f$) in a glowing, updating text box using LaTeX-style rendering.

### 3. Sound Design (Web Audio API)
- Implement a `SoundEngine` class using native `WebAudio API` (Oscillators/GainNodes).
- **Rain Sound:** Use white noise with a randomized band-pass filter that changes intensity based on the $i$ slider.
- **Runoff Sound:** A low-frequency hum (sine wave + sub-oscillator) that increases in volume/frequency as surface runoff depth increases.
- **Feedback Chime:** A harmonic ping when the state transitions from "Infiltration only" to "Runoff occurring."

### 4. Narrative Text-to-Speech (TTS)
- Include a "Narrate Concept" button.
- Use `window.speechSynthesis` to trigger an educational script:
    - *Initial:* "Infiltration is the process where water enters the soil. When rainfall intensity is less than infiltration capacity, all water is absorbed."
    - *Transition:* "When intensity exceeds capacity, the soil is saturated, and surface runoff begins."
- Implement a queue system so narration doesn't overlap; highlight the UI element being discussed during speech.

### 5. Diagram Animations & Aesthetics
- **Theme:** Dark mode aesthetic (Midnight Navy `#0a0b1e`), neon cyan accents for water, and soft white for data text.
- **Animations:** 
    - Use `requestAnimationFrame` for smooth 60FPS fluid particles.
    - Animate arrows representing water flux: magnitude should be tied to the current infiltration rate.
    - Ensure all CSS transitions use `cubic-bezier(0.4, 0, 0.2, 1)` for a premium, buttery-smooth feel.

### 6. Technical Requirements
- **Single-file Architecture:** Provide a single HTML file containing all HTML, CSS (in `<style>`), and JS (in `<script>`).
- **Responsive:** The canvas must be responsive to window resize.
- **Documentation:** Include brief, well-commented code sections explaining the relationship between the math (e.g., $f_t = f_c + (f_0 - f_c) \cdot e^{-kt}$) and the visual state. 

**Instruction:** Build this simulation to be a self-contained learning tool that proves the relationship between infiltration capacity and runoff generation, ensuring students can visually distinguish between the two states through interactive exploration.
