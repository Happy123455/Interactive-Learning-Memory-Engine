Create an interactive "Steel Connection Workshop" simulation using HTML5 Canvas, GSAP for animations, and Web Audio API. 

**Visual Theme:** Dark "Cyber-Engineering" dashboard (Glassmorphism, neon cyan/purple accents). 

**1. Simulation Environment:**
*   **The Workshop:** A center-stage 2D canvas displaying a "Tie Plate to Gusset Plate" connection. Render plates as metallic textures with glowing bolt holes.
*   **Active Interaction:** Users drag "Bolt Parameters" (M16, M20, M24) and "Load Chips" (kN values) from a side panel directly onto the structural diagram. 
*   **Live Physics:** As the user drops load chips, show a force vector arrow (animated with GSAP) lengthening. If the load exceeds capacity, the connection flashes red and emits a "stress alarm" (low-frequency pulse). 
*   **Audio/Voice:** Use `window.speechSynthesis` to narrate: "Let's connect this plate! Drag the bolt grade onto the gusset to start." Use an `OscillatorNode` to map load slider values to a rising/falling pitch synth.

**2. Gamified Pedagogy:**
*   **The ELI5 Analogy:** Use a popup overlay: "Think of this plate like a backpack strap—too few bolts and it pops off like a loose button!"
*   **Interactive IS:800 Codebook:** Include a "Clause 10.2" icon. Dragging this to the canvas "unlocks" a formula overlay where the user must drag numerical variables into slots. Correct placements trigger a "Chime" (GainNode trigger) and green glow.
*   **Dynamic Drafting:** Use sequential line drawing animations to show gauge (g) and pitch (p) dimensions as the user adjusts sliders, with clear callouts.

**3. Engineering Logic:**
*   **Visualizer:** Display a live "Capacity vs. Demand" bar chart. As parameters are adjusted, the bar animates in real-time. 
*   **Viewport:** Use Flexbox to ensure the 100vh layout is responsive. Ensure the canvas remains sharp with `devicePixelRatio` scaling. 

**4. Constraints:** No static text blocks. All text must be in floating, interactive tooltips or HUD panels. Use `requestAnimationFrame` for smooth 60fps interaction.
