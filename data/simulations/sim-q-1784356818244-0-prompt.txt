Act as an expert Educational Software Developer and Prompt Engineer. Your task is to build a single-file, interactive HTML5/JS/CSS simulation that explains the concept of **Development Length (Ld)** in Reinforced Concrete (RCC) design for a college-level "Elementary Structural Design" course.

### 1. Visual Simulation Strategy
*   **Core Visualization**: Use a `<canvas>` element to render a 2D side-profile of a singly reinforced concrete beam.
*   **The Object**: Represent the beam as a rectangular block. Include a longitudinal steel bar (reinforcement) inside the bottom portion of the beam.
*   **The Physics**: As the user adjusts parameters, visually highlight the "anchorage zone." Show a "bond stress" distribution diagram (a triangular or rectangular area) overlaying the steel bar to represent how stress is transferred from steel to concrete.
*   **Math Rendering**: Use a persistent overlay (top-left) to display the dynamic formula: $L_d = \frac{0.87 \cdot f_y \cdot \phi}{4 \cdot \tau_{bd}}$. Animate the variables as they change.

### 2. Interactive Elements
*   **Drag-and-Drop**: Allow the user to drag the "Load Point" or "Support Location" along the beam length. Changing the distance to the support must dynamically update the visual length of the bar.
*   **Sliders**: Include glassmorphic input sliders for:
    *   **Bar Diameter ($\phi$)**: Resizes the visual thickness of the steel bar.
    *   **Steel Grade ($f_y$)**: Changes the glow intensity (Neon Red to Neon Blue).
    *   **Concrete Grade**: Changes the "texture" or color opacity of the concrete block.
*   **Real-time Graph**: Below the beam, plot a "Bond Stress vs. Length" graph using Chart.js or a simple Path2D canvas implementation. The area under this curve must dynamically resize as the user changes inputs.

### 3. Aesthetics & UI
*   **Theme**: Dark mode dashboard (bg: #0f172a). 
*   **Components**: Use "Glassmorphism"—translucent panels with a slight blur backdrop (`backdrop-filter: blur(10px)`), glowing borders (neon accents), and clean, sans-serif typography (Inter or Roboto).
*   **Feedback**: Highlight the "Development Length" zone in a bright, glowing neon color that grows/shrinks as the user adjusts the sliders.

### 4. Sound Design (Web Audio API)
*   **Constraint**: No external audio files. Use only the `window.AudioContext`.
*   **Interaction Sounds**:
    *   **Slider Movement**: A subtle, low-pass filtered oscillator sweep (sine wave) that changes frequency based on slider input value.
    *   **Success/Snap**: A quick "blip" (short-decay square wave) when the calculation reaches a stable, code-compliant length.
    *   **Error/Limit**: A low-frequency, slightly dissonant pulse if the user enters values that violate standard RCC code limits.

### 5. Narrative Text-to-Speech (TTS)
*   **Narration System**: Include a "Concept Narrator" button.
*   **Functionality**: When clicked, use `window.speechSynthesis` to read a curated, step-by-step explanation of the currently visible simulation state (e.g., "The bar diameter has been increased; notice how the development length extends to ensure proper bond.")
*   **Events**: Trigger brief, context-aware audio explanations (1-2 sentences) when the user modifies a critical parameter.

### 6. Technical Requirements
*   **Structure**: Single HTML file containing all CSS in `<style>` tags and JS in `<script>` tags.
*   **Responsiveness**: Ensure the canvas scales to fit the container window.
*   **Animation**: All movements (bar resizing, stress diagram growth) must use `requestAnimationFrame` for fluid, 60fps transitions.

### 7. Implementation Steps for the Code Generator
1.  **Initialize**: Set up a clean layout with a sidebar for controls and a main area for the simulation canvas.
2.  **Logic**: Implement the $L_d$ calculation engine based on IS 456 (or general RCC standards).
3.  **Draw Loop**: Create a function to clear and redraw the canvas on every state change.
4.  **Audio**: Create a helper function `playTone(frequency, type, duration)` to encapsulate the Web Audio API calls.
5.  **TTS**: Implement a queue-based `speak()` function to prevent overlapping speech synthesis.
6.  **Polish**: Add neon box-shadows, subtle grid-line backgrounds, and smooth hover-state transitions for all UI elements.

**Your Goal**: Produce a professional-grade educational tool that makes the abstract concept of Development Length intuitive and visually compelling.
