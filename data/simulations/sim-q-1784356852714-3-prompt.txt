Act as an expert educational software developer. Build a high-fidelity, interactive, web-based simulation for a Transportation Engineering module focusing on the "Calculation of Vertical Summit Curve Length."

### 1. Core Simulation Logic
- **Objective:** Calculate the length of a vertical summit curve ($L$) where $L > SSD$.
- **Formulas:**
  - $N = n_1 - n_2$ (Algebraic difference of grades).
  - $L = \frac{N \cdot S^2}{2 \cdot (\sqrt{2h_1} + \sqrt{2h_2})^2}$ for $L > SSD$.
  - Use IRC standard assumptions: $h_1 = 1.2m$ (Driver eye height), $h_2 = 0.15m$ (Object height).
  - SSD Calculation: $SSD = (0.278 \cdot V \cdot t) + \frac{V^2}{254 \cdot (f \pm 0.01n)}$.
- **State Management:** Create a reactive JavaScript state object that updates $L$ instantly when any parameter ($V, n_1, n_2, f$) changes.

### 2. Visual Simulation Strategy
- **Dashboard Layout:** A dark-themed, glassmorphic layout.
- **Top Canvas (Canvas API):** Render a 2D side-profile view of a road showing the summit curve. Use `requestAnimationFrame` to animate a vehicle (a glowing SVG-path car) moving along the parabolic path.
- **Dynamic Overlays:** Draw the vertical sight-line vector between the driver's eye and the object. As the user changes parameters, the parabola arc must physically redraw to show the change in curvature.
- **Real-Time Plotting:** Include a secondary small canvas acting as a chart, plotting the parabolic path $y = ax^2 + bx + c$.

### 3. Interactive Elements
- **Control Panel:** Use sliders for:
  - `Speed (V)`: 60-120 Kmph.
  - `Gradient n1`: +1% to +10%.
  - `Gradient n2`: -1% to -10%.
- **Drag-and-Drop:** Allow users to drag "control handles" on the curve itself to visually adjust the slopes $n_1$ and $n_2$, which update the input sliders in real-time.
- **Dynamic Equation Display:** Use LaTeX-style rendering (via HTML spans) to show the current calculation $L = \dots$ with the actual numeric values substituted, changing color to highlight the result.

### 4. Audio & Narrative (Web APIs)
- **Speech Synthesis:** Implement a `window.speechSynthesis` "Narrator" button.
  - Logic: When clicked, the AI narrator explains the current state: "The algebraic difference in grades is [N] percent. Since the design speed is [V] Kmph, the required Stopping Sight Distance is [SSD] meters. Therefore, the minimum curve length is [L] meters."
- **Web Audio API:** Use the native OscillatorNode to generate:
  - **Interaction Tone:** A soft, harmonic 440Hz pulse (low gain) whenever a slider is moved or a handle is dragged.
  - **Calculation Tone:** A short, resonant 'ping' (frequency sweep 400Hz to 800Hz) when a new $L$ value is calculated, providing satisfying tactile feedback.

### 5. Aesthetics & UX
- **Design:** Modern "Cyber-Engineering" aesthetic. Dark charcoal background (#121212), translucent cards with blur effect (`backdrop-filter: blur(10px)`), and neon cyan/orange accent colors for the vectors and result numbers.
- **Typography:** Use a clean, geometric sans-serif (e.g., 'Inter' or 'Roboto').
- **Animations:** Use CSS transitions (`all 0.3s ease-out`) for all UI updates. Ensure the car moves smoothly along the curve path using coordinate mapping from the calculated parabola equation.

### 6. Implementation Steps for the Code Generator:
1. **HTML Structure:** Container div for the Canvas, sidebar for controls, and a footer for the dynamic equation readout.
2. **CSS:** Define a "glass" class for translucent panels and "neon" classes for active indicators.
3. **JS Physics Loop:** 
   - Write a function `calculateParabola()` that generates an array of points based on the current $n_1, n_2, L$.
   - Draw the road using `ctx.beginPath()` and `ctx.bezierCurveTo()`.
   - Update the vehicle position $(x, y)$ using the parabolic equation as a function of time.
4. **Integration:** Hook the sliders to the `calculateParabola` function to redraw on input change.
5. **Final Touch:** Add the `speechSynthesis` trigger function to read the summary of the design parameters.
