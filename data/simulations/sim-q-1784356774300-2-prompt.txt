**SIMULATION ARCHITECTURAL BLUEPRINT: "The Steel Connection Sandbox"**

**1. Core Framework:**
Build a responsive, single-page application using HTML5 Canvas, CSS Grid/Flexbox, and GSAP for animations. Strict 100vh viewport constraint with window-resize event listeners. Aesthetic: Cyber-engineering dashboard with glassmorphism panels, dark mode, and neon cyan/magenta/green highlights.

**2. Interactive Sandbox Mechanics:**
- **The Connection Lab:** A central 2D canvas featuring a structural joint (initially an I-Beam/Gusset plate assembly).
- **Gamified Drag-and-Drop:** Create a "Component Tray" containing "Bolt Types" (Black, Turned, HSFG) and "Load Blocks." Drag these onto the joint to trigger visual structural updates.
- **Dynamic Physics Overlays:** Use SVG/Canvas paths to draw real-time force vectors (arrows) that scale with load magnitude. Implement a "Stress-Strain" pop-up graph that updates as bolts are swapped.
- **Gesture Control:** Implement mouse/pointer tracking; moving the pointer across the connection triggers a "shaking" animation and a "stress warning" sound if the bolt capacity is exceeded.

**3. Pedagogy & ELI5 Narratives:**
- **Voiceover System:** Use `window.speechSynthesis` to trigger friendly, childlike explanations (e.g., "Wow! Adding these HSFG bolts makes the connection super stiff, like a giant lego brick!") whenever a user places a component.
- **Audio Synth:** Use Web Audio API oscillators mapped to sliders. Moving the "Load" slider increases pitch frequency; changing bolt types changes the timbre (e.g., Black Bolt = low "thud," HSFG = high "chime").

**4. Engineering Visuals (IS 456/800 Logic):**
- **Blueprints:** Include a clickable "Codebook" icon (IS 800:2007) that slides out a panel showing Clause 10.2 references. 
- **Zoom Zones:** On hover, animate a 150% CSS zoom into the "Bolt Hole/Pitch" zone, displaying neon measurement leaders (Gauge/Pitch) that highlight in red if values violate code requirements.
- **Pour & Glow:** Upon placing a bolt, apply a CSS "pulse" glow animation indicating structural load distribution.
