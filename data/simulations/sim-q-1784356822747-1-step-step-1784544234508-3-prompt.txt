Act as an expert educational software developer. You are tasked with generating a high-fidelity, single-file HTML/JavaScript simulation for a university-level Structural Design course. 

### **Objective**
Create an interactive "Exam Mastery Tool" for **Step 4: Design of Longitudinal Tension Reinforcement (Ast)** of an RCC beam design problem. The simulation must provide an immersive, step-by-step learning experience that mirrors professional exam-writing methodology.

### **Technical Requirements**
1. **Tech Stack**: Use a single-file structure (HTML5, Tailwind CSS for UI, Vanilla JS for logic, Web Audio API for sound, and Web Speech API for voiceover).
2. **Responsive Design**: Clean, academic, "dark-mode" dashboard aesthetic.
3. **Accessibility**: All calculations must be readable by screen readers.

### **Core Simulation Features**
**A. Incoming Data Control (The "Data Pipeline"):**
- Create an "Input Panel" section. Pre-fill it with: `M_e1 (Equivalent Moment) = 45.47 kNm`, `b = 250mm`, `d = 450mm`, `fck = 20 N/mm²`, `fy = 415 N/mm²`.
- Allow the user to edit these values to see real-time ripple effects in the calculations.

**B. Interactive Calculation Engine:**
- Implement the formula: `Ast = (0.5 * f_ck * b * d / f_y) * [1 - sqrt(1 - (4.6 * M_e1 * 10^6) / (f_ck * b * d^2))]`.
- Include a "Bar Selector" dropdown (12mm, 16mm, 20mm, 25mm) to calculate the required number of bars.
- Include a 2D SVG canvas that visualizes the beam cross-section, showing the placement of these bars as they are selected.

**C. The "Exam Sheet" UI:**
- Provide a persistent right-hand panel titled "Exam Solution Sheet". 
- Format this panel to look like lined engineering paper. As the user moves sliders, this panel must dynamically update with formal exam notation:
  *   Step Title: "Design of Longitudinal Tension Reinforcement"
  *   Formula Statement
  *   Substitution of values with units
  *   Final Answer with proper box highlight.

**D. Narration & Audio Feedback:**
- **Web Audio Synth**: Trigger a soft "ping" sound when a valid calculation is completed and a "chime" when the final reinforcement is selected.
- **Speech Synthesis**: Add a "Hear Explanation" button that triggers the browser's TTS engine to narrate the logic: "We are calculating Ast to resist the equivalent moment. Note the importance of the square root term in limit state theory..."

**E. Output & Transfer Panel:**
- Create a prominent "Transfer Results" box.
- Display: `Final Ast = [Value] mm²` and `Reinforcement: [Count] x [Dia] mm bars`.
- Include a 'Copy for Step 5' button that displays a toast notification: "Data successfully formatted for Step 5 calculation."

### **Instructional Logic for Gemini**
1. **Initialization**: Create a responsive layout with a Sidebar (Inputs/Controls), Main View (SVG Beam/Calculation), and Exam Paper (Output Display).
2. **Interactivity**: Use `addEventListener('input')` on all sliders/inputs to trigger a `calculate()` function that refreshes both the SVG and the Exam Paper text.
3. **SVG Generation**: Use standard `<svg>` tags to draw a simple rectangular beam cross-section that updates the number of reinforcement circles dynamically based on the selected bar count.
4. **Speech**: Implement `window.speechSynthesis` to read the step-by-step logic aloud upon user request.

### **Code Generation Rules**
- Ensure all variable names are descriptive (e.g., `effDepth`, `moment_e1`, `barDiameter`).
- Use Tailwind CSS via CDN for styling.
- Keep the UI focused: High contrast, sans-serif fonts, professional engineering color palette (Blues/Grays/White).
- **Mandatory**: Include comments in the JS explaining the formula mapping to standard RCC design codes (Limit State Method).
