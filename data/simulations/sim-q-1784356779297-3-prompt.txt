**Simulation Blueprint: "Weld-It-Up! Structural Sandbox"**

**Goal:** Create an interactive, gamified HTML5/JS simulation where students design a fillet weld connection for a tie plate.

**1. Aesthetic & Layout (Dark Cyber-Engineering):**
- Use a CSS `grid` layout (100vh) with a translucent glass-morphism dashboard.
- **Canvas:** Central 2D viewport showing a 3D-perspective steel tie plate and gusset plate.
- **Theme:** Neon cyan/purple highlights. Use `requestAnimationFrame` for fluid 60fps animations of weld beads.

**2. Core Gamified Mechanics:**
- **Variable Identification:** Display the prompt: "A tie plate of **(a)** mm connected to a gusset plate to transmit **(b)** kN load with **(c)** Fe 410 steel."
- **Interaction:** Students click blank spaces **(a), (b), (c)** to trigger a "Parameter Selector" pop-up. Selecting values triggers a *Voiceover* explaining the structural significance.
- **Drag-and-Drop Slots:** Users drag "Numerical Chips" (e.g., 8mm, 150kN) from a sidebar into the formula target slots on the canvas. 
- **Validation:** Successful placement triggers a "Snap" sound, a green glowing ring, and `window.speechSynthesis` affirmation ("Great! The weld size matches the plate thickness!").

**3. Advanced Visuals:**
- **Weld Growth Animation:** As users adjust weld size (s), draw the fillet weld profile in 2D cross-section on the canvas. Use an "Elastic" easing function for the weld "growing" onto the plate corners.
- **Force Vectors:** Display a vibrant arrow indicating the factored load. Moving the "Load" slider scales the arrow, while the *Web Audio Oscillator* pitch increases in frequency to match the "stress intensity."
- **Gesture Control:** Allow mouse/pointer sweeping over the connection; calculate real-time deflection/stress lines that warp visually with pointer position.

**4. Codebook Integration:**
- Create a "Clause 10.5.7" book icon. Dragging this book onto the workspace unlocks the formula editor, simulating looking up IS 800:2007 codes.

**5. Technical Constraints:**
- Responsive scaling using `canvas.width = window.innerWidth`.
- Use the Web Audio API to map slider movement to pitch.
