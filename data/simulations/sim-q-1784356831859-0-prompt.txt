**PROMPT FOR CODE GENERATOR:**

**Role:** You are an expert Educational Software Architect and Lead Frontend Developer specializing in high-fidelity STEM simulations.

**Objective:** Build a single-file, interactive HTML/JS/CSS simulation environment for "Column Design Principles: Short vs. Slender Columns & IS 456 Code Specifications." 

**Framework Constraints:** 
- Use the **"Universal Gamified Blueprint Pedagogy"** (6-Step Interaction Loop).
- **No static text boxes.** All content must be embedded in the interactive canvas or UI-driven dashboard elements.
- **Design Language:** Cyber-Engineering Dark Studio (#0f172a background, #1e293b panels, neon accents: Cyan #22d3ee, Crimson #ef4444, Emerald #10b981).

**Specific Build Requirements:**

### 1. The Studio Dashboard (Layout)
- **Top Bar:** "Simulation Control Center" with a persistent `speechSynthesis` toggle and status indicators for the 6-step loop.
- **Left Panel (The "Codebook" Library):** A scrollable tabbed drawer containing "IS 456:2000" virtual pages. Users must navigate to pages 48-50 (Column design) to "unlock" drag-and-drop capability.
- **Center Canvas (The Active Studio):** A 2D procedural canvas rendering a 3D-perspective RCC column. 
- **Right Panel (The Interaction Dock):** Where formula components (Variables: $L_{ex}, L_{ey}, D, b, P_u, e_{min}$) and "Condition Cards" appear for dropping into the canvas.

### 2. Gamified Interaction Logic
- **Step 1 (Problem Extraction):** Provide an interactive text block. When the user clicks "Short Column" or "Slender Column" in the text, the canvas dynamically shifts the column's aspect ratio ($L/b$ or $L/d$ ratio). Use `requestAnimationFrame` to animate the elongation of the column.
- **Step 2 (The Codebook Unlock):** Users must drag the correct "IS 456 Page" from the Left Panel into a "Verification Slot" on the canvas. If correct, the formula slots for $e_{min}$ or Longitudinal reinforcement % activate with a neon green pulse.
- **Step 3 (Drag & Drop Formulation):** Create "Numerical Chips" ($0.05, 20mm, 0.8\%, 4\%$). The user must drag these into the correct "Formula Slot" on the canvas. 
    - *Feedback:* Use `Web Audio API` (OscillatorNode) for a high-frequency "Chime" on success and a low-frequency "Thud" on failure.
- **Step 4 (Dynamic Visuals):**
    - **Longitudinal Reinforcement:** Dragging a reinforcement chip into the slot triggers a "Glow Animation" where the rebar inside the column cage pulses with neon cyan light.
    - **Eccentricity:** As $e_{min}$ is set, animate a "Resultant Force Vector" shifting off-center from the neutral axis.
    - **Camera Zoom:** Implement a `CSS transform: scale(1.5)` zoom-in on the cross-section when the user interacts with "Lateral Ties," revealing a detailed cross-section view.

### 3. Audio & Accessibility
- **Voiceover:** Trigger `window.speechSynthesis` during state changes (e.g., "Column buckling potential identified: Slender mode engaged.")
- **Sound:** Use standard `AudioContext` for interaction feedback (Beeps on selection, clicks on drag, confirmation pulses).

### 4. Technical Constraints
- **Library Usage:** Use standard HTML5 Canvas API for all structural renderings. No bulky external frameworks; lightweight vanilla JS preferred.
- **Visuals:** Use high-contrast stroke patterns for the RCC section (hatching for concrete, solid red lines for steel rebars). 
- **Animations:** Use `GSAP` (if available) or `requestAnimationFrame` for fluid transitions between column states (Short/Slender) and zooming.

### 5. Task Workflow
1. **Define the CSS Grid** for the Dashboard.
2. **Implement the Column Renderer:** A function that draws a column and accepts inputs for Height, Width, and Steel %.
3. **Setup the Logic Gate:** Build the 6-step progression state machine.
4. **Integration:** Link the "Formula Slots" to the simulation parameters so that dropping a value instantly updates the column's visual stress/buckling profile.

**Final Deliverable:** A robust, single-file HTML/JS/CSS output that functions as a high-end, immersive engineering simulation studio. Start by initializing the environment and the first "Data Extraction" step.
