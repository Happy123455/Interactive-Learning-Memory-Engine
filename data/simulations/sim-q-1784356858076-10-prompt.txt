You are an expert educational software developer. Your task is to build a high-fidelity, interactive web simulation for a Transportation Engineering module: **"Bitumen Testing: The Ductility Test."**

### 1. Project Overview & Aesthetic
Create a single-file HTML/JS/CSS application. Use a **"Cyber-Lab" aesthetic**: dark mode background (#0a0a0c), glassmorphic control panels (backdrop-filter: blur(10px)), and neon-accented UI elements (electric blue and vibrant amber). Use clean, modern sans-serif typography (Inter or Roboto).

### 2. Simulation Strategy
*   **Visual Representation:** Use a 2D HTML5 Canvas for the simulation. Render a realistic cross-section of a ductility briquette mold immersed in a water bath.
*   **The Physics Loop:** Implement a requestAnimationFrame loop to animate the "towing" mechanism. The central bitumen sample must stretch elastically before thinning into a thread and eventually snapping.
*   **Real-time Math:** Display a live-updating dashboard showing `Elongation (cm)` and `Force (N)` calculations. Use Chart.js or a custom Canvas path to plot a Force vs. Elongation curve in real-time as the test progresses.

### 3. Interactive Elements
*   **Drag & Drop:** Allow the user to "drag" the movable carriage of the ductility testing machine to adjust the initial setup or pull speed.
*   **Control Panel:** Provide sliders for:
    *   `Pulling Speed` (0.1 to 5.0 cm/min).
    *   `Temperature Control` (20°C to 30°C - this should affect the viscosity/stretchiness of the animation).
*   **Interactive Nodes:** Highlight the "Briquette" ends. Clicking these triggers a tooltip explaining the stress distribution at the clips.

### 4. Vector & Force Overlays
*   Render translucent vector arrows representing the pulling force vectors at the ends of the bitumen thread.
*   As the thread stretches, update the arrow magnitude (length) and color (blue to red as stress increases).
*   Overlay the real-time equation for Ductility: $D = L_2 - L_1$ (where L is the length at break).

### 5. Web Audio API Integration (No external files)
Use the Web Audio API to provide sensory feedback:
*   **Hum/Drone:** A low-pass filtered oscillator constant hum representing the motor running.
*   **Stretch Tension:** Use an oscillator whose frequency increases linearly with the displacement of the bitumen.
*   **Snap Effect:** Trigger a high-frequency white noise burst with an exponential gain decay when the bitumen thread reaches its breaking point.

### 6. Narrative Text-to-Speech (TTS)
