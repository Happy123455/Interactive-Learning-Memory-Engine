Act as an expert educational software developer. Build a single-file, interactive HTML5/JavaScript simulation to teach the "Marshall Method of Bituminous Mix Design."

### 1. Visual Simulation Strategy
- Use a `<canvas>` element for a 2D physics-based simulation of the Marshall Stability Test.
- Create a "Lab Environment" dashboard with a central viewport showing the Marshall testing machine (load frame and mold).
- Implement a 2D animation loop: show the load head compressing the sample. Use vector arrows to represent the compressive force magnitude. 
- Real-time plotting: Use a Chart.js or dynamic SVG coordinate system to plot the Load vs. Deformation curve as the test progresses.

### 2. Interactive Elements
- **Drag-and-Drop:** Provide a "Preparation Bench" where students drag bitumen, aggregate, and filler components into a mixing bowl to define mix proportions (percentage of bitumen).
- **Control Sliders:** Add glassmorphic sliders to adjust:
    - Bitumen Content (4% to 8%)
    - Compaction level (Number of blows)
    - Loading rate (mm/min)
- **Interactive Nodes:** Clicking the "Stability" or "Flow" indicators on the graph should trigger an info-popover explaining the physics at that specific point.

### 3. Sound Design (Web Audio API)
- Implement a `SoundEngine` class using the Web Audio API. 
- **Impact Sounds:** When the "Compaction" process occurs, trigger a percussive sound using a short-decay noise oscillator.
- **Feedback Sounds:** Use an oscillator to generate low-frequency hums for machine operation and high-frequency "success" chimes when valid inputs are selected. Avoid external files; synthesize all audio.

### 4. Narrative Text-to-Speech
- Include a "Narrate" button at the bottom of the dashboard.
- Integrate `window.speechSynthesis` to read aloud the specific step being performed (e.g., "Step 1: Determine the specific gravity of the constituents," "Step 2: Mixing at 150-160 degrees Celsius").
- Ensure the narration synchronizes with the simulation steps; create a state machine that tracks the "Current Step."

### 5. Diagram Animations & Math
- Display real-time equations in a floating glassmorphic box: $Stability = \frac{Load}{Area}$, $Flow = \Delta Deformation$.
- As the load increases in the animation, update the text values of these equations dynamically using a monospaced font.
- Use arrow animations that grow in length (scale) as the applied load intensity increases.

### 6. Aesthetics (UI/UX)
- **Theme:** "Cyber-Lab" dark theme. Use a charcoal background (`#121212`) with vibrant neon cyan and amber accents.
- **Glassmorphism:** Use `backdrop-filter: blur(10px)` and semi-transparent white/black backgrounds (`rgba(255, 255, 255, 0.1)`) for control panels and overlays.
- **Typography:** Use a clean, modern sans-serif stack like 'Inter' or 'Roboto'.
- **Transitions:** Use CSS `transition: all 0.3s ease-in-out` for all interactive elements to ensure smooth UI responsiveness.

### Implementation Guidelines
- The file must be self-contained: HTML, CSS, and JS in one block.
- Use pure JS (no external frameworks like React/Vue).
- Structure the code into distinct modules: `UIController`, `SimulationEngine`, `SoundModule`, and `Narrator`.
- Include a "Step-through" mode that highlights the correct order of the Marshall Method (Preparation -> Compaction -> Density/Void Analysis -> Stability/Flow Test).
