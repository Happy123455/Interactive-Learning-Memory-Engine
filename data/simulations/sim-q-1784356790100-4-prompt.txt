Act as an expert educational software developer. Build a single-file, interactive HTML5/JavaScript simulation for a structural engineering tutorial on "Axially Loaded Angle Struts." The simulation must calculate the compressive strength of an ISA (Indian Standard Angle) column and visualize the mechanical behavior.

### 1. Visual Simulation Strategy
*   **Main Canvas**: Use a 2D Canvas context to render the angle strut. Show a 3D-perspective isometric view of the angle (ISA 75x75x10 to 100x100x10) transitioning between sizes.
*   **Dynamic Load Visualization**: Draw a force vector (red arrow) applied at the centroid. Use a semi-transparent "buckling arc" overlay that deforms sinusoidally based on the calculated Euler buckling load ($P_c$).
*   **Real-time Graphing**: Use a secondary canvas area to plot a Slenderness Ratio ($\lambda$) vs. Compressive Strength ($f_c$) curve, with a glowing dot indicating the student’s current configuration.

### 2. Interactive Controls (Glassmorphic Dashboard)
*   **Input Sliders**: Create sliders for "Section Size" (Discrete steps: 75x75x10, 80x80x10, 90x90x10, 100x100x10) and "Length" (Continuous range: 2.5m to 3.5m).
*   **Drag-and-Drop**: Allow users to drag the load application point across the cross-section to see how eccentricity impacts the stress distribution (visualized via a heatmap on the angle face).
*   **Equation Overlay**: Display live-updating LaTeX-style equations (e.g., $P = A \cdot f_c$). Use a monospace font for variables that update values instantly as sliders move.

### 3. Web Audio API Sound Design
*   **Native Synthesis**: Implement a `WebAudioContext` that triggers only via user interaction.
*   **Feedback Loops**:
    *   **Slider Interaction**: Generate a low-pass filtered "click" (white noise through an exponential decay gain node) when a parameter changes.
    *   **Buckling Threshold**: Use an oscillator (Sine wave) that increases in frequency as the length increases (representing the column approaching its critical buckling limit).
    *   **Success Tone**: A soft C-major chord arpeggio when a valid design constraint is met.

### 4. Narrative Text-to-Speech (TTS)
*   Include a "Narrate" button. When clicked, use `window.speechSynthesis` to read the current design status (e.g., "The current slenderness ratio is 120. The section is prone to buckling.")
*   Implement automatic triggers: When a user changes the section size, the system should briefly state the change in area and radius of gyration.

### 5. Aesthetic Guidelines
*   **Theme**: Dark mode (background: #0a0a0c).
*   **Accents**: Use neon blue (#00f2ff) for structural lines and neon magenta (#ff00ff) for force vectors.
*   **UI Components**: Use glassmorphism (backdrop-filter: blur(10px) saturate(180%); background-color: rgba(255, 255, 255, 0.05); border: 1px solid rgba(255, 255, 255, 0.1);).
*   **Typography**: Clean sans-serif (e.g., Inter or Roboto).

### 6. Technical Requirements
*   **Engineering Logic**: Implement the standard IS 800 code formula for angle struts ($f_c$ based on $\lambda$). Ensure all units are consistent (N, mm).
*   **Animation**: Use `requestAnimationFrame` for smooth transitions between column states.
*   **Encapsulation**: All logic (HTML, CSS, JS) must be contained within a single `.html` file.
*   **Responsive**: Ensure the dashboard scales correctly on tablet and desktop screens.

### 7. Step-by-Step Logic Flow
1.  **Initialize**: Setup WebAudio nodes and default variables for ISA 75x75x10 at 2.5m.
2.  **Render**: Draw the strut and the graph grid.
3.  **Update Loop**: 
    *   On slider movement, calculate cross-sectional properties ($A, r_x, r_y$).
    *   Calculate critical load using the IS 800 simplified formula.
    *   Update the buckling arc deformation using `Math.sin()`.
    *   Update the text overlays with the new compressive strength value.
4.  **Feedback**: If the user hovers over the equation, trigger the TTS to explain the variable’s physical significance.
