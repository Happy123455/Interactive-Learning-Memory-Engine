Build a high-performance, interactive HTML/JS simulation for the Engineering Hydrology unit on "Factors Affecting the Rate of Evaporation." 

### **1. Visual Simulation Strategy**
*   **Scene**: Create a 2D canvas-based physics animation representing a water reservoir. 
*   **Core Visuals**: Display a cross-section of a water body with a glowing blue "water level" line. Use a particle system (small white/blue circles) to represent vapor molecules transitioning from the water surface into the air.
*   **Animation Loop**: The evaporation rate should be linked to the particle emission rate. Higher evaporation = higher particle count/velocity.
*   **Layout**: Use a dark-mode dashboard (Hex: #0f172a) with glassmorphic cards (background: rgba(255, 255, 255, 0.05); backdrop-filter: blur(10px)).

### **2. Interactive Controls & UI**
*   **Input Controls**: Provide a set of sliders to adjust the following variables taught in the syllabus:
    *   **Temperature**: Adjusts the ambient heat (color shifts from cool blue to warm orange).
    *   **Wind Speed**: Adjusts the velocity of cloud/air icons sweeping over the water.
    *   **Humidity**: Adjusts the "saturation" level of the air overlay (high humidity adds a dense, foggy filter).
    *   **Impurity Level**: Adds particles representing salt/impurities, which inhibit the release of vapor particles.
    *   **Surface Area**: Controls the width of the reservoir container.
*   **Dynamic Feedback**: Include a real-time updating graph (using Chart.js or D3) showing the "Evaporation Rate (mm/day)" vs. the active variable being adjusted.
*   **Drag & Drop**: Allow the user to drag a "cover" (e.g., polyethylene sheet) onto the water surface, which immediately halts particle emission (demonstrating evaporation reduction).

### **3. Web Audio API Sound Design (No External Files)**
*   **Evaporation Hum**: Use an `OscillatorNode` (sine wave) at 110Hz, modulated by a `GainNode` that adjusts volume based on the total evaporation rate.
*   **Interaction Clicks**: Use a low-pass filtered triangle wave pulse for slider adjustments.
*   **Toggle Sounds**: Use a rapid frequency sweep (upwards) for enabling features (like the cover) and a downwards sweep for disabling.

### **4. Narrative Text-to-Speech (TTS)**
*   **Narration System**: Implement a "Narrate" button. When clicked, use `window.speechSynthesis` to provide context.
*   **Dynamic Scripting**: If a student moves a slider, the simulation should track state. Example: "You have increased the wind speed. Notice how the particle emission accelerates, as higher wind removes the vapor layer, promoting faster evaporation."
*   **Instructional Loop**: Provide a "Explain Concepts" mode that cycles through the factors listed in the provided slides, highlighting the corresponding control as it speaks.

### **5. Mathematical Visualization**
*   **Formula Overlay**: Display an equation box (LaTeX-styled) at the bottom. As the student changes variables, update the formula to show the relationship (e.g., *E ∝ Temperature*).
*   **Vector Diagrams**: Draw a small vector arrow above the water surface that grows or shrinks in length and changes color (red to green) to represent the "Evaporation Force/Magnitude."

### **6. Aesthetics & Technical Constraints**
*   **Theme**: Cybernetic/Modern academic. Use glowing neon accents (Cyan for water, Amber for heat).
*   **Typography**: Use 'Inter' or 'Roboto'.
*   **Tech Stack**: Pure HTML5, CSS3 (with Flexbox/Grid), and Vanilla JavaScript (ES6+). 
*   **Performance**: Use `requestAnimationFrame` for all particle updates to ensure 60FPS. 
*   **Accessibility**: Ensure all sliders have high-contrast labels and the simulation is keyboard-navigable.

### **Execution Workflow for the Generator:**
1.  Initialize the canvas context.
2.  Define the `EvaporationPhysics` engine that calculates particle velocity based on the input variables.
3.  Implement the Web Audio nodes and connect them to the evaporation rate.
4.  Construct the UI panel using absolute positioning for the glassmorphic controls.
5.  Set up the `speechSynthesis` event listeners for interactive learning.
6.  Ensure all units (mm/hr, Kelvin, etc.) align with the Darshan University Civil Engineering slide content provided.
