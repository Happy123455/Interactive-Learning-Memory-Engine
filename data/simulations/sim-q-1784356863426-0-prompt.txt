You are an expert Frontend Engineer and Educational Game Developer. Your task is to build a high-fidelity, interactive, gamified simulation titled "Flexible Pavement Architect" using HTML5, CSS3, and Vanilla JavaScript. 

### 1. THE ARCHITECTURAL VUE (CORE LAYOUT)
- **Dashboard UI**: Implement a "Cyber-Engineering" aesthetic: Dark mode, glassmorphism panels (backdrop-filter: blur), and neon-accented borders (cyan for structural info, purple for interaction zones, green for success/verification).

### 2. GAMIFIED CONSTRUCTION MECHANICS (DRAG-AND-DROP)
- **The Construction Canvas**: Provide a blank foundation cross-section. The user must drag and drop material "blocks" (Subgrade, Sub-base, Base, Binder Course, Surface Course) from the side inventory onto the canvas.
- **Magnetic Snapping**: Implement snap-to-layer logic. When a block is dropped, trigger a "pour" animation—a fluid transition where the layer visually settles into the section.
- **Layer Verification**: Once a layer is dropped, it must glow with a neon highlight. The user must click the layer to trigger a `window.speechSynthesis` narration explaining its specific function (e.g., "Sub-base: Distributes loads and provides drainage").

### 3. INTERACTIVE FIGURES & ANALYSIS
- **Live Vector Overlays**: As the user builds, draw dynamic "Load Distribution" force vectors on the canvas. When a user drags a "Wheel Load" icon onto the Surface Course, animate a downward force bulb (using `CanvasRenderingContext2D` arcs) that spreads wider and shallower as it passes through each successive layer.
- **The X-Ray Inspector**: Include an "Inspect Mode" toggle. When active, moving the mouse over the cross-section displays a callout box with technical specs (Material, Modulus of Elasticity, Typical Thickness) in a clean, high-contrast overlay.

### 4. DYNAMIC FEEDBACK & AUDIO
- **Web Audio Synth**: 
    - **Success**: High-pitched ascending arpeggio (sine wave).
    - **Invalid Placement**: Low-frequency, muted "thud" (sawtooth wave with short decay).
    - **Snap Effect**: Sharp "click" when layers align.
- **Speech Synthesis**: Utilize `window.speechSynthesis` to provide contextual audio narration upon interacting with any layer, ensuring the learner hears the engineering logic while they build.

### 5. EDUCATIONAL PEDAGOGY (TARGET: FLEXIBLE PAVEMENT)

- **Styling**: All text must be rendered with modern sans-serif fonts (Inter or Roboto). Ensure labels have legible semi-transparent backdrops for readability over the diagram.
- **Interaction Logic**: Use pointer events (mousedown/move/up) to ensure compatibility with touch and desktop devices. Implement a "Reset Construction" button that triggers a fluid slide-out animation of current layers.
