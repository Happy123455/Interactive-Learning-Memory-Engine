**Prompt for AI Code Generator: Hydrologic Abstractions Interactive Simulator**

**Objective:** Develop a single-file, high-performance HTML5/JavaScript simulation titled "Hydrologic Abstractions Explorer." The tool must visualize the water cycle components: Evapotranspiration, Transpiration, Interception, and Depression Storage for an Engineering Hydrology context.

---

### 1. Visual Simulation Strategy
*   **Engine:** Use a responsive `<canvas>` element for a 2D side-profile view of a landscape.
*   **Scene Elements:** 
    *   Left side: A water body (lake) to demonstrate Evaporation.
    *   Center: Vegetation (trees/crops) to demonstrate Transpiration and Interception.
    *   Right side: Rough, uneven terrain to demonstrate Depression Storage.
*   **Physics Loop:** Use `requestAnimationFrame`. Implement a particle system for rain (falling blue dots) and water vapor (rising semi-transparent white particles). 
*   **Visual Overlays:** Use dynamic SVG-like drawing on the canvas to represent vector forces (arrows showing magnitude of flux) and mass-balance flows (labels for *E, T, I, D*).

### 2. Interactive Elements (Dashboard)
*   **Control Panel:** A glassmorphic sidebar/overlay with sliders for:
    *   `Rainfall Intensity` (mm/hr)
    *   `Vegetation Density` (Influences Interception)
    *   `Surface Roughness` (Influences Depression Storage)
    *   `Temperature` (Influences Evaporation/Transpiration)
*   **Interaction:** 
    *   **Drag-and-Drop:** Allow users to drag "Vegetation" icons from a library onto the landscape to observe real-time changes in Interception and Transpiration.
    *   **Live Graphs:** A bottom-anchored real-time Chart.js or D3-style plot displaying the "Water Balance" (Precipitation vs. Abstractions).
    *   **Equation Display:** A floating, responsive math block (using simple text-based rendering or MathJax) showing the governing equations: $ET = E + T$, and $Total Abstraction = I + D + Infiltration$.

### 3. Web Audio API Integration (No external files)
*   **Sound Engine:** Implement an `AudioContext` class for system-generated sounds:
    *   **Rain:** White noise generated via `AudioWorkletNode` or `ScriptProcessorNode` filtered with a low-pass filter.
    *   **State Changes:** Use `OscillatorNode` (Sine/Triangle) to produce "blips" when parameters are adjusted.
    *   **Impact:** A quick "thud" synthesized with an exponential decay on the gain node when rainfall interacts with depression storage surfaces.

### 4. Narrative Text-to-Speech (TTS)
*   **Narrator System:** Include a "Narrate" toggle. Use `window.speechSynthesis` to trigger descriptive explanations when a student clicks an element (e.g., clicking the "Depression Storage" zone triggers: *"Depression storage is the temporary storage of rainfall in small surface irregularities. Notice how increasing surface roughness increases this value."*)
*   **Instructional Workflow:** Create a "Guided Tour" button that sequentially highlights areas of the screen while narrating the definitions provided in the Unit 2 notes.

### 5. Diagram Animations
*   **Mathematical Rendering:** When the user changes a parameter, show the formula in the dashboard animating (e.g., scale up the value being modified).
*   **Vector Arrows:** Dynamically change the length and color (Gradient from Blue to Red) of flux arrows. If `Temperature` increases, show the evaporation flux arrow (rising from the lake) growing in size and velocity.

### 6. Aesthetics & UI/UX
*   **Theme:** Dark mode aesthetic. Use a midnight-blue/deep-charcoal background.
*   **Neon Accents:** Use cyan for water/rainfall, lime for vegetation, and amber for equation results. 
*   **Glassmorphism:** Use `backdrop-filter: blur(10px);` on all control containers with semi-transparent white backgrounds (`rgba(255, 255, 255, 0.1)`).
*   **Typography:** Use a clean, modern sans-serif font (e.g., Inter or Roboto).
*   **Responsive:** Ensure the canvas resizes gracefully to fit various display aspect ratios.

---

**Execution Requirements:**
1.  All logic must be contained in a single HTML file (HTML, CSS, JS).
2.  Code must be heavily commented, explaining how the hydrologic parameters link to the visual state.
3.  Ensure high performance by minimizing heavy calculations inside the `requestAnimationFrame` loop.
4.  Include a "Reset Simulation" button to return to default hydrologic conditions.
