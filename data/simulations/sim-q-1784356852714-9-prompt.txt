Create a high-fidelity, interactive web-based simulation for a Transportation Engineering module on "Superelevation in Horizontal Curves." The tool must be built as a single-file HTML5 application using CSS3 (for styling/animations) and vanilla JavaScript (for logic, canvas rendering, and audio synthesis).

### 1. Visual Simulation Strategy
- **Central Canvas**: A 2D top-down view showing a vehicle navigating a curve with a radius 'R'. Include a side-profile cross-section view showing the pavement banking (superelevation 'e').
- **Vector Overlays**: Use a dynamic canvas loop (`requestAnimationFrame`) to render force vectors in real-time (Centrifugal Force P, Gravity Component, Friction Force F). As users modify inputs, these vectors should scale and re-orient fluidly.
- **Physics Engine**: Implement a basic equilibrium solver. Visualize the vehicle as a rectangular block. Use standard kinematic equations: $P = WV^2/gR$ and $e + f = V^2/127R$ (where $V$ is kmph).

### 2. Interactive Elements
- **Input Controls**: Use a glassmorphic sidebar containing:
    - **Sliders** for "Radius (m)", "Design Speed (kmph)", and "Coefficient of Friction (f)".
    - **Toggle Switches** for modes: "Part (a): Full Friction" vs "Part (b): No Superelevation (Solve for f)".
    - **Display Labels**: Real-time calculated values for Superelevation (e) or Required Friction (f) updated via the DOM.
- **Drag-and-Drop Interaction**: Allow users to drag the vehicle along the path of the curve to observe how centripetal force requirements change if they deviate from the design speed.

### 3. Aesthetics & UI/UX
- **Theme**: Dark mode dashboard with deep charcoal backgrounds (#121212) and neon cyan/magenta accents.
- **Glassmorphism**: Use `backdrop-filter: blur(10px)` for control panels.
- **Typography**: Clean, sans-serif fonts (e.g., 'Inter' or 'Roboto').
- **Transitions**: Smooth easing for all vector updates and slider movements.

### 4. Audio Synthesis (Web Audio API)
- **Sound Design**: Create a non-external sound engine using the `AudioContext` API.
    - **UI Interaction**: A soft, high-frequency "pluck" (short-decay oscillator) for button clicks.
    - **Simulation State**: A low-frequency hum that changes pitch based on the "Speed" slider to represent engine/road noise. Use a `gainNode` to fade it out when the simulation is paused.

### 5. Educational Narrative (Speech Synthesis)
- **Narration Engine**: Implement a "Narrate Concept" button. When clicked, use `window.speechSynthesis` to read a pedagogical breakdown of the current state:
    - "The centrifugal force is currently exceeding the resistive forces. Observe the red vector length."
    - "By increasing the superelevation, we balance the lateral load, reducing the strain on friction."
- **Context Awareness**: The narration should dynamically pull values from the sliders to personalize the explanation.

### 6. Implementation Steps for the Model
1. **HTML Structure**: Set up a main `<canvas>` for drawing and a `<section id="controls">` for the dashboard.
2. **Mathematical Controller**: Create a JS object that updates the `e` and `f` variables based on the current inputs and switches. 
   - Formula for (a): $e = (V^2 / 127R) - f$
   - Formula for (b): $f = V^2 / 127R$
3. **Canvas Drawing Routine**: 
   - Use `ctx.beginPath()` for the road curvature and cross-section lines.
   - Use `ctx.arrow()` functions (custom implementation) to draw the P, W, and Friction vectors.
4. **Integration**: Connect the `input` event listeners to the `render()` loop and the speech synthesis functions.
5. **Responsiveness**: Ensure the canvas scales to window size while maintaining the 16:9 aspect ratio.

**Constraints**: Do not use any external images or media. All graphical assets must be drawn programmatically using Canvas API paths. Keep the code clean, modular, and heavily commented for educational clarity.
