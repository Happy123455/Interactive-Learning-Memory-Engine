### Simulation Blueprint: The "Steel-Snap Workshop"

**Objective**: Create a high-fidelity, interactive 2D physics sandbox for identifying and testing structural steel connections. 

**Core UI/UX**:
*   **Aesthetic**: "Cyber-Blueprint" theme. Dark grid-paper background, translucent glass panels, and glowing neon UI (cyan/magenta).
*   **Layout**: 100vh flexbox container. Left: "The Field" (Canvas). Right: "The Toolbox" (Tabs: Bolts, Welds, Load Inputs). Bottom: "Narration/Status Bar".
*   **Responsiveness**: Full-window canvas with `requestAnimationFrame` scaling. Use `CanvasRenderingContext2D` for clean, high-DPI vector paths.

**Interactive Mechanics**:
1.  **Field Application Finder**: A split-screen mode where users "snap" photos (generated via canvas filters) of steel joints. Use a drag-and-drop mechanism to place "Connection Type" cards (Lap, Butt, Gusset) onto the joints.
2.  **Gamified Simulation**: 
    *   **Drag-and-Drop Parameters**: Users drag physical bolt/weld icons into a "Joint Hub". Success triggers a pulse-glow effect (neon green) and a `window.speechSynthesis` explanation (e.g., "This is a Lap Joint! It’s like two sticky notes held by a thumbtack!").
    *   **Vector/Physics Overlay**: Provide a "Force Toggle" that draws real-time resultant shear/moment vectors over the joints. When a user drags a "Load Slider," the connection visually deforms, and the pitch of a Web Audio `OscillatorNode` rises to match the "stress-strain" intensity.
3.  **IS 456 / IS 800 Integration**: Include a clickable "Code Book" modal. Dragging a clause number (e.g., "Cl. 10.2") onto an active joint instantly applies the design limits and highlights failing bolts in flashing red.
4.  **Feedback**: 
    *   **Sound**: High-quality synth clicks for UI, rising frequency "tension" chirps during beam bending, and deep bass thuds upon successful component attachment.
    *   **Visuals**: Use CSS animations for "Concrete/Steel Pour" effects and smooth transitions between diagram states (e.g., pivot point shifts in semi-rigid connections). 

**Constraint**: Absolutely no static text blocks. Every label must be a hoverable/interactive SVG element. Ensure zero scrolling; all content must fit within the 100vh viewport.
