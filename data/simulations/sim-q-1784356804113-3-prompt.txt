**PROMPT FOR CODE GENERATION: INTERACTIVE STRUCTURAL DESIGN SIMULATOR**

**Role:** Act as a Senior Educational Software Architect and Frontend Expert.
**Objective:** Develop a high-fidelity, interactive single-page simulation (HTML5/CSS3/JS) for a college-level Structural Engineering course focusing on "Moment of Resistance and Safe Load Calculation for a Singly Reinforced Concrete Beam."

### 1. Visual Simulation Strategy
*   **Physics Engine:** Utilize `Matter.js` or a custom `requestAnimationFrame` loop for real-time physics.
*   **Canvas Rendering:** Use HTML5 Canvas to render a cross-section of an RCC beam (b x d).
*   **Diagrams:** Display a split-screen view: 
    *   **Left:** A 2D interactive beam cross-section with a dynamic stress-strain block diagram overlay. 
    *   **Right:** A real-time load-deflection graph plotting the relationship between the UDL and the beam's internal bending moment.
*   **Dynamic Visuals:** As input parameters (b, d, bar diameter) change, the beam dimensions and reinforcement bars must visually resize using smooth scaling transitions.

### 2. Interactive Elements
*   **Input Controls:** A glassmorphic sidebar featuring range sliders for:
    *   Width (b) [200mm - 500mm]
    *   Effective Depth (d) [300mm - 800mm]
    *   Bar Diameter (12mm, 16mm, 20mm selection toggle)
    *   Span Length (2m - 6m slider)
*   **Drag & Drop:** Allow users to "drag" a virtual load onto the beam. As the load is dragged across the span, show the live bending moment value at the center.
*   **State Updates:** Every interaction must instantly trigger a recalculation of the Moment of Resistance ($M_u$) and the Safe Working UDL ($w$), updating the displayed equations in real-time.

### 3. Sound Design (Web Audio API)
Implement a `SoundEngine` class using the Web Audio API (No external files):
*   **Update Sweep:** A low-pass filtered oscillator sweep (sine wave) triggered when sliders are moved.
*   **Calculation Success:** A pleasant, harmonious arpeggio chime when the beam is "Safe."
*   **Warning Pulse:** A low-frequency, slightly dissonant pulse (square wave) if the applied load exceeds the Moment of Resistance (Failure state).

### 4. Narrative Text-to-Speech (TTS)
*   Integrate a `Narrator` module using `window.speechSynthesis`.
*   Include a "Start Tutorial" button that triggers a step-by-step narration:
    1.  "Defining beam geometry and material properties."
    2.  "Calculating the neutral axis depth and lever arm."
    3.  "Determining the capacity of the section."
    4.  "Calculating the safe working load based on the maximum bending moment."
*   Provide a toggle button to enable/disable auto-narration.

### 5. Diagram Animations & Math Rendering
*   **Math Display:** Use `MathJax` or `Katex` for clean, professional rendering of the Limit State Design formulas (e.g., $M_u = 0.87 f_y A_{st} d (1 - (A_{st} f_y / b d f_{ck}))$).
*   **Vector Overlays:** Use animated arrows representing internal forces (Compression in concrete vs. Tension in steel). The length of these arrows must scale dynamically with the input forces.

### 6. Aesthetics & UI/UX
*   **Theme:** Dark mode aesthetic with `#121212` background.
*   **Styling:** Glassmorphism for control panels (`backdrop-filter: blur(10px)`, semi-transparent black surfaces).
*   **Accents:** Glowing cyan neon highlights for active stress zones and vibrant orange for warning thresholds.
*   **Typography:** Clean, sans-serif font (Inter or Montserrat).
*   **Modals:** A sleek, animated modal for the step-by-step tutorial that dims the background canvas.

### 7. Technical Requirements
*   **Structure:** Single HTML file containing CSS, JS, and dependencies via CDN.
*   **Responsiveness:** Must be fully responsive and maintain the aspect ratio of the structural diagrams.
*   **Code Quality:** Clean, commented code with clear separation of concerns (Logic Engine, Rendering Engine, Sound Engine).

**Constraint:** Ensure the physics calculations for the UDL and Moment of Resistance follow standard IS 456:2000 or general Limit State Design principles. Provide a toggle to switch between "Live Calculation" and "Guided Tutorial" modes.
