### **Part 4: Robust Viewport & Resolution Rules (The Foundation)**

1.  **CSS:** As defined in Part 1, ensure the main container `height: 100vh;` and uses `grid` or `flexbox` for sub-containers. `overflow: hidden;` on the root `body` and `#app-container` to prevent double scrollbars.
2.  **JavaScript Canvas Resizing:**
    ```javascript
    const canvas = document.getElementById('simulationCanvas');
    const ctx = canvas.getContext('2d');
    const canvasContainer = document.getElementById('simulation-canvas-container');

    function resizeCanvas() {
        const dpr = window.devicePixelRatio || 1;
        canvas.width = canvasContainer.clientWidth * dpr;
        canvas.height = canvasContainer.clientHeight * dpr;
        ctx.scale(dpr, dpr);
        // Redraw all elements after resize
        drawSimulation();
    }
    window.addEventListener('resize', resizeCanvas);
    resizeCanvas(); // Initial call
    ```
3.  **Drawing Philosophy:** All canvas elements must be drawn relative to the current `canvas.width` and `canvas.height` (or a fixed aspect ratio if needed), not absolute pixel values, to ensure responsiveness. Clear the canvas `ctx.clearRect(0, 0, canvas.width, canvas.height);` or `ctx.fillRect()` with the dark background color at the start of each `drawSimulation()` cycle.
