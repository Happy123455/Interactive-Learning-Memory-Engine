**System Prompt for Structural Engineering Simulation Builder**

**Objective:** Develop a high-fidelity, interactive HTML5/JavaScript educational simulation for a "Discontinuous Single Angle Strut" design. The tool must allow engineering students to visualize the relationship between axial load, effective length, and cross-sectional capacity.

**1. Visual Simulation Strategy**
*   **Canvas Environment:** Utilize a 2D Canvas API loop to render a professional-grade structural engineering schematic.
*   **Central Schematic:** Display a 2D side-profile of a single angle strut between two rigid supports.
*   **Physics/Math Layer:** Implement a real-time reactive grid. As input parameters change, update a secondary "Stress-Strain/Capacity" overlay plot (using Chart.js or D3.js) alongside the physical schematic.
*   **Constraint Visualization:** Use red/green color-coded vector overlays to indicate the "Factor of Safety" or "Buckling Capacity" vs. "Applied Load."

**2. Interactive Elements**
*   **Control Dashboard:** Create a glassmorphic sidebar containing:
    *   **Sliders:** Factored Load (80-100kN), Span (2.5-3m).
    *   **Draggable Handles:** Allow students to drag the supports horizontally to change the span length, with real-time value updates.
    *   **Bolt Logic:** A toggle to simulate 1 vs 2 bolts, which triggers an automatic update to the "Effective Length" calculation (K-factor adjustment).
*   **Reactive State:** All inputs must trigger a re-calculation of the design adequacy (Load/Capacity ratio) instantly.

**3. Sound Design (Web Audio API)**
*   **Oscillator Synthesis:** Do not use external files. Initialize an `AudioContext` with the following:
    *   **Success Tone:** A harmonic chord (440Hz + 554Hz) triggered when the strut design passes capacity checks.
    *   **Warning Sweep:** A descending low-pass filter sweep (sawtooth wave) when the design is over-stressed.
    *   **Interaction Click:** A short, dampened sine-wave click on every slider movement or button press.

**4. Narrative Text-to-Speech**
*   **Voiceover Integration:** Implement a `window.speechSynthesis` service.
*   **Contextual Triggers:** Include a "Narrate" toggle. When active, the app must describe the current step (e.g., "Increasing the span length increases the slenderness ratio, thereby reducing the axial load-carrying capacity").
*   **Tutorial Mode:** Add an "Explain" button that triggers a sequential narration of the design steps according to standard steel code (IS 800 or similar).

**5. Diagram Animations & Math**
*   **Equation Rendering:** Use MathJax or LaTeX-to-HTML to display the governing formula (e.g., $P_d = A_e f_{cd}$) at the bottom of the screen.
*   **Dynamic Updating:** As variables (Load, Length, Section Size) change, animate the equation variables in bold, glowing highlights to show which component is being affected.
*   **Visual Feedback:** Use GSAP (GreenSock) for smooth transitions between parameter states. Ensure the structural element (the strut) subtly "buckles" (bends) visually when the load exceeds capacity.

**6. Aesthetics & UI Guidelines**
*   **Theme:** Dark mode aesthetic (Background #0f172a).
*   **Accents:** Neon cyan and lime green for interaction points and critical capacity thresholds.
*   **Glassmorphism:** Use `backdrop-filter: blur(10px)` and `rgba` backgrounds with low opacity for all control boxes to create a modern, high-tech engineering workstation look.
*   **Typography:** Clean, sans-serif, high-legibility fonts (Inter or Roboto).
*   **Responsiveness:** The layout must remain functional across varying viewport sizes, centering the schematic and pinning controls to the right sidebar.

**Deliverables:**
Provide a single-file solution (HTML/CSS/JS bundled) or a clearly structured project directory that is self-contained. Ensure the code is commented for pedagogical transparency.
