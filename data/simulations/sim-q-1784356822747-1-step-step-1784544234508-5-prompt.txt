**Prompt for Code Generation: Structural Engineering Simulation - Limit State Design of RCC Beam**

**Role:** Act as a Senior Educational Software Developer and Structural Engineering Expert.
**Task:** Build a high-fidelity, gamified, interactive simulation for a web-based learning environment using HTML5 Canvas, modern JavaScript (ES6+), and CSS3.

**Simulation Objective:**
Create an interactive tutorial for "Unit 2: Design of RCC Beams," specifically focusing on **Step 6: Determining Design Shear Strength (τc)**. The user must understand how to derive τc based on the percentage of reinforcement (pt) and concrete grade (fck) following IS 456 standards.

---

### **Design & Visual Specifications:**
1.  **Aesthetic:** "Cyber-Engineering Dashboard." Use a deep charcoal/black background with high-contrast neon accents (Cyan for structural parameters, Electric Purple for formulas, Matrix Green for computed results). Glassmorphism panels for information boxes.
2.  **Interface Components:**
    *   **The Beam Cross-Section (Central Canvas):** A dynamic 2D cross-section diagram showing 'b' (width), 'd' (effective depth), and the reinforcement steel area 'Ast'.
    *   **The Parameter Deck:** A sidebar containing "Drag-and-Drop" cards for values (e.g., *fck=20 N/mm²*, *Ast=1435.51 mm²*, *b=300mm*).
    *   **The Interactive Formula Slot:** A glowing, empty equation area for $p_t = (100 * A_{st}) / (b * d)$.
    *   **Live Graph/Table Overlay:** A translucent panel representing IS 456 Table 19. When the calculated *p_t* value is dropped onto the table, the corresponding *τc* value glows and locks into place.

### **Core Interactive Mechanics (Instructional Requirements):**
1.  **Drag-and-Drop Logic:**
    *   Users must drag parameter cards onto the Canvas or Formula Slot.
    *   If a correct value is dropped, trigger a "Positive Resonance" sound (synthesized sine wave chime).
    *   If an incorrect value is dropped, trigger a "Warning Tone" (low-frequency buzz) and highlight the mistake in red.
2.  **Real-Time Computation:**
    *   As values are dropped into the $p_t$ formula, the Canvas should animate a "filling" effect in the steel reinforcement bars to represent the calculated percentage.
    *   Display a real-time "Stress-Strain" line graph that updates as the reinforcement percentage changes.
3.  **Auditory & Narration:**
    *   Use `window.speechSynthesis` to provide a professional, pedagogical narration. Example: "Step 6: We now determine the design shear strength. Drag the reinforcement card into the percentage formula to proceed."
    *   Include Web Audio API synth triggers for interaction: Clicks for selection, high-pitched ascending beeps for successful calculation progression.

### **Technical Implementation Steps:**
1.  **State Management:** Create a JS object to hold the current problem variables ($f_{ck}=20, b=300, d=500, A_{st}=1435.51$).
2.  **Canvas Animation:** Use `requestAnimationFrame` for smooth transitions when force vectors or cross-section dimensions are updated. 
3.  **Gamified Feedback:**
    *   **Task 1:** Calculate $p_t$ by dragging variables into the formula.
    *   **Task 2:** Drag the resulting $p_t$ coordinate onto the "IS 456 Table 19" pop-up.

4.  **No Exam Paper Text Blocks:** Do not generate static text containers that mimic exam sheets. The UI must be purely graphical, functional, and "dashboard-like." All instructional text should appear as floating, animated tooltips or HUD overlays.
