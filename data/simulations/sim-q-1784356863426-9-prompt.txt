Act as an expert Educational Technology Developer. Your goal is to build a high-end, gamified, interactive simulation dashboard for "Flexible Pavement Bituminous Construction" using HTML5, CSS3, and Vanilla JavaScript. 

### 1. Visual Architecture (Aesthetics)
- **Dashboard Layout:** A "Cyber-Engineering Command Center." Use a dark-mode theme (`#0a0a0c`) with translucent frosted-glass panels (`backdrop-filter: blur(10px)`). Use neon accents: Cyan (for data/labels), Purple (for active machinery), and Warning Orange (for temperature alerts).
- **Responsiveness:** Use CSS Grid/Flexbox to ensure the app is locked to `100vh` without scrollbars. The canvas must handle high-DPI scaling automatically.

### 2. The Simulation Core: Bituminous Pavement Construction
- **Canvas Environment:** A multi-layered road section cross-section (Subgrade, Sub-base, Base, Bituminous layer). 
- **Interactive Machinery:** Include drag-and-drop icons representing the "Paver Finisher" and "Steel Drum/Pneumatic Roller."
- **The Core Interaction:** 
    - **Step 1 (Drag & Drop):** User drags a "Bitumen Truck" icon onto the roadway; a fluid "pour" animation fills the bituminous layer slot with a temperature-reactive texture (glows orange/red when hot).
    - **Step 2 (The Temperature Loop):** A thermometer widget tracks the mix temperature. If the temperature drops below the compaction threshold (120°C - 150°C), the layer turns a dull grey.
    - **Step 3 (Compaction Mechanic):** Drag the "Roller" icon back and forth over the pavement. As it passes, use Canvas paths to draw "compaction waves" and increase the "Density %" readout in real-time.

### 3. Engineering Pedagogy & Gamification
- **Formula Slots:** Create interactive drop-targets for paving parameters (e.g., "Layer Thickness," "Compaction Speed," "Temperature"). 
- **Parameter Identification:** Clicking on the road cross-section reveals floating labels for (h, T, ρ, v). The user must drag calculated value chips into these slots to unlock the next stage.
- **Dynamic Physics/Math:** Plot a real-time graph showing "Density vs. Number of Passes." As the user drags the roller, the curve updates dynamically using a parabolic function.
- **IS/Codebook Integration:** A sidebar "Field Manual" icon. When clicked, it expands to show a "Standard Requirements" card. The student must match the site temperature to the manual's requirements to proceed.

### 4. Audio & Voice Integration
- **Web Audio Synth:** 
    - "Click" sounds for successful drops.
    - A low-frequency, pulsating "rhythmic hum" for the roller operation.
    - "Warning" beeps when temperature drifts outside the ideal range.
- **Narration:** Use `window.speechSynthesis`. When a user drags the roller, have the agent speak: *"Compaction in progress. Maintain temperature above 120 degrees to ensure optimal density."*

### 5. Technical Implementation Requirements
- **Canvas Layering:** Separate background (stationary grid), mid-ground (interactive road sections), and foreground (floating UI/alerts).
- **Animation Strategy:** Use `requestAnimationFrame` for smooth machinery movement and temperature color transitions.
- **State Management:** Maintain a central object (e.g., `simState`) tracking `temperature`, `density`, `compactionCycles`, and `isPaved`.
- **Drag & Drop:** Use standard HTML5 Drag & Drop API or touch-compatible Pointer Events for mobile-friendliness.

### 6. Interaction Workflow (Step-by-Step)
1. **Introduction:** Display the "Construction Site" dashboard.
2. **Phase 1 (Paving):** Drag the "Bitumen Mix" icon; trigger the "pour" animation and update the cross-section height.
3. **Phase 2 (Monitoring):** Monitor temperature; provide user feedback via voiceover if it cools too fast.
4. **Phase 3 (Compaction):** Drag the roller. Use math to increment density based on passes. Update the graph in real-time.
5. **Phase 4 (Validation):** If density reaches the target range (e.g., 98%), play a "Success" chime, glow the road green, and display a "Construction Certified" badge.

**Constraint:** No static exam text or notebook layouts. Every instruction must be tied to a visual, interactive element in the canvas environment.
