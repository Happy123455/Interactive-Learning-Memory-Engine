You are an expert educational software developer. Your task is to generate a high-performance, single-file HTML/JS/CSS simulation for an **Isolated Sloped Footing Design** experience.

### **The Objective**
Create a "Universal Gamified Blueprint Studio" where students design an isolated footing for a column (1000kN load, 150kN/m² soil capacity). The simulation must avoid static text and instead leverage interactive 2D canvas manipulations and drag-and-drop engineering logic.

### **Technical Requirements**
1.  **Framework**: Vanilla HTML5, CSS3, and JavaScript (ES6+). Use `requestAnimationFrame` for all animations.
2.  **Sound/Voice**: Implement `window.speechSynthesis` for narrative guidance and the Web Audio API for UI feedback (snaps, chimes, error buzzes).
3.  **Visuals**: Use a "Dark Engineering Studio" theme (Slate-900 background, neon cyan/purple accents). Ensure all UI elements are glass-morphic (`backdrop-filter`).

### **Development Steps**

#### **Step 1: The Interactive Variable Extraction**
*   **The Problem Card**: Display the problem text in a floating glass panel. When the user clicks a variable (e.g., "1000kN" or "150kN/m²"), highlight the text in gold and trigger an `onSpeech` narration explaining its role in the calculation.
*   **Blueprint Growth**: As variables are identified, animate the appearance of the footing cross-section on the canvas. The column width/depth and footing boundary lines must extrude from a central origin with smooth scaling transitions.

#### **Step 2: The "IS 456" Codebook Challenge**
*   Create a virtual, draggable "IS 456 Codebook" icon. When clicked/dragged into the viewport, it opens a scrollable overlay showing relevant clauses (e.g., Page 69 for footing pressure).
*   **Gamification**: The user must drag the correct Clause ID/Formula card from the book into a "Formula Slot" on the main workspace.

#### **Step 3: Interactive Physics & Formula Assembly**
*   **Formula Slots**: Create empty equation placeholders (e.g., `Area = Load / SBC`).
*   **Value Cards**: Generate interactive "Value Cards" (e.g., "1000", "150", "Area Result") that the user drags from the problem text onto the formula slots.
*   **Snap & Feedback**: If the user drops the correct value, the card snaps, glows green, and emits a success chime. If incorrect, the card shakes red, and the UI provides a hint.

#### **Step 4: Canvas Simulations & Dynamic Zoom**
*   **Vector Overlays**: Render the downward pressure vectors (arrows) on the soil-footing interface. As the footing size (Area) is calculated and adjusted, the vector density must dynamically scale.
*   **Camera Zoom**: Implement a 150% smooth-scroll zoom effect that focuses specifically on the "Reinforcement/Cover Zone" when the student reaches the cover calculation step. The canvas must highlight the 60mm clear cover boundary in a pulsing red glow.
*   **Section Rendering**: Animate a "Concrete Pour" filling the footing boundary, followed by the appearance of reinforcement bars (glowing steel neon-blue) as the user identifies the steel grade ($f_y$) and depth ($D$).

#### **Step 5: Output Decomposition**
*   Create a side-panel "Capacity Dashboard." Use a stacked bar chart to display the pressure distribution across the footing. 
*   Include a "Verification Check" button that, when clicked, animates the soil pressure profile. If the pressure exceeds 150kN/m², animate the footing sinking slightly into the soil with a warning tone.
