Build a "Steel Connection Playground" as a high-performance HTML5/JS simulation. 

**Aesthetic & Core Framework:**
*   **Theme:** Dark cyber-engineering dashboard. Use neon cyan/magenta/green outlines.
*   **Viewport:** Strict 100vh CSS grid layout; no body scrolling. Use responsive `<canvas>` for all interactive diagrams.
*   **Interaction:** Pointer-based "physics-drag" system. Objects (bolts, I-beams, cover plates) must feel "heavy" with momentum, snapping into precise engineering alignment with magnetic gravitational audio cues.

**Pedagogical Engine (ELI5 + Interactive Engineering):**
*   **Playful Analogies:** Explain beam-to-column connections as "holding hands" where the beam is the arm and the column is the body. Use a "Voiceover Manager" (`window.speechSynthesis`) to narrate friendly, encouraging explanations when elements are dragged correctly.
*   **Soundscape:** Connect interactive sliders (e.g., bolt pitch distance) to Web Audio oscillators. As the user drags a bolt further, the pitch increases in a rhythmic "mechanical click" frequency. 
*   **Interaction Loop:**
    1.  **Identification:** Provide a "Blueprint Checklist" panel. Clicking "Identify Beam" highlights the beam in glowing neon; "Identify Column" highlights the column.
    2.  **Drag-and-Drop Assembly:** Allow users to drag "Bolt Clusters" (M16/M20) from a sidebar onto the connection interface. Successful placement triggers a "satisfying metal-on-metal" chime and locks the bolt in place.
    3.  **Real-Time Physics:** Display dynamic force vectors as semi-transparent arrows. If the connection is a "Pinned" joint, visualize it rotating slightly on the canvas when "Load" is applied (drag a heavy box onto the beam).
    4.  **Equation Graphing:** Display an overlay "Formula Panel" that updates its values live as the user slides the pitch (p) or edge distance (e) parameters.
    5.  **Gamification:** Create "IS 456/800" codebook buttons. Clicking them triggers a "Codebook Unlock" animation, revealing the formula (e.g., strength calculation) required to pass the current challenge.
