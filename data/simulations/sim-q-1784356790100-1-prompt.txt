### Prompt for Gemini: Build "The Lacing Lab" - An Interactive Structural Engineering Simulation

**Role & Objective:**
You are an expert educational software engineer. Your task is to build a high-fidelity, interactive web simulation titled **"The Lacing Lab"** using HTML5, CSS3 (Tailwind/Styled components), and Vanilla JavaScript. This tool is designed to teach Civil Engineering students about Lacing Systems in built-up steel compression members.

**Visual Aesthetic:**
- **Cyber-Engineering Dark Mode**: Use a deep charcoal background (`#0f172a`), translucent "glassmorphism" panels, and glowing neon accents (Cyan for structural lines, Magenta for force vectors, Lime for successful connections).
- **Layout**: Use a `100vh` flex-grid layout. No scrolling; everything must fit perfectly. 

**Simulation Mechanics (The Lacing Lab):**
1. **The Interactive Sandbox**:
    - **Dynamic Column View**: A central 2D canvas showing a built-up column (two channels back-to-back).
    - **Lacing Placement**: Use drag-and-drop to place "Lacing Bars" (flats) from a tool-dock onto the column.
    - **Interactive Gesture**: Implement mouse/touch drag events that allow the user to "sweep" across the column to see it deform or "buckle" under virtual load.
2. **Gamified Elements**:
    - **IS 800:2007 Clause Cards**: Create a "Code Book" side-panel. When the user drags a "Lacing Bar" onto the column, the simulation checks the angle (40°–70°) and pitch. If incorrect, the column glows red; if correct, it snaps into place with a satisfying chime and a "Green Check" pulse.
    - **Parameter Tuning**: Include sliders for `Lacing angle (θ)` and `Pitch (p)`. As the user slides these, a Web Audio API oscillator should dynamically shift the pitch (higher frequency = tighter spacing/higher stress).
3. **Engineering Visuals**:
    - **Real-time Vectors**: Display animated, glowing force arrows representing axial compression and the transverse shear (2.5% of axial load) being transferred by the lacing.
    - **Profile Diagram**: A secondary canvas showing the cross-section (Plan view) vs. the side elevation (Section view), which updates as parts are added.
4. **Educational Pedagogy (The ELI5 Engine)**:
    - **Speech Synthesis**: Utilize `window.speechSynthesis`. When a user interacts with a component, the app should narrate: "Look at how the lacing bars act like a team of friends holding hands to stop the column from wobbling!"
    - **Simplified Analogies**: Display a popup explanation when a "Lacing Bar" is hovered, comparing it to "a ladder that keeps two long sticks from bending apart when you try to squash them."
5. **Technical Constraints**:
    - **No Text-Heavy Sheets**: Absolutely no static paragraphs of theory. Information must be delivered via interactive callouts, tooltips, and dynamic labels that appear only when parts are dragged.
    - **High-DPI Canvas**: Use `requestAnimationFrame` for all animations. Ensure the canvas remains sharp on all screens.
    - **Responsiveness**: All elements must resize relative to the viewport.

**Coding Instructions:**
1. **HTML Structure**: Create a clean grid with a `sidebar` (tools/codebook), `main` (the simulation canvas), and `overlay` (feedback/score).
2. **CSS**: Use fluid animations for the "Concrete/Steel Glow" effect. Ensure buttons have a "bouncy" hover effect.
3. **JS Logic**:
    - Build a state machine to track: `Lacing_Attached`, `Angle_Valid`, `Pitch_Valid`.
    - Implement a `snapToGrid` function for the drag-and-drop system.
    - Create a `playSound(frequency)` function using `AudioContext`.
    - Use `speechSynthesis.speak()` to provide helpful tips based on the user's current progress.

**Specific Implementation Step:**
1. Render the main column as two vertical channels.
2. Create a "Drag Me" button that generates a Lacing Bar at the cursor.
3. If dropped on the column, calculate if the position allows a 45-degree angle.
4. Trigger a "Success" animation (glowing green outlines) if the structural rule is met.
5. Zoom the camera (CSS `transform: scale`) into the connection joint when the lacing is placed successfully to highlight the bolt/weld.

**Final Output Requirement:**
Provide a single-file solution (HTML with internal CSS and JS) that implements this experience. Ensure the tone is playful, encouraging, and visually stunning.
