Act as an expert Educational Software Developer and Prompt Engineer. Your objective is to build a high-fidelity, interactive "Construction Management & Professional Practice" simulation dashboard. 

**STRICT ARCHITECTURAL DIRECTIVE**: You are to generate the code for a web-based, gamified simulation that teaches the "Building Process" and "Building Orientation."

### 1. CORE VISUAL & UI ARCHITECTURE
- **Aesthetic**: Create a "Cyber-Engineering" dashboard. Use dark mode, CSS glassmorphism (translucent panels, backdrop-filter: blur), and neon-accented UI elements (Cyan for Active, Magenta for Selection, Lime for Success).
- **Layout**: Utilize CSS Grid/Flexbox with `100vh` containment. No body-level scrolling. Use a main canvas area flanked by a collapsible "Resource/Tool" sidebar and a "Professional Logic" bottom panel.
- **Canvas Rendering**: Use an HTML5 Canvas to render a dynamic, isometric or orthographic site layout.

### 2. INTERACTIVE MECHANICS (The "Building Process" Simulator)
- **Gamified Workflow**: Build a five-stage drag-and-drop process: *Briefing → Designing → Tendering → Construction → Commissioning*.
- **Interaction**: Users must drag "Activity Cards" (e.g., "Select Project Manager," "Calculate Bill of Quantities," "Site Supervision") onto the correct "Stage Slot." 
- **Feedback**: 
    - **Visual**: Upon a correct drop, trigger a green neon pulse ring and a subtle "Snap" sound effect. 
    - **Physical**: If the user drops an activity in the wrong stage, show a red error vibration (CSS animation) and trigger `window.speechSynthesis` explaining the logic (e.g., "The Tendering process must occur before Construction starts to ensure legal and cost viability.").
- **Dynamic Updates**: As stages are completed, the central canvas should animate the building's growth—from a raw plot of land to a 3D wireframe, then a rendered structure.

### 3. THE "SUN & ORIENTATION" LAB
- **Interactive Compass**: Include a rotatable sun-path dial. Drag the sun icon around the site. 
- **Real-Time Vector Overlays**: As the sun rotates, project "Solar Heat Gain" vectors onto the building facades. If the user places a "Sun Breaker" or "Shading Device" (dragged from the sidebar) onto the facade, watch the heat vectors deflect and the internal temperature graph (using `CanvasRenderingContext2D`) plummet.
- **Dynamic Zoning**: Highlight walls in warm colors (Red for high heat gain) as the sun moves, rewarding the user for correctly orienting rooms.

### 4. MULTIMEDIA & NARRATION
- **Web Audio Engine**: Create a synth-based audio manager.
    - **Success Chime**: Triadic major chord pulse.
    - **Click/Drag**: High-frequency, dampened square-wave blips.
    - **Warning**: Low-frequency oscillating sine wave.
- **Voiceover**: Use `window.speechSynthesis` triggered by hovering over specialized "Concept Nodes" or when completing a project stage. Ensure a clean, professional narrative voice.

### 5. TECHNICAL SPECIFICATIONS
- **Responsiveness**: Implement an observer pattern for the canvas resize events; it must maintain a consistent resolution for high-DPI scaling (use `devicePixelRatio`).
- **Data Logic**: Use a lightweight JS state machine to manage the progress of the five building stages.
- **Assets**: All shapes (rebars, shading devices, building sections) must be drawn programmatically using the Canvas API (no external image dependencies if possible).
- **Smoothness**: Use `requestAnimationFrame` for all transitions and animations (sun movement, building growth, vector shifts).

### 6. REQUIRED MODULES IN CODE
1. `initApp()`: Setup the grid and glass panels.
2. `renderBuildingStage()`: Handles the growth animations of the structure.
3. `handleDragAndDrop()`: Logic for slot snapping and validation.
4. `updateSolarVectors()`: Math-heavy function calculating incidence angles based on sun position.
5. `speakConcept(text)`: Wrapper for `window.speechSynthesis` for the educational narration.

"Create this interactive simulation as a single-file application (HTML/CSS/JS). Ensure the code is production-ready, highly commented, and strictly follows the aesthetic of a high-end engineering laboratory tool. Do not include static text blocks; everything must be revealed through user interaction with the dashboard."
