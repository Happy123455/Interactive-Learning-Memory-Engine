**Prompt for Gemini:**

"Act as an expert Educational Software Architect. Your task is to develop the source code for a highly interactive, web-based simulation module titled **'Climatology: The Solar-Orientation Studio'**. The module is for architectural students to visualize how building orientation (Sun, Wind, Humidity) affects thermal comfort.

### 1. CORE ARCHITECTURAL REQUIREMENTS
*   **The Interface**: Build a 'Cyber-Engineering Studio' dashboard using a dark-mode CSS theme. Use a grid layout (100vh) with a sidebar for parameters and a large, central, interactive canvas. Use glassmorphism panels (translucent blur) and neon-green/cyan accents.
*   **The Canvas**: A 2D top-down floor plan of a house with a rotating 'sun-path' slider. The canvas must support high-DPI scaling and responsive resizing.
*   **Engineering Visuals**: Use HTML5 Canvas to render:
    *   **Sun Rays**: Vector lines representing solar path/intensity.
    *   **Wind Vectors**: Animated particles (or arrows) that change velocity/direction based on user input.
    *   **Thermal Heatmaps**: A dynamic overlay that color-codes the floor plan (blue for cool, red for hot) as the building rotates.
*   **Gamified Drag-and-Drop**: Create a library of 'Environmental Parameter Cards' (e.g., 'Prevailing Summer Wind', 'Harsh Evening Sun', 'Humidity Index'). Users must drag these cards onto specific walls of the building floor plan. 
    *   *Interaction:* When a 'Sun-Breaker' or 'Shading Tree' icon is dropped onto a wall, trigger a visual animation (a projection of a shadow or a cooling gradient) that dynamically alters the 'Thermal Comfort' score.

### 2. DYNAMIC SIMULATION LOGIC
*   **The Solar Engine**: Create a sun-path slider. As the user drags the slider, the 'Sun' object orbits the canvas. The building orientation rotates accordingly. 
*   **Feedback Loops**: Use an internal formula to calculate 'Heat Gain' based on the orientation angle. Display this as a live, pulse-glowing readout. If the heat gain exceeds a threshold, flash the 'Warning' indicators in amber.
*   **Voice & Audio**: 
    *   Integrate `window.speechSynthesis` to provide brief, professional architectural narration when a user drags a component (e.g., 'Optimal orientation minimizes afternoon heat gain.').
    *   Use Web Audio API to play distinct 'snap' chimes on successful placement of structural features and 'low-freq' hums when the climate control fails.

### 3. TECHNICAL CONSTRAINTS
*   **No Clutter**: Do not create static text-heavy exam sheets. All text must be embedded in the interactive elements (e.g., hovering over a wall shows its specific thermal load).
*   **Layout**: Use a `CSS Grid` container. The main view (canvas) takes 80% of the screen, with control panels docked to the right. 
*   **Performance**: Use `requestAnimationFrame` for all animations (shadow casting, wind flow, sun rotation) to ensure fluid motion.
*   **Interactive Checks**: Include a 'Checklist Panel' that tracks: 'Identify Sun Path', 'Orient Primary Living Spaces', 'Mitigate Evening Heat'. These items transition from 'Pending' to 'Done' with a satisfying check-animation.

### 4. STEP-BY-STEP IMPLEMENTATION STEPS
1.  **Skeleton**: Build the `index.html` with a full-screen canvas and the glass-panel dashboard overlay.
2.  **Styling**: Apply the 'Cyber-Engineering' CSS—dark backgrounds, subtle neon glow, and high-contrast typography.
3.  **Engine**: Initialize a JavaScript class to handle the building geometry and the rotation matrix.
4.  **Drag-Interaction**: Implement the drag-and-drop system. Allow dropping 'Sun Breakers' or 'Vegetation' onto the canvas coordinate system.
5.  **Simulation**: Map mouse/slider input to calculate and redraw the shadow vectors and thermal feedback zones.
6.  **Narration**: Attach the `SpeechSynthesis` and Audio triggers to the event listeners of the drag-and-drop actions.

Provide the complete, single-file HTML/CSS/JS solution, ensuring the code is modular, well-commented, and free of any 'exam sheet' mockups."
