Act as an expert Educational Software Developer and Prompt Engineer. Your objective is to create a high-fidelity, interactive, web-based simulation for a Structural Engineering course, focusing on the calculation of the Moment of Resistance for a Doubly Reinforced RCC Beam.

### Technical Requirements & Architecture
Build a single-file HTML/JS application using the Canvas API for visualization, Tailwind CSS for a dark-themed glassmorphic UI, and Web Audio API for synthetic soundscapes.

### 1. Visual Simulation Strategy
*   **Beam Canvas:** Render a 2D cross-sectional view of the beam. Draw a rectangle (b x d) with internal circles representing the reinforcement bars. 
*   **Vector Overlays:** Use a secondary animation layer to draw force vectors (Compressive force C1, C2 and Tensile force T). These must update dynamically as the user modifies beam dimensions or bar diameters.
*   **Real-time Graphing:** Include a small canvas window that plots the Strain Distribution Diagram (linear) and Stress Distribution Diagram (parabolic-rectangular) using a smooth easing animation loop.

### 2. Interactive Elements & Controls
*   **Sidebar Controls:** Provide sliders for `b` (beam width) and `d` (effective depth). 
*   **Drag-and-Drop Interaction:** Allow users to drag the reinforcement bar icons (circles) within the beam canvas to change their position or "click-to-toggle" to change bar diameter (e.g., swapping 25mm for 20mm). 
*   **Live Equations:** Display the Moment of Resistance ($M_u$) formula using MathJax-style rendering. As inputs change, update variables in the equation with glowing text highlights.
*   **State Management:** Every change to a variable must trigger a recalculation function that immediately updates the vector lengths and the plotted stress-strain graphs.

### 3. Sound Design (Web Audio API)
*   **Interaction Feedback:** Use an `AudioContext` with an OscillatorNode (sine wave, 440Hz) for clicking elements and a low-pass filter sweep (rising 200Hz to 800Hz) when a calculation is completed.
*   **Dynamic Response:** Implement a gentle, low-frequency hum (20Hz-60Hz) that increases in amplitude as the "Load" or "Moment" values reach critical design limits, providing visceral feedback on structural stress.

### 4. Narrative Text-to-Speech (TTS)
*   **Narrator Engine:** Implement a `window.speechSynthesis` controller. 
*   **Educational Triggers:** Include a "Narrate Step" button that explains the current mathematical operation being performed (e.g., "Calculating the area of tension steel..."). 
*   **Contextual Help:** As the user hovers over the reinforcement bars, have the narrator speak the reinforcement count and diameter currently selected.

### 5. Diagram Animations & Aesthetics
*   **Aesthetics:** Dark theme (#0f172a), neon cyan (#22d3ee) for interactive components, and neon amber (#fbbf24) for force vectors. Use backdrop-blur glassmorphism for the UI panels.
*   **Mathematics Rendering:** Use `requestAnimationFrame` to interpolate the length of stress vectors smoothly. When the beam is "loaded," apply a subtle CSS scale transform to the beam to simulate deflection.

### 6. Implementation Instructions
*   **Step 1:** Setup the HTML5 layout with a central `<canvas>` for the beam and a glassmorphic sidebar for inputs.
*   **Step 2:** Write the physics logic for calculating $x_u$, $M_{u1}$, and $M_{u2}$ based on the doubly reinforced beam theory (IS 456-2000 standards).
*   **Step 3:** Implement the event listeners for drag-and-drop to update the `d_prime` (effective cover) and `d` (effective depth) values in the logic.
*   **Step 4:** Integrate `window.speechSynthesis` with a queue system so narrations don't overlap.
*   **Step 5:** Finalize with a "Clean UI" pass—ensure all transitions are `ease-in-out` and typography is a clean sans-serif (Inter or Roboto).

**Deliver a complete, single-file HTML solution that allows a student to fully explore the relationship between steel area, beam depth, and the resulting Moment of Resistance.**
