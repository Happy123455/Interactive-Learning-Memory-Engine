Act as a Senior Educational Software Developer and prompt-engineer. Your task is to build a single-file, production-ready HTML/JS/CSS application that simulates a "Battening System for Steel Compression Members." 

The application must be a modern, high-fidelity educational tool designed for an "Elementary Structural Design" course. 

### 1. Visual Simulation Strategy
- Use the HTML5 Canvas API to render a 2D side-by-side view of a Built-up Steel Column. 
- Left Panel: "Plan View" (showing batten plate configuration, bolt positions, and channel spacing).
- Right Panel: "Sectional Elevation" (showing the vertical distance between battens, lacing/batten geometry, and buckling behavior).
- Use `requestAnimationFrame` for a smooth physics loop that demonstrates how altering the batten spacing ($s_c$) or effective length ($L_e$) affects the buckling profile of the column.

### 2. Interactive Elements
- **Sliders**: Create glassmorphic UI inputs for:
    - `Spacing between battens (s_c)`: Dynamically updates the spacing in the 2D sketch.
    - `Column Height (L)`: Changes the visual length of the member.
    - `Load (P)`: Updates the stress intensity vector arrows overlaid on the column.
- **Drag & Drop**: Allow the user to drag the batten plates vertically along the column axis; snap them to engineering constraints (e.g., maximum allowable pitch).
- **Real-time Plotting**: Use Chart.js or a custom Canvas path to plot the Euler Buckling load curve vs. Slenderness ratio ($\lambda$) as the user modifies inputs.

### 3. Sound Design (Web Audio API)
Implement a dedicated `AudioEngine` class using the Web Audio API (OscillatorNodes and GainNodes):
- **Interaction Click**: A soft, high-frequency sine-wave "blip" (440Hz, low attack, exponential decay).
- **Constraint Violation**: If a user sets an invalid spacing (violating design codes), trigger a "low-pass filtered" sawtooth buzz to signal a structural error.
- **Data Update**: A subtle, quiet "click" when sliders move.

### 4. Narrative Text-to-Speech
- Implement a `Narrator` module using `window.speechSynthesis`.
- Add a "Concept Narration" toggle. When enabled, every time a parameter is changed, the browser must read a context-aware description (e.g., "Increasing the batten spacing reduces the moment of inertia, leading to a lower buckling resistance").
- Include a "Guided Tour" button that triggers a sequence of narrations explaining the structural purpose of battens as the camera zooms into specific components.

### 5. Diagram Animations
- **Vector Overlays**: Draw dynamic force vectors ($P$) in bright neon colors. As the user adjusts parameters, animate the vector thickness (strokeWidth) to represent load intensity.
- **Grid Lines**: Draw a faint, interactive grid that recalibrates as the user changes scale.
- **Equations**: Display the governing equation $I_{eff} = I_x + I_y$ on the dashboard. Use a MathJax-like font style; animate the variables dynamically as the user interacts with the column geometry.

### 6. Aesthetics & UI/UX
- **Theme**: Dark mode dashboard with a deep charcoal background (`#0d0d0d`).
- **Accent Colors**: Use neon cyan (`#00f2ff`) for interactive elements and structural highlights; use magenta (`#ff00ff`) for warnings/violations.
- **Styling**: Utilize glassmorphism (backdrop-filter: blur) for the control panels. 
- **Typography**: Use a clean, modern sans-serif font (e.g., 'Inter' or 'Roboto').
- **Responsiveness**: Ensure the canvas scales to maintain aspect ratio on tablet and desktop screens.

### Technical Requirements
- Single HTML file structure: CSS in `<style>`, JS in `<script>`, content in `<body>`.
- No external libraries (or use CDN links for Chart.js/MathJax only).
- Ensure all logic is cleanly commented for educational auditing.
- Include a "Reset Simulation" button that restores default structural parameters.

**Deliver the code with a high focus on clean, modular, object-oriented JavaScript.**
