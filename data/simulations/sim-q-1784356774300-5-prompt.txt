Build an interactive "Bolted Lap Joint Playground" using HTML5 Canvas, GSAP for animations, and Web Audio API. Use a dark, neon-cyber aesthetic (cyan/purple/green glows on black glass backgrounds). 

**1. The Simulation Engine:**
Create a split-screen viewport:
- **Left Panel (Workboard):** A 2D structural workspace with two overlapping steel plates. Users drag physical "Bolt" icons onto the overlap area. 
- **Right Panel (Dashboard):** A vertical stack of translucent glass panels for variables (plate thickness $t$, bolt diameter $d$, load $P$). 

**2. Gamified Mechanics:**
- **Drag-and-Drop Formula Slots:** Create glowing circular drop-zones in the sidebar. When a user drags a value card (e.g., "16mm Bolt") into a target slot, trigger a "snap" animation, a *chime* sound, and a pulsing green ring.
- **Gesture Control:** Implement a mouse-swipe handler across the joint. As the user swipes, the plates "stretch," showing real-time displacement in the UI. If the load $P$ exceeds bolt capacity, the bolts turn bright red, the UI shakes (GSAP `shake`), and a *warning siren* (low-frequency oscillator) plays.

**3. Interactive Figures & Visuals:**
- **Dynamic Drafting:** Use an animation where the plate width and thickness lines grow with a leader line as parameters change. 
- **Bolt Stress Visualization:** As bolts are placed, render translucent force-vector arrows through them. If the load is high, the arrows scale and shift color from green to vibrant magenta.
- **Audio/Voice:** Map the `load` slider to a Web Audio `OscillatorNode` (increase frequency with load). Integrate `window.speechSynthesis` to provide ELI5 narration (e.g., "When we pull these plates, the bolts act like little gatekeepers! Let’s add more to share the load!").

**4. Technical Requirements:**
- Use `requestAnimationFrame` for fluid 60fps physics/dragging.
- Responsive CSS Grid/Flexbox with `100vh` containment; no scrollbars.
- Include a "Codebook" button; clicking it overlays a modal featuring simulated IS 800:2007 clauses that pulse when the correct value is referenced.
