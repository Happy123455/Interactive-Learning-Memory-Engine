Act as a Senior Educational Frontend Developer. Your objective is to build a high-fidelity, interactive "Flexible Pavement Design Lab" using a single HTML file (HTML5 Canvas, CSS3, and Vanilla JavaScript).

### 1. Visual Simulation Strategy
*   **Core Engine:** Use a 2D HTML5 Canvas to render a cross-section of a flexible pavement structure. 
*   **Layers:** Represent the four main layers (Subgrade, Sub-base, Base, and Bituminous/Wearing Course) as stackable, color-coded geometric rectangles.
*   **Visual Fidelity:** Use a layered "depth" effect. When a user hovers over a layer, provide a subtle glowing outline.
*   **Physics Loop:** Implement a requestAnimationFrame loop to manage transitions and hover states.

### 2. Interactive Elements (Drag-and-Drop)
*   **The "Builder" Area:** Create a workspace where layers are initially scattered in a "bin." Users must drag and drop the layers into the correct hierarchical order (from bottom to top: Subgrade → Sub-base → Base → Binder Course → Wearing Course).
*   **Validation Logic:** Upon dropping a layer, check the Y-coordinate. If placed correctly, trigger a "snap" animation with a glowing green pulse. If incorrect, trigger a "reject" shake animation and return to the bin.
*   **Control Panel:** Include a floating Glassmorphic dashboard on the right with a "Reset Simulation" button and "Analyze Forces" toggle.

### 3. Diagram Overlays & Real-time Plotting
*   **Vector/Force Overlay:** When "Analyze Forces" is toggled, draw dynamic downward-pointing arrows (vectors) representing load distribution (Boussinesq’s theory).
*   **Plotting:** Below the pavement section, include a small area that graphs the "Stress Distribution Curve" in real-time. As the user moves a "Load Point" slider horizontally across the surface, update a line graph to show the dissipation of vertical stress as depth increases.

### 4. Sound Design (Web Audio API)
Use the Web Audio API to create native feedback loops (no external assets):
*   **Snap Success:** A short, low-frequency 220Hz sine wave "pluck" with a fast decay.
*   **Error:** A dual-tone 110Hz/100Hz "buzz" oscillator for 100ms.
*   **Interaction:** Soft 440Hz "click" sounds for UI button presses.
*   **Ambient:** A very low volume, low-pass filtered white noise (simulating a lab environment).

### 5. Narrative Text-to-Speech (TTS)
*   **Voiceover Engine:** Implement a `speak(text)` function using `window.speechSynthesis`.
*   **Interactive Narration:** Every time a student successfully places a layer, the app should narrate a brief definition of that layer (e.g., "Correct! The Wearing Course provides a smooth, skid-resistant surface.").
*   **Narrate Button:** Add a "Narrate Lesson" button that walks the user through the function of each pavement layer in sequence.

### 6. Aesthetics & UI/UX
*   **Design Language:** Dark-themed dashboard (Background: #0a0a0c). Use neon cyan and electric violet for accent lines and text.
*   **Glassmorphism:** Control panels must use `backdrop-filter: blur(10px)` with a semi-transparent dark background (`rgba(255, 255, 255, 0.05)`).
*   **Typography:** Use a clean, modern sans-serif font (e.g., 'Inter' or 'Roboto').
*   **Mathematics:** Render the stress distribution equation using clean CSS styling or a simple Canvas text layout overlaying the graph area.

### Technical Requirements for the Generator:
*   Ensure the code is self-contained in one file.
*   Use standard ES6 JavaScript.
*   Include a status notification toast at the top center for interaction feedback.
*   Ensure smooth transitions using `transition` properties for CSS and `linear interpolation` for Canvas animations.
