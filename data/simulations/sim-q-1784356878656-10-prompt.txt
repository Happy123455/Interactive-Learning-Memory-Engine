Build a high-fidelity, interactive HTML/JS simulation titled "Solar Orientation & Architectural Comfort Lab." The simulation must function as a professional-grade engineering dashboard with a "Cyber-Engineering" aesthetic: dark backgrounds, translucent glass-morphism panels, and neon-accented UI elements (Cyan/Purple/Green).

### 1. Visual & Structural Layout
*   **Viewport**: Utilize a 100vh flex-box grid. The layout must have a fixed sidebar for tools/parameters and a large, high-DPI HTML5 Canvas for the simulation.
*   **The "Solar Lab" Canvas**: Render a 3D-perspective "Building Footprint" in the center. Allow users to rotate this building block using mouse-drag.
*   **Dynamic Visualizations**: 
    *   **Sun Arc**: An overhead glowing arc representing the sun’s path. 
    *   **Vector Overlays**: Project vibrant, animated lines of solar radiation (yellow rays) onto the building surfaces. 
    *   **Thermal Heatmap**: Apply a real-time GLSL shader that turns building walls from cool blue (shade) to hot red (direct exposure) based on the sun's position.

### 2. Core Gamified Mechanics
*   **Interactive Sun Manipulator**: A draggable "Sun Disk" on the solar arc. As the user drags the disk (Morning to Evening), the time-of-day clock updates, and the building’s shadow/heat maps update in real-time.
*   **Drag-and-Drop Shielding**: Provide a "Tool Tray" containing shading elements: *Vertical Fins, Horizontal Louvers, and Deciduous Trees*.
*   **The "Snap-to-Wall" Logic**: Users drag these elements and drop them onto specific building facades. Upon dropping, the shader must recalculate the shadow mask on the building wall immediately.
*   **Constraint Checklist**: Display a persistent floating dashboard with the "Observations of Sun" checklist (Morning, Noon, Evening). As the user drags the sun into these zones, the items automatically tick from "Pending" to "Analyzed" with a glowing green checkmark.

### 3. Engineering Data & Feedback
*   **Real-time Graphing**: Include an integrated Chart.js or D3 canvas panel showing "Indoor Temperature vs. Orientation Angle." This graph must redraw instantly as the user rotates the building or moves shading devices.
*   **Formula Logic**: Create "Formula Slots" where the user must drag numerical values (e.g., Latitude, Wall Surface Area, Solar Intensity) from the environment into a live equation: `Total Heat Gain = (Intensity × Area) - Shading Efficiency`. 
*   **Camera Zooms**: On specific "Analysis Trigger" events (e.g., when the sun hits the "Noon" position), trigger a 150% smooth-scroll zoom into the window/shading junction, highlighting the intensity of radiation in bold red.

### 4. Audio & Narration
*   **Web Audio Synthesis**: Implement a subtle "binaural" ambient drone. Use synth beeps for successful "Snap" events and a low-frequency warning tone if the heat gain exceeds safety thresholds.
*   **Speech Synthesis**: Integrate `window.speechSynthesis` to provide academic context. When a student drops a "Horizontal Louver" onto a wall, trigger a narration: *"Horizontal louvers are recommended for South-facing walls to mitigate peak noon solar intensity."*

### 5. Technical Requirements
*   **Responsive Engine**: The canvas must resize to fit the parent container using `window.addEventListener('resize')` and `requestAnimationFrame`.
*   **Aesthetics**: Use CSS `backdrop-filter: blur(15px)` for all panels. Elements must have glowing neon borders. Use a clean, sans-serif, high-contrast font (Inter or Roboto).
*   **No Clutter**: Do not include static textbook text. Every piece of info must be embedded within the interactive tooltips, the dynamic charts, or the speech-synthesized narration.

### 6. Interaction Flow
1.  **Stage 1 (Identification)**: The user identifies the "Sun's Path" by scrubbing the sun arc.
2.  **Stage 2 (Analysis)**: As the user scrubs, the heatmap highlights areas of discomfort.
3.  **Stage 3 (Correction)**: The user selects shading devices from the inventory and drops them on the "hot" zones.
4.  **Stage 4 (Validation)**: The formula panel updates, showing the reduction in "Total Heat Gain," triggering a chime sound and a "Climate Optimized" verification seal.
