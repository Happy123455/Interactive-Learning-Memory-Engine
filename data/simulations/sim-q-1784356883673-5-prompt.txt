### Prompt for Code Generation: Architectural Space-Making Simulation

**Objective:** Create a high-fidelity, interactive web-based simulation using HTML5 Canvas, CSS3, and Vanilla JavaScript (ES6+). The simulation must demonstrate two core "Elements of Space Making": **1) Color (Spatial Perception)** and **2) Enclosure and Boundaries (Spatial Definition)**.

---

### 1. Visual Strategy & Layout
*   **Aesthetic:** Utilize a "Cyber-Architect" dark theme: background `#0f172a`, glassmorphic control panels (`rgba(255, 255, 255, 0.05)` with `backdrop-filter: blur(10px)`), and neon-accented borders. Use a clean, geometric sans-serif font (e.g., 'Inter').
*   **Scene Structure:** Divide the screen into two main canvases:
    *   **Canvas A (Color):** A 3D-perspective-projected room interior that updates in real-time based on color temperature inputs.
    *   **Canvas B (Enclosure):** A 2D top-down plan view where users can drag wall segments to define boundaries.

### 2. Interactive Components
*   **Color Module:**
    *   **Controls:** A slider for "Color Temperature" (Kelvin scale) and "Saturation."
    *   **Effect:** Update the CSS variables of the room rendering. Show a real-time "Spatial Expansion/Contraction" indicator (e.g., a dynamic text overlay showing "Perceived Depth: High/Low").
*   **Enclosure Module:**
    *   **Drag-and-Drop:** Allow users to grab corners of an enclosure (a rectangle/polygon) and stretch them.
    *   **Vector/Force Overlays:** When edges are manipulated, display animated dashed vector lines representing "Sightlines" and "Movement Flow."
    *   **Dynamics:** As the user shrinks the enclosure, animate an "Anthropometric Scale" indicator that changes from "Comfortable" to "Claustrophobic."

### 3. Real-Time Math & Diagrams
*   **Equation Plotting:** Create a floating overlay graph that plots "Surface Area vs. Occupant Comfort" using a simple decay curve ($y = 1/x$). Use `requestAnimationFrame` for smooth, high-frame-rate rendering.
*   **Diagrams:** As edges move, calculate and display the area in real-time ($A = L \times W$). Draw coordinate markers that snap to a grid.

### 4. Web Audio API (Native Synthesis)
*   Implement a `SynthService` using the Web Audio API.
*   **Interaction Sounds:** 
    *   **Hover:** Low-pass filtered pulse (`OscillatorType: 'sine'`) at 220Hz.
    *   **Drag:** Subtle white-noise grain or low-frequency sweep triggered on `mousedown` and modulated by `mousemove` speed.
    *   **Snap-to-Grid:** A resonant 440Hz beep (short decay) triggered when an edge snaps to a unit.

### 5. Text-to-Speech (TTS) Integration
*   **Narrate Button:** Add an "Explain Concept" button for both modules.
*   **Functionality:** Utilize `window.speechSynthesis`. When triggered, it should read:
    *   *Color:* "Cool colors expand the perception of depth, while warm colors create a sense of intimacy and contraction."
    *   *Enclosure:* "Boundaries define the transition from void to mass. Adjusting these parameters directly impacts spatial hierarchy and user circulation."
*   **Auto-Trigger:** Provide an option to "Auto-Narrate" when a user hovers over a new UI element.

### 6. Technical Requirements
*   **Framework:** Pure Vanilla JS (No libraries like jQuery or React; utilize standard DOM APIs).
*   **Math Rendering:** Use standard HTML5 Canvas `arc()` and `lineTo()` methods for high performance.
*   **Responsive:** Ensure the interface is fully responsive, using CSS Grid and Flexbox for the sidebars.
*   **Code Structure:**
    *   `App.init()`: Initializes state and audio context.
    *   `PhysicsEngine`: Handles the boundary drag logic.
    *   `Renderer`: Handles the Canvas 2D/3D drawing loop.
    *   `AudioEngine`: Manages Web Audio nodes (Gain, Oscillator, Context).

### 7. Deliverable Instructions
*   Provide a single `index.html` file containing CSS and JS.
*   Use standard `<canvas>` for the visuals.
*   Ensure all colors are defined as variables at the top of the CSS block for easy thematic adjustments.
*   Include clear, commented code explaining how the "Theory of Architecture" concepts (as defined in the unit notes) are mapped to the interaction logic.
