**PROMPT FOR CODE GENERATOR:**

**Role:** Act as a Senior Educational Software Architect and Lead Frontend Engineer specializing in high-fidelity STEM simulations.

**Objective:** Develop a single-file, interactive HTML/JS simulation for "Highway Maintenance Objectives" within a premium, dark-themed cyber-engineering dashboard. The goal is to transform abstract theoretical concepts into a tangible, gamified "Road Health Inspector" sandbox.

**UI/UX Aesthetic Requirements:**
1. **Dashboard:** Use a CSS `display: grid` or `flex` layout, 100vh height, zero-scroll container. High-contrast dark theme (slate/obsidian backgrounds) with glowing neon borders (Cyan for data, Purple for UI, Green for active/success).
2. **Glassmorphism:** All panels must use `backdrop-filter: blur(10px)` with semi-transparent dark backgrounds.
3. **Animations:** Use GSAP or CSS `transition/keyframe` animations for smooth structural drawing, glowing pulsing indicators, and fluid parameter transitions.

**Functional Simulation Mechanics:**
1. **Interactive Canvas (Road Health Inspector):**
   - Provide a dynamic 2D canvas depicting a highway cross-section or top-down road segment.
   - Implement "Damage Hotspots" (potholes, rutting, cracking) on the road surface.
   - **Drag-and-Drop Maintenance:** Create a library of "Maintenance Tool Cards" (e.g., Pothole Filler, Crack Sealer, Resurfacing Unit). Users must drag these icons directly onto the road damages.
   - **Visual Feedback:** Upon a successful drop, trigger a "repair animation" (e.g., filling a pothole) accompanied by a Web Audio chime.

2. **The "Objectives" Slot Puzzle:**
   - Instead of a text-based list, represent the "Objectives of Highway Maintenance" (e.g., Retaining Serviceability, User Safety, Asset Value Protection, Structural Integrity) as floating draggable "Objective Chips."
   - Create a central "Maintenance Hub" target area. Users must drag the correct chips into the Hub to "activate" the corresponding maintenance feature on the canvas.
   - **Success State:** Once all objectives are sorted, the road section undergoes a high-fidelity visual update (brightness increase, crack removal, glow effect).

3. **Dynamic Data & Engineering Visuals:**
   - Implement an overlay HUD that displays real-time "Health Percentages" for the highway section.
   - Use a dynamic canvas graph (Chart.js or custom path drawing) that plots "Serviceability Index vs. Time," updating live as the user applies repairs.
   - Use SVG-based force/stress vectors if the road shows deformation.

4. **Interactive Pedagogy (Audio/Voice):**
   - **Concept Narration:** Trigger `window.speechSynthesis` when a user drops an objective chip into the Hub, narrating the importance of that specific maintenance objective.
   - **Audio Feedback:** Integrate `AudioContext` to trigger frequency-modulated beeps for drag start, successful snap, and "system error" (if a tool is used on the wrong damage type).

**Code Constraints:**
- **Zero Clutter:** No textbooks, no static exam papers, no solution sheets. The screen must feel like an interactive cockpit.
- **Responsive Canvas:** Use `ResizeObserver` to ensure the canvas scales perfectly without distortion on window resizing.
- **Clean Architecture:** Use standard HTML5, CSS3, and ES6+ Vanilla JavaScript. Keep all styles in a `<style>` block and logic in a `<script>` block.
- **High DPI:** Ensure the canvas context `getContext('2d')` accounts for `window.devicePixelRatio` for sharp rendering on retina displays.

**Pedagogical Integration:**
- Ensure the user understands that *Maintenance* = *Protection of Capital Investment* + *Traffic Safety* + *Economic/Social Connectivity*. The simulation must implicitly reward the user for choosing the "preventative" maintenance route over the "reactive" route via a scoring multiplier in the UI.

**Task:** Build the complete simulation in a single file following these specifications. Start with a "Mission Briefing" glass panel that prompts the user to "Initiate Road Maintenance Protocol."
