Act as a Lead Educational Developer and Creative Technologist. Your goal is to generate a high-fidelity, single-file HTML/JS simulation (using Tailwind CSS for styling and P5.js for visual rendering) that serves as an interactive study tool for a University Architecture Exam.

### **Core Objective**
Create a thermodynamic simulation comparing **Indian Passive Cooling** (Courtyards/Jalis) vs. **Western Thermal Envelopes** (High-insulation/Compact). The simulation must function as a dynamic bridge between exam theory and quantitative calculation.

### **Technical Requirements**
1.  **Frameworks**: Use Tailwind CSS (CDN) for UI, P5.js for the simulation canvas, and the Web Speech API for narrations.
2.  **Layout**: 
    - **Sidebar (Left)**: "Exam Writing Guide" (Markdown-formatted text explaining the step, formulas, and how to structure the answer).
    - **Main (Center)**: "Thermodynamic Canvas" (P5.js animation visualizing airflow (venturi effect) in a Jali/Courtyard vs. heat-loss simulation in a Western envelope).
    - **Dashboard (Right)**: "Input/Output Transfer Control."
3.  **Interactivity**:
    - **Sliders**: Controls for 'Ambient Temp', 'Humidity', and 'Wall Material/Thermal Mass'.
    - **Toggle**: Switch between "Indian Passive Strategy" and "Western Active/Envelope Strategy" to see live thermodynamic changes.

### **Instruction Prompts for the Model**

**Step 1: UI/UX Construction**
*   Create a dashboard with an **"Input Panel"** where students can see values (e.g., Temperature Delta, Thermal Conductivity of materials).
*   Add a **"Calculation Engine"** that calculates real-time efficiency scores (e.g., "Passive Cooling Potential" vs "Heat Retention Index").
*   Implement a **"Glowing Output Box"** that displays the final calculated values for the exam answer, with a "Copy to Clipboard" feature that formats the text for an exam-style response.

**Step 2: P5.js Visualizations**
*   **Indian Simulation**: Use moving particle vectors to represent wind flowing through a 'Jali' (accelerating air) and rising air in an 'Internal Courtyard' (stack effect).
*   **Western Simulation**: Use color-gradient overlays (Red for heat, Blue for cold) to show thermal insulation effectiveness in a compact volume.
*   The visual must change dynamically as the user adjusts the 'Thermal Mass' slider.

**Step 3: Web Audio & Speech**
*   Implement a `window.speechSynthesis` function. Create a "Narrate Exam Strategy" button. When clicked, it should read the exam-specific advice for Step 4 provided in the source text.
*   Use the `AudioContext` to trigger subtle sound cues: a "woosh" (wind) when wind speed increases in the Jali model, and a "low hum" when thermal mass is high.

**Step 4: Exam Solution Format Logic**
*   Inside the "Exam Writing Guide" panel, ensure the following template is shown:
    *   **Title**: Climatic Adaptation and Passive Design Strategies.
    *   **Logic**: [Formula/Equation display].
    *   **Application**: A text-box that generates a synthetic exam paragraph based on the simulation state (e.g., "Given a High Thermal Mass value of X, the Indian Courtyard strategy results in a Y% reduction in indoor peak temperature...").

### **Interaction Constraints**
*   **Persistent State**: Use `localStorage` to ensure if the user refreshes, the data from "Step 3" remains in the Input Panel.
*   **Design**: The aesthetic must be "Academic Minimalist"—dark mode with high-contrast text and architectural blue/grey accents.
*   **Responsiveness**: The app must be fully responsive, readable on tablets and desktop browsers.

### **Final Instruction for the Developer**
"Ensure the generated code is a single, clean `.html` file that is copy-paste ready. Include clear comments in the JS explaining where the user can modify the physics parameters for the thermodynamics. The tool must serve as a bridge between the provided theory notes and the required quantitative exam output."
