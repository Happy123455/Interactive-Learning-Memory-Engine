"You are an expert educational software developer. Your task is to build a highly interactive, gamified simulation in a single HTML/JS/CSS file that teaches the concept of **'The Role of the Sun in Architectural Orientation'**. 

### 1. Visual & Aesthetic Framework
- **Theme**: Cyber-engineering dark dashboard. Use a deep charcoal `#121212` background, translucent glassmorphism panels, and neon accents (Cyan for solar rays, Amber for heat, Emerald for optimal ventilation).
- **Layout**: Use CSS Grid/Flex to ensure a 100vh, non-scrolling workspace. The dashboard must feature a 'Simulation Stage' (canvas) on the left, a 'Control Deck' for parameters on the right, and a 'Narration/Status Bar' at the bottom.
- **Responsiveness**: Use high-DPI scaling for HTML5 Canvas and fluid containers.

### 2. Core Simulation Mechanics
- **The Solar Orbit Engine**: Render a 2D top-down and isometric view of a model building on a central grid. Include a 'Sun' slider that moves along a circular path (representing sunrise to sunset) and a seasonal slider (Solstice/Equinox).
- **Dynamic Solar Rays**: Draw real-time, semi-transparent vector lines (rays) projecting from the Sun toward the building. Use blending modes (screen/overlay) to make them look like glowing light beams.
- **Heat/Light Heatmaps**: As the Sun moves, apply a procedural CSS heatmap overlay on the building walls/floor plan—pulsing red/orange for 'Intense Heat' (Noon) and soft yellow for 'Pleasant Light' (Morning).
- **Interactive Drag & Drop**:
    - Provide 'Sun Breaker' (fin/louvers) and 'Shady Tree' cards in a side toolbox.
    - User must drag these items onto the building’s East, West, or South facades.
    - Upon dropping, the 'heatmap' on the interior wall must dynamically update to show reduced solar gain (colors shifting from red to cool blue).

### 3. Engineering & Pedagogy Logic
- **Interactive Parameters**: Include clickable UI labels for (Solar Altitude, Azimuth, Wind Path, Heat Gain). Clicking a label triggers a `window.speechSynthesis` narration explaining that specific term based on the provided course notes.
- **Vector Overlays**: Toggle a 'Force/Flow' button that draws animated arrows showing convective airflow (Ventilation Support) based on internal temperature differentials caused by the sun.
- **Gamification**: Introduce a 'Comfort Goal' meter. If the internal temperature/light levels exceed the comfort threshold due to poor orientation, trigger a warning tone and highlight the wall in 'Danger Red'.

### 4. Technical Constraints
- **Audio**: Use `Web Audio API` to trigger subtle, high-quality synth chimes when a 'Sun Breaker' is successfully placed. Use low-pass filtered 'humming' sounds that increase in pitch as the sun reaches its zenith (noon).
- **Canvas Drafting**: When a user selects a wall, animate a zoomed-in cross-section showing wall thickness and sun-angle interception. Use sharp, technical line styles.
- **Constraint Checklist**: Include a 'Learning Checklist' panel (Pending/Completed). As the user interacts with the sun and sees the effects, tick off items like 'Morning Sun Benefits', 'Noon Heat Management', and 'Evening Slanting Ray Effects'.

### 5. Implementation Instructions
- Do NOT include text-heavy exam sheets or static paper-based layouts. 
- All data must be represented via visual interactions (e.g., if explaining 'Bactericidal Properties', visualize it as a 'Cleanliness' stat that increases as light hits a surface).
- Build the logic to handle window resize events to keep the grid perfectly aligned.
- Use modular JavaScript; ensure the simulation logic is separated from the UI rendering for smooth 60fps animations.

**Your Goal**: Create a sandbox where the user feels like a lead architect manipulating environmental variables to optimize building performance. Begin by initializing the canvas with a default orientation and wait for the user to start dragging solar assets."
