**System Prompt: Interactive Professional Roles & Building Lifecycle Simulation Builder**

**Objective:**
Build a high-fidelity, interactive, web-based simulation environment that visualizes the "Role of Other Professionals in Building." The environment must function as a professional, cyber-engineering dashboard. Use HTML5 Canvas, GSAP for animations, and Web Audio API for feedback.

---

### **1. Core Simulation Architecture (Dashboard UI)**
*   **Aesthetics:** Dark-mode "Cyber-Engineering" interface. Use a high-contrast palette (Deep Obsidian background, Cyan/Neon-Green/Electric-Purple highlights). 
*   **Layout:**
    *   **Center Stage:** A dynamic 2D grid/canvas showing a "Live Building Site" cross-section.
    *   **Side Panels:** "Professional Asset Panel" (draggable icons/cards representing roles) and a "Project Requirement Log."
    *   **Translucent Glassmorphism:** All UI panels must be blurred translucent glass layers.

### **2. Interaction Mechanics: The "Collaborative Load" Simulation**
*   **Asset Drag & Drop:** Create "Professional Cards" (Soil Scientist, Surveyor, Structural Engineer, etc.). The user must drag these cards into the center canvas onto specific active zones of a building schematic.
    *   *Example:* Drag "Structural Engineer" to the beam-column joint to trigger a 150% camera zoom and display reinforcement calculation vectors.
    *   *Example:* Drag "Soil Scientist" to the foundation base to see a soil-bearing capacity graph update.
*   **Snap-to-Slot Logic:** When a card is dropped into a valid zone, trigger:
    *   **Visual Feedback:** The specific building component (e.g., the foundation or the rebar) glows and displays a "Validated" pulse.
    *   **Sound Feedback:** Use Web Audio API to play a clean, harmonic chime (Success) or a low-frequency hum (if placed incorrectly).
    *   **Speech Synthesis:** `window.speechSynthesis` must announce the role’s contribution (e.g., "Structural Engineer identified: Ensuring load stability and reinforcement integrity").

### **3. Dynamic Visualizations (The "Expert" Style)**
*   **Vector Overlays:** Upon placing the "Structural Engineer" or "Mechanical Engineer," draw animated vector lines showing force paths (cyan) or airflow/plumbing flow (purple) across the canvas.
*   **Live Equations:** When a role is placed, render a floating, elegant mathematical expression related to their field (e.g., Load = Weight/Area) using CSS-styled typography.
*   **Growth/Drafting Animations:** Use staggered line drawings to "build" the component on screen when the correct professional is placed.

### **4. Gamified Logic & Feedback**
*   **Problem/Checklist Tracker:** A sidebar checklist that tracks: "Professional Identification Status." Pending items are grayed out; identified items turn vibrant neon-green with a completion tick.
*   **Codebook Integration:** Create a "Reference Portal" icon. Clicking it opens a virtual, draggable digital sheet containing clauses relevant to the specific professional role being analyzed.
*   **Capacity Visualizer:** If the user identifies all professionals, unlock a "Project Readiness" bar chart showing the sum of structural, mechanical, and architectural progress.

### **5. Technical Specifications for the Model**
*   **Canvas Grid:** Always maintain a crisp, coordinate-based grid.
*   **Camera Controls:** Implement programmatic zoom-and-pan. When a component is clicked/engaged, the camera should smoothly pan to that node, zoom to 150%, and highlight the area with a bold red bounding box.
*   **Accessibility:** Ensure every simulation step has `aria-label` tags for screen readers, and speech narration is clear and paced for an educational setting.
*   **Constraint:** Do NOT include textbook text boxes or copy-paste content blocks. Every piece of information must be conveyed through the interaction (hover-over tooltips, animated callouts, or speech synthesis).

---

**Instruction to the model:**
"Develop the simulation as a single-page application. Structure the code with CSS variables for the color palette, a central JavaScript object for managing the 'Professional Role' state, and a robust function for the Drag-and-Drop collision detection. Prioritize fluid motion (GSAP) and immersive, high-tech aesthetics."
