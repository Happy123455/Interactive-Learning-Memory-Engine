**PROMPT FOR CODE GENERATOR (GEMINI)**

**ROLE:** Act as an Expert Interactive Educational Developer and UI/UX Designer.
**TASK:** Develop a high-fidelity, single-file HTML/JS interactive simulation representing the "Indian Institute of Architects (IIA)" within the context of the Architecture Profession.

**CORE DIRECTIVE:** 
Build a "Professional Ecosystem Dashboard." This is NOT a text reader. It is a drag-and-drop workspace where students manipulate professional bodies and architectural stakeholders to understand their functions and relationships.

**TECHNICAL SPECIFICATIONS:**
- **Viewport:** 100vh, 100vw, CSS Grid/Flex layout, fluid canvas resizing.
- **Theme:** "Cyber-Engineering Dark Mode" (Deep charcoal backgrounds, neon cyan/purple accents, glassmorphism blur filters on UI panels).
- **Sound:** Use `window.speechSynthesis` for concept narration on interaction and `Web Audio API` (OscillatorNode) for UI feedback (e.g., successful drops = high-frequency chime, invalid drops = low-frequency thump).

**BUILD REQUIREMENTS:**

1. **The Interactive "Body" Workspace (Canvas & UI):**
   - **Central Panel:** A dynamic canvas displaying a map of the "Architectural Ecosystem." 
   - **Draggable Elements:** Create "Data Cards" for the Indian Institute of Architects (IIA), Council of Architecture (COA), and NASA India. Each card contains specific metadata (e.g., "Founded: 1917," "Members: 124,000," "Headquarters: Mumbai").
   - **Interaction Logic:** Provide three "Logic Slots" on the canvas: [Regulation], [Professional Networking], and [Student Engagement].
   - **Goal:** Students must drag the IIA, COA, and NASA cards into their correct functional slots. 
   - **Dynamic Response:** On a correct drop:
     - The slot glows green with a pulsing animation.
     - A Web Audio "Success" chime plays.
     - `speechSynthesis` triggers a short, professional explanation of that body’s role.
     - The canvas draws a glowing vector connection line between the body and its function.

2. **Structural Engineering Style Guide (Applied to Professional Bodies):**
   - **Checklist Progress Bar:** A "Professional Alignment Checklist" at the top right that transitions from "Pending" to "Verified" as cards are placed correctly.
   - **Parameter Highlights:** Hovering over the IIA card should trigger a "Data X-Ray," where the card expands to show sub-affiliations (UIA, CAA, SAARCH) with glowing connection nodes.

3. **Gamification & UX:**
   - **Constraint:** Use a physics-based snap-to-slot mechanism for drag-and-drop.
   - **Feedback:** Use `requestAnimationFrame` for smooth 60fps animations of the cards moving and the connection lines growing/morphing.
   - **Visual Polish:** Ensure "Glass Panels" provide a translucent backing for text, using `backdrop-filter: blur(10px)`.

4. **Interactive "Concept Narration" System:**
   - On clicking any placed card, trigger a "Deep Dive" mode: The canvas zooms into that specific element (e.g., IIA), dimming the rest of the workspace and displaying a modal overlay with the specific source notes provided (e.g., "1,24,000 members," "Associated with UIA/CAA").

5. **Code Architecture Constraints:**
   - **Single File:** Everything in one HTML file (CSS in `<style>`, JS in `<script>`).
   - **Robustness:** No external dependencies—use vanilla JS for canvas drawing and state management. 
   - **Responsive:** Ensure the UI scales across resolutions using `vw/vh` units and a resize event listener to recalibrate the canvas coordinate system.

**DELIVERY INSTRUCTIONS:**
- Start the simulation with a clean, cinematic "Initialization" sequence (fade-in of the dark dashboard).
- Include an "Info" button that triggers a brief `speechSynthesis` summary of the exercise.
- Avoid all "textbook" formatting; represent all data visually as nodes, cards, or interactive vectors.
