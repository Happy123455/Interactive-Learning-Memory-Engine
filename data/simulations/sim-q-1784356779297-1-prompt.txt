Build a 100vh, full-screen interactive web simulation for **"Welding Types & Symbols"** using a playful, neon-cyber sandbox aesthetic.

### **1. Core Visual Mechanics**
*   **The Workbench:** A dark, translucent glass dashboard.
*   **The "Toy" Simulator:** Create a "Welding Lab" where users drag steel plates onto a central jig.
*   **Interactive Welding:** Users select a weld type (Fillet, Butt, Slot, Plug) from a "Toolbox" menu. Upon dragging the tool to the steel joint, initiate a **"Pour & Glow" animation**: vibrant, pulsing orange/white plasma particles follow the cursor path, simulating the melt pool.
*   **Real-time Symbols:** As the user "welds," a floating "Welding Symbol" card (tail, arrow, weld symbol) dynamically generates and tracks the cursor, explaining the notation (e.g., arrow side vs. other side) through an animated callout.

### **2. Gamification & Physics**
*   **EL5 Analogies:** When a user clicks a weld type, the `window.speechSynthesis` narrates: *"Imagine this weld is like super-strong sticky glue for metal! Watch it glow as we melt the edges together!"*
*   **Audio Synthesis:** Connect a Web Audio Oscillator to the weld-path speed. Moving the mouse faster increases the pitch (a high-frequency "hiss"), while slower movement produces a deeper, lower-pitched buzzing arc. 
*   **Gesture Interaction:** Implement `pointermove` event listeners. Sweeping the mouse quickly across the joint "fuses" it; a successful fusion triggers a bouncy, cheerful "Ding!" and a green halo effect.

### **3. Educational Overlay**
*   **Checklist Component:** A neon-lit "Mission Log" tracks: [ ] Identify Weld Type, [ ] Draw Symbol, [ ] Validate Strength.
*   **Dynamic Zoom:** Upon "completing" a weld, the canvas zooms (150%) into the cross-section to show the Heat Affected Zone (HAZ) and fusion depth, with labeled force vectors.
*   **Codebook Library:** Add a clickable "IS 800" book icon. When clicked, it renders an overlay of the relevant welding clause, allowing users to drag specific notation parameters onto their digital drawing for verification.

**Tech Stack:** HTML5 Canvas (high-DPI), GSAP for smooth motion, Web Audio API, and Native Speech Synthesis. Ensure strict flexbox layout to prevent scrollbars.
