You are a lead interactive simulation developer. Your objective is to build a high-fidelity, gamified, and responsive web-based simulation titled "The Architect’s Command Center." This tool will teach students the "Role of an Architect in the Built Environment" through a professional-grade, cyber-engineered dashboard.

### 1. CORE VISUAL IDENTITY
*   **Design Language**: Cyber-Engineering Dark Theme. Use CSS glassmorphism (translucent, blurred backdrops), deep charcoal backgrounds (#0f111a), neon cyan (borders/active states), and soft purple (data callouts).
*   **Layout**: A split-screen environment. 
    *   **Left Panel (The "Mission Brief")**: A scrolling, interactive checklist of the Building Process (Briefing → Designing → Tendering → Construction → Commissioning).
    *   **Right Panel (The "Construction Canvas")**: A 2D HTML5 Canvas acting as the structural simulation workspace.
    *   **Footer**: A command ribbon for triggering narration and sound effects.

### 2. INTERACTIVE MECHANICS
*   **Drag-and-Drop Professional Synergy**: 
    *   Create a "Professional Toolkit" tray containing circular icons representing different stakeholders (Soil Scientist, Lawyer, Structural Engineer, Quantity Surveyor, Builder, Architect).
    *   **Action**: When a user drags a professional onto the "Construction Canvas," the simulation must react dynamically. For example, dragging the "Structural Engineer" onto a wall segment should trigger a glowing force-vector overlay (arrows showing load distribution) and a brief `window.speechSynthesis` audio explaining their role in stability.
*   **The "Building Process" Workflow**:
    *   Create a horizontal timeline. Users must drag and drop "Stage Cards" (e.g., "Feasibility Report") into the correct sequence. 
    *   **Validation**: If placed correctly, the UI should emit a harmonic "success" chime (Web Audio API synth) and the card should lock with a green neon ring. If incorrect, a warning red pulse and a low-frequency "error" beep.

### 3. ADVANCED SIMULATION FEATURES
*   **Orientation Visualizer (Sun & Wind)**:
    *   Implement a central, rotating building wireframe on the canvas. 
    *   Provide two "Environment Sliders": Sun Path (Time of Day) and Wind Direction. 
    *   As the sun moves, cast real-time, translucent geometric shadows across the building massing. Use a "Heat Overlay" (gradient blue-to-red) on walls to show solar gain intensity.
*   **Elements of Design Lab**:
    *   Provide a library of geometric shapes (Positive/Negative space). Allow the user to drag these onto the canvas to form a composition. 
    *   Include "Toggle Overlays" (buttons) that reveal lines of force, value gradients (light/dark mapping), and textural overlays.

### 4. NARRATION & AUDIO
*   **Speech Integration**: On every major interaction (e.g., placing the "Architect" icon), trigger `window.speechSynthesis` to read a concise, professional summary of that professional’s role based on the provided source text.
*   **Audio Feedback**:
    *   Success: 440Hz Sine wave, short duration.
    *   Error: 110Hz Sawtooth wave, subtle "thud" effect.
    *   Navigation/Action: Gentle "click" white-noise burst.

### 5. TECHNICAL CONSTRAINTS
*   **Canvas Grid**: Implement a subtle background dot-grid on the canvas to represent precision drafting paper.
*   **Responsive UI**: Ensure the canvas and panels scale fluidly. Use CSS Flexbox/Grid for the dashboard structure.
*   **Animations**: Use GSAP or standard CSS keyframes for fluid transitions (e.g., "Growth" animations when a building phase is activated).
*   **No Clutter**: Absolutely no textual "exam paper" layout. Everything must exist as a functional UI element (chips, sliders, drag-targets, and dynamic icons).

### 6. DELIVERY
Write the HTML/JS/CSS code as a single-file application. Ensure all logic for the "Role of an Architect" (COA, IIA, NASA, and professional roles) is embedded as JSON data objects within the JS so that interacting with elements triggers relevant information pop-ups in the dashboard.

**Proceed to build the application as an expert systems engineer.**
