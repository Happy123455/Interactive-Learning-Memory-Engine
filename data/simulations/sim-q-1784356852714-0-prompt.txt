Act as an expert educational software developer. Build a high-fidelity, interactive HTML5/JavaScript simulation for the "PIEV Theory" (Perception, Intellection, Emotion, Volition) as part of a Transportation Engineering course.

### 1. Visual Simulation Strategy
*   **The Environment**: Create a 2D Canvas animation representing a "Driver’s View" (top-down perspective) of a highway.
*   **The Driver Object**: An abstract, glowing vehicle icon moving at a constant velocity.
*   **The Hazard**: A stationary object (e.g., a stalled car or construction cone) that appears at a random distance.
*   **PIEV Timeline**: A horizontal "Timeline Rail" at the bottom of the canvas. As the driver approaches the hazard, a progress marker moves along this rail, highlighting the four phases:
    *   **P (Perception)**: Flash of retinal signal.
    *   **I (Intellection)**: Cognitive processing/hazard identification.
    *   **E (Emotion)**: Fear/impulse response.
    *   **V (Volition)**: Physical act of hitting the brakes.

### 2. Interactive Elements
*   **Sliders**: Include controls for "Initial Velocity (km/h)" and "Driver Alertness Level (Reaction Time in seconds, 1.0s to 3.0s)".
*   **Drag & Drop**: Allow the user to drag the hazard object closer or further away to test if the "Total Stopping Distance" (SSD) is sufficient.
*   **Real-time Equations**: Render the dynamic equation `SSD = v*t + v^2 / (2g * (f ± slope))` in a glassmorphic overlay. Variables must update live as the user adjusts sliders.
*   **Indicator Overlay**: When the simulation runs, show a vector arrow indicating the braking force (deceleration) that appears only once the "Volition" phase is reached.

### 3. Sound Design (Web Audio API)
*   **Implementation**: Use the native `AudioContext` to synthesize sounds.
*   **State-based Audio**: 
    *   **Ambient**: A subtle low-frequency "road hum" oscillator (sawtooth wave, low gain).
    *   **Phase Transitions**: Emit a soft, distinct "click" sine-wave pulse for each PIEV stage transition.
    *   **Alert**: A high-frequency, rising sweep (frequency ramp) triggered the moment the hazard is identified (end of Intellection).

### 4. Narrative Text-to-Speech (TTS)
*   **Voiceover**: Include a "Explain PIEV" button. 
*   **Mechanism**: Use `window.speechSynthesis` to trigger an educational narrative: 
    *   *“Perception: The eyes detect the hazard. Intellection: The brain processes the danger. Emotion: Fear triggers a response. Volition: The foot moves to the brake pedal.”*
*   **Sync**: The voiceover must pause/trigger based on the simulation state or user request.

### 5. Aesthetics & UI
*   **Theme**: Modern "Cyber-Dark" aesthetic. Deep charcoal background (#121212) with neon blue and cyan accents.
*   **Glassmorphism**: Use translucent panels with `backdrop-filter: blur(10px)` for the control dashboard.
*   **Typography**: Use clean, sans-serif fonts (e.g., 'Inter' or 'Roboto').
*   **Animations**: Ensure all object movements (the vehicle, the progress marker) use `requestAnimationFrame` for buttery-smooth 60fps performance. Use CSS transitions for UI panel fades.

### 6. Technical Requirements
*   **Logic**: Use the IRC standard assumption: Total reaction time = 2.5s. Allow the slider to deviate from this so students can observe the impact of delay.
*   **Responsiveness**: The canvas must be responsive to window resizing.
*   **Code Quality**: Write in modular ES6+ JavaScript. Keep the simulation logic (physics) separate from the rendering logic (Canvas API). 
*   **No External Dependencies**: Use pure JS and the native Web Audio API; do not reference external images or libraries. Everything must be rendered via Canvas drawing commands.
