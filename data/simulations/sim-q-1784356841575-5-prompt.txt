Build a high-fidelity, interactive HTML5/JavaScript educational simulation for an "Infiltration Indices" engineering module. The simulation must be a self-contained, responsive, single-file web application using a modern dark-theme dashboard aesthetic (glassmorphic control panels, neon-accented SVG/Canvas elements, and smooth CSS transitions).

### 1. Core Visual Strategy
*   **Split-View Dashboard**: 
    *   **Left Canvas**: A real-time 2D visualization of a rainfall-soil interaction. Use a soil profile cross-section where "Rainfall Intensity" (i) falls as animated particles. The soil surface should show a dynamic "Infiltration Capacity" (f) line.
    *   **Right Dashboard**: A real-time graphing area using a chart library (or canvas-based drawing) plotting "Rainfall Intensity (i)" vs. "Infiltration Capacity (f)" over time. Overlay the calculated $\phi$-index line as a horizontal dashed neon-blue line.
*   **Physics Loop**: Use `requestAnimationFrame` to manage particle flow and value updates. If $i > f$, show "Runoff" as blue water moving horizontally across the soil surface; if $i < f$, show particles disappearing into the soil.

### 2. Interactive Controls & Logic
*   **Control Panel**: 
    *   **Sliders**: Include sliders for `Rainfall Intensity (mm/hr)`, `Soil Moisture State (Initial vs. Saturated)`, and `Time Duration (hrs)`.
    *   **Interactive Input**: Create an input table where users can add incremental rainfall blocks for a storm event (e.g., 8-hour distribution).
    *   **Drag-and-Drop**: Allow users to drag the "$\phi$-index" horizontal line up or down on the graph to visually balance the "Rainfall Volume" above the line against the "Runoff Volume."
*   **Dynamic Calculations**: Automatically compute and display:
    *   $W\text{-index} = \frac{P - R - S}{t}$
    *   $\phi\text{-index}$ value (the average intensity above which total rainfall volume equals runoff).

### 3. Audio & Narrative Features (Native Web APIs)
*   **Web Audio Synth**: Use the `AudioContext` API to generate:
    *   **Click/UI Sound**: A high-pass filter "blip" when sliding parameters.
    *   **Rainfall Loop**: A low-frequency white noise generator with an oscillator sweep that changes pitch/volume based on the rainfall intensity slider.
    *   **Runoff Alert**: A subtle "ping" notification when $i > f$ is detected.
*   **Text-to-Speech (TTS)**: 
    *   Implement a `window.speechSynthesis` engine.
    *   Add a "Narrate Concept" button that provides a step-by-step walkthrough: "Current intensity is 50mm per hour. Since this exceeds the soil capacity, the surplus becomes runoff."
    *   Use distinct, clear voice synthesis to explain the difference between $\phi$ and $W$ indices as the user adjusts variables.

### 4. Mathematical Rendering & Animation
*   **Vector/Graph Overlays**:
    *   Show vector arrows representing rainfall velocity that decrease in length as they hit the ground.
    *   When $i > f$, animate a "Runoff" volume bar graph filling up in real-time.
    *   Use `MathJax` or a lightweight CSS formula renderer to display the governing equations dynamically as they are being used in the simulation calculations.

### 5. Aesthetics & UI/UX
*   **Theme**: Deep space-grey background (#121212) with neon cyan, magenta, and lime green accents.
*   **Components**: Glassmorphic panels with `backdrop-filter: blur(10px)` and semi-transparent white borders.
*   **Typography**: Clean, geometric sans-serif fonts (e.g., Inter or Roboto).
*   **Responsiveness**: Ensure the graph and canvas scale proportionally to mobile or desktop screen widths.

### 6. Technical Requirements
*   No external dependencies other than minimal CDN links for math rendering or chart libraries if necessary (prefer native Canvas API for performance).
*   Include a "Reset Simulation" button and an "Example Data" load button that populates the inputs with the data from "Example 01" in the provided source text.
*   The code must be encapsulated in a single HTML file containing `<style>`, `<script>`, and `<body>` sections, ensuring high readability and clean, commented logic.
