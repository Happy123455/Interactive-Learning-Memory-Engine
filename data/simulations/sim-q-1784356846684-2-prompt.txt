## **SIMULATION BLUEPRINT: PRECIPITATION PLAYGROUND**

**Concept:** A "Weather Creator Sandbox" where users interactively set up environmental conditions to observe and differentiate between Convective and Orographic Precipitation, guided by an ELI5-style playful narrator and vibrant visuals.

**AESTHETICS & LAYOUT:**
*   **Overall Theme:** Premium cyber-engineering dark dashboard.
    *   Background: Deep charcoal/black gradient (`#1a1a2e` to `#0f0f1f`).
    *   Panels: Translucent "glassmorphism" effect using `backdrop-filter: blur(10px);` and `rgba(30, 30, 50, 0.4)` background, with subtle `1px solid rgba(150, 150, 200, 0.2)` borders.
    *   Highlights: Glowing neon accents (cyan: `#00ffff`, purple: `#ff00ff`, green: `#00ff00`).
    *   Typography: Clean, sans-serif font (e.g., 'Orbitron', 'Rajdhani', or system-ui) for titles, 'Roboto Mono' for data.
    *   Fluid CSS animations for transitions, hover effects, and element interactions.
*   **Viewport & Resolution Rules:**
    *   Use CSS Flexbox and/or Grid for the main layout.
    *   The entire application MUST fit within `100vh` and `100vw` without generating double scrollbars.
    *   The main canvas area must dynamically resize on `window.resize` events, maintaining aspect ratio or scaling appropriately.
    *   Support high-DPI (Retina) scaling for all canvas drawings using `window.devicePixelRatio`.
    *   Draw clean, subtly textured, filled backdrop panels behind any text annotations on the canvas.

**HTML STRUCTURE (Conceptual):**
```html

    <header id="header">Precipitation Playground: Cloud Creator</header>
    <div id="main-content">
        <aside id="control-panel-left" class="glass-panel"></aside>

```

**JAVASCRIPT CORE REQUIREMENTS:**
*   **Canvas Initialization:** Get 2D context, apply `devicePixelRatio` for sharp rendering.
*   **Global State Management:** Use a simple JS object to manage simulation parameters (e.g., `simState = { sunHeat: 0, windSpeed: 0, mountainHeight: 0, ... }`).
*   **Animation Loop:** `requestAnimationFrame` for smooth updates and rendering.
*   **Drag-and-Drop Logic:**
    *   Custom D&D for `sunIcon`, `mountainTool`, `windTool`, `moisturePacket`.
    *   Detect `mousedown`/`touchstart`, `mousemove`/`touchmove`, `mouseup`/`touchend` events.
    *   Calculate offset, update element positions on canvas.
    *   Trigger `onDragStart`, `onDragMove`, `onDragEnd` custom events.
*   **Web Audio API:**
    *   Master gain node.
    *   Oscillator nodes for pitch-shifting sounds (sine wave, triangle wave).
    *   Buffer sources for short SFX (clicks, chimes, cheers).
*   **Web Speech Synthesis API:**
    *   `window.speechSynthesis` for all narration.
    *   Ensure a friendly, encouraging child-like voice is selected if available (e.g., 'Google US English' or similar).
    *   Queue utterances to prevent overlap.
*   **Event Listeners:** For D&D, sliders, buttons, and `window.resize`.
*   **Hand/Mouse Motion Gesture Detection:**
    *   Detect sustained `mousemove`/`touchmove` in a particular direction (e.g., left-to-right sweep across the canvas).
    *   When a sweep is detected over a designated area (e.g., over the "ground" for heat, or over the "atmosphere" for wind), trigger a specific simulation effect (e.g., generate more heat, increase wind intensity).

### **Phase 2: Core Simulation Logic & Interactivity**

1.  **Canvas & Drawing Setup (JavaScript):**
    *   Get `canvas` element and `ctx = canvas.getContext('2d')`.
    *   Function `resizeCanvas()`:
        *   `canvas.width = canvas.clientWidth * devicePixelRatio;`
        *   `canvas.height = canvas.clientHeight * devicePixelRatio;`
        *   `ctx.scale(devicePixelRatio, devicePixelRatio);`
        *   Call `resizeCanvas()` on initial load and `window.addEventListener('resize', resizeCanvas)`.
    *   `drawBackground()`: Render a dynamic sky gradient (dark blue to light blue or grey depending on "cloudiness") and a flat ground layer (green/brown) and a water body (blue).
    *   **Interactive Draggable Elements (Canvas):**
        *   `sunIcon`: Render as a glowing yellow-orange circle with subtle rays.
            *   `x, y, radius`.
            *   Drag & Drop: `onDragMove` updates its position.
            *   **Effect:** Influences `simState.groundTemperature`. Higher sun = hotter ground.
        *   `mountainTool`: Render as a stylized grey/brown mountain range SVG or path.
            *   `x, y, width, height`.
            *   Drag & Drop: `onDragMove` updates its horizontal position. Can snap to the bottom of the canvas.
            *   **Effect:** Creates a barrier for wind, triggering orographic lift.
        *   `windTool`: Render as a large, animated cyan arrow indicating direction and strength.
            *   `x, y, length, angle`.
            *   Drag & Drop: `onDragMove` updates its `x, y` and `length` (representing strength). Can be rotated.
            *   **Effect:** Influences `simState.windSpeed` and `simState.windDirection`.
        *   `moisturePacket`: Render as a fluffy, light blue cloud icon.
            *   `x, y, radius`.
            *   Drag & Drop: `onDragMove` updates its position.
            *   **Effect:** Represents the availability of moisture for cloud formation.

2.  **Sound & Narration (JavaScript):**
    *   **Web Audio Synth:**
        *   `audioCtx = new (window.AudioContext || window.webkitAudioContext)();`
        *   `masterGain = audioCtx.createGain(); masterGain.connect(audioCtx.destination);`
        *   `pitchOscillator = audioCtx.createOscillator(); pitchOscillator.type = 'sine'; pitchOscillator.start(); pitchOscillator.connect(masterGain);`
        *   Connect `simState.groundTemperature` (from `sunIcon` position) to `pitchOscillator.frequency.value`. Higher temp = higher pitch.
        *   Connect `simState.windSpeed` (from `windTool` length) to a *separate* `pitchOscillator.frequency.value`. Faster wind = higher pitch.
        *   **SFX:** Load short `click.wav`, `chime.wav` (success), `boing.wav` (bounce), `warning.wav` (error) using `audioCtx.decodeAudioData`. Play on drag start/end, successful condition met.
    *   **Native Web Speech Storytelling Voiceover:**
        *   `speak(text, pitch=1.0, rate=1.0, volume=1.0)` function:
            *   `utterance = new SpeechSynthesisUtterance(text);`
            *   `utterance.pitch = pitch; utterance.rate = rate; utterance.volume = volume;`
            *   `window.speechSynthesis.speak(utterance);`
            *   Ensure `window.speechSynthesis.cancel()` is called before speaking new messages if the previous one is still playing.
            *   Queue system for multiple narration calls.
        *   **Initial greeting:** "Hello, little cloud creator! Let's make some rain!" (Chime SFX)
        *   **On dragging Sun:** "Wooosh! Dragging the big bright sun warms up the ground! Can you hear the sound changing? That's the ground getting toastier!" (Connects to sun pitch-shifter)
        *   **On dragging Mountain:** "Whoa! A giant mountain! Clouds will have to climb over this big bump!"
        *   **On dragging Wind:** "Zoom! The wind is starting to blow! It will push our clouds wherever it goes!" (Connects to wind pitch-shifter)

### **Phase 3: Precipitation Mechanics & Visuals**

1.  **Convective Precipitation Logic:**
    *   **Conditions:** High `simState.groundTemperature` (e.g., above a threshold) and `moisturePacket` present over flat ground (no mountain nearby).
    *   **Visuals:**
        *   **Heat Waves:** Animated, shimmering lines rising from the ground below the `sunIcon`.
        *   **Cloud Growth Animation:** If conditions met, an initial small `moisturePacket` over the ground will gradually expand and darken (from light blue to grey), forming a convective cloud (cumulus/cumulonimbus-like). This should be a growth animation, not just appearing.
        *   **Rainfall:** When the cloud reaches a certain density/height, start animating falling rain particles from it. Particles should be bright blue/white, with a slight "splash" effect on the ground.
        *   **Dynamic Camera Zooms:** When convection starts, smoothly zoom the canvas (e.g., 150%) into the cloud formation, highlighting rising air currents (subtle up-arrows).
    *   **Narration:** "Look! The sun made the ground super warm, like a big hot plate! The air and water vapor are getting bouncy and zooming up to make a cloud. *Boing!* This is called Convective Precipitation, like steam from your hot chocolate!" (Cheer SFX when rain starts).

2.  **Orographic Precipitation Logic:**
    *   **Conditions:** `windTool` pushing `moisturePacket` towards `mountainTool`. `simState.windSpeed` above a threshold.
    *   **Visuals:**
        *   **Wind Flow:** Animated wind lines (cyan) showing air currents being forced up the windward side of the mountain.
        *   **Cloud Growth Animation:** As the `moisturePacket` moves up the mountain, it should gradually expand, cool, and condense into an orographic cloud, clinging to the mountain slope on the windward side. Show cooling effect (e.g., cloud changes from light blue to a cooler, slightly darker blue as it rises).
        *   **Rainfall:** Start animating rain particles falling on the *windward side* of the mountain when the cloud reaches critical conditions. The leeward side should remain dry, possibly with a "rain shadow" effect (brighter sun/sky).
        *   **Dynamic Camera Zooms:** When orographic lift occurs, smoothly zoom the canvas (e.g., 150%) into the windward slope, highlighting the rising cloud and rain.
    *   **Narration:** "Whee! The wind is like a big pusher, making the cloud climb the mountain like a slide! As it goes up, it gets chilly and makes rain! This is Orographic Precipitation, like clouds trying to get over a giant speed bump!" (Cheer SFX when rain starts).

3.  **Unified Precipitation Rate Graph:**
    *   Located in `control-panel-right`.
    *   A real-time line graph plotting `precipitationRate` (Y-axis) vs. `time` (X-axis).
    *   Graph line should be a vibrant green neon.
    *   `precipitationRate` should be a numerical value derived from the active precipitation type and its intensity.
    *   If both convective and orographic conditions are simultaneously met (unlikely in this simplified model, but possible for advanced interactions), the graph should show the combined effect or two separate lines.
