Act as an expert Full-Stack Developer and Educational Software Engineer. Your objective is to build a high-fidelity, gamified web simulation for **Transportation Engineering (Unit 5: Rail Transportation)**, specifically focused on **"Synthesizing and Comparing Railway Gauge Dimensions."**

### **CORE DIRECTIVE: THE "GAUGE ANALYTICS STUDIO"**
Do not create a document or a standard quiz. Build a **Cyber-Engineering Dashboard** where the student interacts with physical representations of track geometry.

---

### **1. AESTHETICS & LAYOUT (100vh Rigid Containment)**
- **UI Design**: Dark-mode, glassmorphism dashboard (backdrop-filter: blur). Use neon accents (Cyan for structural data, Purple for UI elements, Amber for warnings).

- **Canvas**: An HTML5 Canvas element serving as the "Virtual Workshop" where track cross-sections are rendered.
- **Responsive Canvas**: Auto-resize to high-DPI/Retina screens, maintaining aspect ratio.

### **2. INTERACTIVE SIMULATION ENGINE**
- **The Gauge Workbench**: A central 2D drawing area that renders three track cross-sections (Broad, Meter, Narrow). 
- **Drag-and-Drop Value Transfer**: Provide "Data Chips" containing numerical values (e.g., "1676mm", "1000mm", "762mm") at the bottom of the screen. The user must drag these chips onto the corresponding track section in the canvas.
- **Snap & Validate**: On drop, the canvas must trigger a "snap" animation, play a success chime (Web Audio API), and highlight the track section with a glowing neon outline.
- **Real-Time Canvas Annotation**: Upon correct placement, show dynamic dimension leader lines (using `canvas` drawing methods) that update labels instantly.

### **3. GAMIFIED MECHANICS & INTERACTION**
- **IS-Codebook Library**: A sidebar containing a clickable "Railway Design Manual" icon. Clicking it opens an overlay with the required code reference (e.g., Indian Railway Standards). The user must select the correct gauge clause to unlock the simulation step.
- **Dynamic Camera Zoom**: When a user selects a gauge type, trigger a `requestAnimationFrame` zoom (scale 1.5x) into that specific track cross-section to show the internal rail head profile.
- **Stress/Load Visualizer**: Add a toggle button "Visualize Load Capacity." When active, overlay force vectors on the tracks showing the distribution of rolling stock weight based on the gauge width.

### **4. AUDIO & NARRATION**
- **Synthesized Narration**: Use `window.speechSynthesis` to provide audio feedback. When a user drags a value, the browser should say, "Broad Gauge identified as 1676 millimeters."
- **Audio Synthesis**: Use the `AudioContext` API to generate distinct sonic profiles:
    - *Success*: High-frequency ascending chord.
    - *Error*: Low-frequency, pulsing bass tone.
    - *Transition*: "Click" sound when shifting between Gauge types.

- **Side-by-Side Comparison Grid**: Create a "Tabulation Module" which is a glass-paneled component that populates as the student drags values. 
- **Dynamic Transition**: As values are dropped, the table rows must transition from transparent/blurred to high-contrast, glowing white text.
- **Real-Time Comparison**: If a user attempts to swap a dimension to the wrong track, trigger a "Jitter" animation on the chip and a warning chime.

- **Framework**: Pure JavaScript, HTML5 Canvas, CSS Grid/Flexbox.
- **Performance**: High-efficiency animation loops (`requestAnimationFrame`).
