Act as a Senior Educational Software Engineer and Structural Design Expert. Build a high-fidelity, single-file interactive simulation (HTML/CSS/JS) for a "Laced Built-up Column Design" tutorial. The simulation must visualize the structural mechanics of two ISMC 350 channels back-to-back under a 1000 kN axial load.

### 1. Visual Simulation Strategy
*   **Engine**: Use HTML5 Canvas for the structural visualization.
*   **Core View**: A 2D side-profile view of the built-up column. Render the ISMC 350 profiles as distinct, high-contrast steel shapes. 
*   **Dynamic Lacing**: The lacing system should be procedural. As the user modifies parameters, re-draw the lacing pattern (angle of inclination, spacing) dynamically.
*   **Real-time Math**: Integrate `MathJax` or custom SVG text overlays to display real-time calculations (e.g., Slenderness ratio λ, Buckling load $P_e$, and Lacing force components).

### 2. Interactive Elements
*   **Dashboard**: Create a glassmorphic sidebar with neon-accented input fields and sliders for:
    *   `Load (kN)`: Slider (500–2000).
    *   `Effective Length (m)`: Slider (3–8).
    *   `Spacing (mm)`: Slider (200–400).
*   **Drag & Drop**: Implement a "Stress Visualization Mode" where users drag a probe along the column length; the canvas should render a ghosted pressure/stress intensity plot over the segment being hovered.
*   **Force Overlays**: Draw interactive vector arrows representing the load transfer from the main chord to the lacing bars. Arrows should scale in real-time as the load slider is adjusted.

### 3. Sound Design (Web Audio API)
*   **Implementation**: Use `window.AudioContext`.
*   **User Feedback**: 
    *   *Parameter Change*: A subtle, short-duration low-pass filtered sine sweep (440Hz to 660Hz) when sliders move.
    *   *Success/Threshold*: A harmonic chime (triadic chord) generated via oscillators when the design satisfies structural safety codes (IS 800:2007 criteria).
    *   *Error*: A low-frequency, pulsating pulse wave when the design fails (lambda > 180 or inadequate section).

### 4. Narrative Text-to-Speech
*   **System**: Use `window.speechSynthesis`.
*   **Functionality**: Add a "Tutor Mode" toggle. When active, every time a student adjusts a parameter, the browser speaks a concise pedagogical explanation: "Increasing the spacing decreases the radius of gyration, significantly impacting the critical buckling load."
*   **Controls**: Include a "Read Steps" button that iterates through the design procedure (1. Calculate $\lambda$, 2. Determine compressive strength $f_{cd}$, 3. Design lacing).

### 5. Diagram Animations & Aesthetics
*   **Theme**: Dark mode (Background: #0a0a0c) with neon cyan for active structural components and neon amber for force vectors.
*   **Transitions**: Use `requestAnimationFrame` for all diagram resizing. When a value changes, animate the growth/shrinkage of the cross-section profiles and lacing grid using linear interpolation (LERP).
*   **Typography**: Use 'Inter' or 'Roboto' sans-serif fonts.
*   **UI Elements**: Glassmorphic panels using `backdrop-filter: blur(10px)` and semi-transparent borders.

### 6. Functional Requirements
*   **Logic**: Include a mini-calculation engine in JS that evaluates the feasibility of the ISMC 350 sections based on the input load and effective length. 
*   **Visual Output**: If the design is unstable (lambda exceeds code limits), the column should glow with a pulsing red neon warning, and the stress graph should highlight the critical zone.
*   **Code Structure**: Provide a single-file solution (`.html`) containing CSS in `<style>` and JS in `<script>`. Use modular functions for rendering, audio, and speech to ensure readability.

**Your Goal**: Produce a professional, highly polished, gamified learning experience that bridges the gap between static textbook equations and real-world structural behavior.
