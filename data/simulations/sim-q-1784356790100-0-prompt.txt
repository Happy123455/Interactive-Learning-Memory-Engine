**Role:** You are an expert educational software engineer and creative coder. Your task is to build a single-file, interactive HTML5/JS simulation that demonstrates the "Failure Modes of Axially Loaded Columns" for a college-level Structural Engineering course.

### Core Simulation Architecture
- **Framework:** Vanilla HTML5, CSS3, and JavaScript (ES6+). No external libraries. Use the Canvas API for all visualizations.
- **Theme:** Modern Dark Dashboard. Use a color palette of deep charcoal backgrounds (#121212), glassmorphic control panels (backdrop-filter: blur(10px)), and neon-accented UI elements (Cyan for stable states, Electric Orange for critical stress, Magenta for failure points).
- **Typography:** Sans-serif (Inter or system-stack), high readability.

### Visual Simulation Strategy
1. **The Column Object:** A vertical 2D representative column in the center. Use a spring-mass-dashpot visual metaphor to represent axial stiffness.
2. **Failure Modes Visualization:** Implement three toggleable modes:
    *   **Squashing (Crushing):** Column shortens while its width expands slightly (Poisson’s effect).
    *   **Buckling (Elastic Instability):** Column adopts a sinusoidal (Euler) curve shape.
    *   **Combined/Local:** Animate local flange buckling as a mesh deformation.
3. **Real-time Graphing:** A dynamic sidebar graph using the Canvas API. The X-axis represents axial load (P), and the Y-axis represents vertical displacement (δ). Plot the "load-displacement" curve in real-time as the user increases force.

### Interactive Elements
1. **Load Slider:** A vertical slider to increase the axial force applied to the column head.
2. **Drag & Drop Handle:** A handle at the top of the column that users can drag to simulate eccentric loading, which triggers different buckling curves.
3. **Constraint Controls:** Buttons to change boundary conditions: Pinned-Pinned, Fixed-Free, Fixed-Pinned, Fixed-Fixed. The animation must reflect the Effective Length ($K \cdot L$) by changing the curvature of the column shape.
4. **Data Overlay:** Display the active equation (e.g., $P_{cr} = \pi^2 EI / (KL)^2$) in a glowing floating panel that updates the variables based on input.

### Web Audio API Integration
*Do not use external files. Generate all sound using the `AudioContext`.*
- **Interaction Sound:** A low-frequency "thrum" (oscillator type: sine) that increases in pitch as load increases.
- **Failure Trigger:** A sharp, descending "glissando" sweep (oscillator type: sawtooth) when the load exceeds the calculated $P_{cr}$.
- **Click Feedback:** A soft, high-frequency "click" (short-duration burst) for every button press.

### Narrative Text-to-Speech (TTS)
- Implement a `narrate(text)` function using `window.speechSynthesis`.
- Add a "Concept Narration" toggle. When active, it must automatically read:
    1. A brief overview of the selected failure mode upon switching.
    2. An explanation of what happens to the column as the user drags the slider.
- Add a "Learn More" button that triggers a structured voiceover explaining the relationship between slenderness ratio and buckling.

### Animation & Physics
- Use `requestAnimationFrame` for a smooth 60fps loop.
- Use Easing functions for UI transitions.
- **Vector Overlays:** Draw dynamic force vectors at the column ends. As the column buckles, draw the P-Delta effect vector (the moment created by the eccentricity).
- **Grid System:** An subtle background grid that deforms slightly to represent internal strain.

### Technical Constraints
- The entire application must be contained in a single HTML file.
- All styles must be inside a `<style>` block.
- All logic must be inside a `<script>` block.
- The UI must be responsive and centered in the viewport.

### Implementation Checklist for the Developer
1. **Setup the Canvas environment.**
2. **Build the CSS Glassmorphic Dashboard.**
3. **Develop the Mathematical solver** for $P_{cr}$ based on chosen end conditions.
4. **Integrate the Web Audio synthesis layer.**
5. **Implement the `speechSynthesis` interface.**
6. **Ensure the Euler Buckling curve logic renders accurately on the canvas.**
7. **Ensure the transition between "Stable" and "Failure" states is visually distinct and jarring (e.g., red flashing, vibration animation).**

Begin by creating the structure, then define the physics loop, and finally add the audio/TTS enhancements.
