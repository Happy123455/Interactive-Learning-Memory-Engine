Act as an expert Educational Software Developer and Prompt Engineer. Your objective is to create a high-fidelity, interactive, web-based simulation for the "Aggregate Impact Test" in Transportation Engineering. The goal is to provide students with a visceral understanding of aggregate toughness and impact resistance.

### Technical Requirements & Architecture
Build this as a single-file solution (HTML5, CSS3, Vanilla JS). 
- **Graphics Engine**: Use the HTML5 Canvas API for smooth 60fps animations.
- **Physics**: Implement a simple gravity-based Verlet integration for the falling hammer.
- **Styling**: Use a "Cyber-Engineering" aesthetic: dark theme (`#0f172a`), neon cyan/lime accents, glassmorphism panels (`backdrop-filter: blur(10px)`), and Google Fonts (Inter/Roboto).

### 1. Visual Simulation Strategy
- **Canvas Setup**: Split the screen. The left side holds the "Apparatus" (Hammer, Drop Guide, Aggregate Cup). The right side acts as a "Data Dashboard" for real-time plotting.
- **The Apparatus**: Render a 2D side-profile of the Impact Testing Machine. The hammer must be draggable vertically. 
- **Visual Overlays**: Use vector arrows on the hammer head showing velocity vectors (magnitude and direction) during the fall. Highlight the point of impact with a glowing pulse effect.

### 2. Interactive Elements
- **Drag-and-Drop**: Users drag the hammer head to a specific height (10cm to 38cm). Lock the hammer in place on release.
- **Control Panel**: 
    - **Sliders**: Adjust "Aggregate Hardness" (Simulates different rock types) and "Hammer Weight".
    - **Buttons**: "Release Hammer", "Reset Test", "Narrate Mechanism".
- **Dynamic Plotting**: Use a lightweight charting approach to plot "Impact Force vs. Time" on the dashboard. As the hammer strikes, show the impulse curve peak.

### 3. Sound Design (Web Audio API)
Do not use external files. Implement the following using `AudioContext` oscillators:
- **Impact Sound**: A complex tone created by a low-frequency oscillator (sawtooth wave) decay with a quick white-noise burst for the "crunch" of aggregate fracturing.
- **Mechanical Whir**: A low-pitch sine wave pulse as the hammer is dragged.
- **Interface Clicks**: Soft, high-frequency chirps for button presses.

### 4. Narrative Text-to-Speech (TTS)
- Implement a `speak(text)` function using `window.speechSynthesis`.
- Add a "Narrate" toggle. When active, trigger automatic explanations at key milestones: 
    - "Hammer positioned at [X] cm. Preparing for release."
    - "Impact! Calculating the Impact Value based on weight distribution."
    - "Test result: The aggregate has shattered into fragments. Calculating percentage fines."

### 5. Diagram Animations & Equations
- **Overlay Rendering**: Render mathematical expressions (e.g., $AIV = (W_2 / W_1) * 100$) in a dedicated transparent glass panel.
- **Real-time Math**: As the hammer falls, display dynamic text showing `Height = X`, `Potential Energy = mgh`, and `Velocity = sqrt(2gh)`. Use `requestAnimationFrame` to update these values in sync with the hammer's position.
- **Fragment Simulation**: Upon impact, spawn 10-15 small particle polygons (representing aggregate pieces) that scatter with momentum conservation.

### 6. Implementation Workflow
- **Step 1: CSS Framework**: Define the grid layout. Create a glassmorphic sidebar for controls and a main dark-themed viewport.
- **Step 2: Physics Loop**: Code the hammer drag logic. Ensure the velocity increases according to $v = \sqrt{2gh}$.
- **Step 3: Web Audio Initialization**: Write the functions for the 'Impact' sound effect using GainNodes for volume control.
- **Step 4: Integration**: Map the "Release" button to the physics animation and sound trigger. 
- **Step 5: Narrative Logic**: Wrap event listeners in a conditional `isNarrating` flag to trigger `speechSynthesis` at relevant state changes.

**Constraint Checklist**: 
- No external libraries (e.g., D3, Three.js). Pure Vanilla JS.
- The UI must feel like a professional aerospace or civil engineering dashboard.
- Ensure the math is accurate to the standard Aggregate Impact Value (AIV) testing procedure.
