**Simulation Blueprint: "The Structural Tug-of-War"**

**Objective**: Create a gamified, physics-based sandbox comparing "Working Stress Method" (WSM) and "Limit State Method" (LSM) using playful analogies.

**Visual Interface**:
- **Style**: Dark cyber-neon dashboard, 100vh containment.
- **Components**: Left panel contains a "Stress-o-Meter" slider and "Theory Cards" (WSM vs. LSM). Right panel features a high-fidelity 2D Canvas grid.
- **Canvas Physics**: A central concrete beam (a "Gummy Bear" for elasticity, "Hard Rock" for limit state).

**Interaction Logic**:
1. **The Playground**: Users drag "Load Cubes" onto the beam. 
2. **WSM Mode (Safe Play)**: As load increases, the beam bends slightly. Use `window.speechSynthesis` to say, "WSM is like a cautious turtle; it stays well below the breaking point to keep us safe!" Show linear stress-strain lines.
3. **LSM Mode (The Limit)**: As load increases, the beam reaches a vibrant, pulsing "collapse" point. Narrate: "LSM is the daring adventurer! We push it to the very edge of safety using smart math factors." 
4. **Drag-and-Drop Math**: Provide floating numerical chips (Factor 1.5, Factor 1.0). Drag these onto the beam’s load equation area. A successful "snap" triggers a green glow and a high-pitched "ding" via Web Audio Oscillator; an incorrect placement triggers a low-pitched "bloop" and a red shake effect.
5. **Real-time Feedbacks**:
   - **Visuals**: As the user moves the mouse across the beam, the beam bends using a quadratic bezier curve.
   - **Audio**: Connect mouse-x position to an oscillator frequency (`gainNode.gain.value` linked to beam curvature). High bend = High frequency squeak.
   - **Diagrams**: Overlay dynamic vector arrows showing internal stresses. As the user toggles between WSM/LSM, smoothly transition the stress-block from a triangle (WSM) to a parabolic-rectangular block (LSM).

**Technical Constraints**: 
- Use responsive HTML5 Canvas with `devicePixelRatio` scaling.
- Ensure all speech and sound triggers are throttled to prevent audio overlap.
