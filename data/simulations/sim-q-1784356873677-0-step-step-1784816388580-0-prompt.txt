**PROMPT FOR GEMINI: ADVANCED INTERACTIVE ENGINEERING SIMULATION GENERATOR**

**Role:** You are a Lead Educational Developer and Creative Technologist specializing in gamified structural and transportation engineering simulations.

**Task:** Build a high-fidelity, interactive HTML5/JS/CSS simulation for the topic: **"Railway Gauge Definition & Classification."**

**Core Requirements:**
1. **The "Engineering Studio" Layout:**
   - Use a full-screen (100vh) CSS Grid layout. The right sidebar is a "Dark Mode Dashboard" (Glassmorphism, deep charcoal background, neon cyan/purple accents).
   - The central area is an interactive Canvas (High-DPI enabled) simulating a 3D-perspective railway track section.
2. **Interactive Railway Gauge Simulation:**
   - **Visual Mechanic:** A top-down and front-facing cross-section of a railway track. Users must drag a "Gauge Calibration Tool" (a precision measuring caliper) between the inner faces of the two rails.
   - **Physics/Interaction:** When the tool reaches the inner faces, it snaps into position with a satisfying magnetic click (Web Audio API sound). 
   - **Real-Time Data:** As the tool snaps, the value (e.g., 1676mm, 1000mm, 762mm) displays on a floating digital label. The dashboard concurrently populates the "Define Gauge" field with the correct technical definition.
3. **Gamified Exam Writing (The "Constraint Solver"):**
   - No static text boxes. Instead, create "Formula/Definition Slots." 
   - Provide "Word Tiles" floating in a workspace. The student must drag words (e.g., "Clear," "Minimum," "Horizontal," "Inner faces," "Parallel rails") into the "Definition Slot." 
   - If a tile is placed correctly, it locks with a green glow and a "Success" chime. If incorrect, it bounces back with a "Warning" sound.
4. **Speech & Audio Engine:**
   - Integrate `window.speechSynthesis`. When a user correctly defines the gauge, trigger a professional, calm engineering voice: *"Correct. The gauge is the clear minimum horizontal distance between the inner faces of the two parallel rails."*
   - Add ambient synth-tech background hums and tactile UI interaction beeps.
5. **Dynamic Camera & Visualization:**
   - Implement an "X-Ray View" toggle button. When clicked, the rails turn semi-transparent to reveal the ballast, sleeper, and formation level underneath. 
   - Use dynamic zooming: Upon defining the gauge, zoom the canvas 150% into the rail-head junction to emphasize the "Inner Face" contact point.
6. **Technical Guidelines:**
   - **Canvas:** Use `requestAnimationFrame` for smooth object movement and hover-state glows.
   - **Responsiveness:** The layout must handle window resizing seamlessly using `ResizeObserver`. No double scrollbars.
   - **Aesthetics:** Use a dark, futuristic engineering palette (e.g., `--neon-cyan: #0ff`, `--slate: #1a1a2e`). All panels must have a `backdrop-filter: blur(10px)` effect.
   - **Code Structure:** Provide a single-file solution (HTML/CSS/JS embedded) that is modular, clean, and fully commented. 

**Pedagogical Goal:**
The user must transition from an "Unfamiliar Student" to an "Engineered Understanding" by physically manipulating the rail assembly to discover the definition, rather than reading it.

**Constraints:**
- NO static exam paper visuals.
- NO large walls of text.
- Focus entirely on the physical interaction of the Gauge Tool with the Rail Track and the word-tile assembly system.
- The simulation MUST feel like an advanced CAD-utility tool, not a web page.
