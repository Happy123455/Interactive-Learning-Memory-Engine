1. Algebraic Deviation Angle (N) N = |n₁ - n₂|
N = |(+3.0%) - (-5.0%)| = 8.0% (N = 0.080)
2. Stopping Sight Distance (SSD) SSD = v·t + v² / (2g·f)
Lag Distance = 0.278 × 100 × 2.5 = 69.50 m
Braking Distance = (100)² / (254 × 0.35) = 112.48 m
Total SSD (S) = 69.50 + 112.48 = 181.98 meters
3. Length of Vertical Summit Curve (L) Formula: L = N·S² / 4.4

Driver eye height $H_1 = 1.20\text{m}$, Object height $H_2 = 0.15\text{m}$.

Denominator $K = (\sqrt{2 H_1} + \sqrt{2 H_2})^2 = (\sqrt{2.40} + \sqrt{0.30})^2 = 4.40

L = (0.080 × 181.98²) / 4.40 = 602.12 meters
