Act as an expert Educational Software Developer and Prompt Engineer. Your objective is to create a high-fidelity, interactive HTML5/JavaScript educational simulation for a Structural Engineering course (Unit 5: Compression Members). 

The simulation must act as an interactive "Field Identification Tool" that allows students to analyze steel compression members in real-time.

### 1. Technical Requirements
- **Framework**: Vanilla JavaScript, HTML5 Canvas API, and CSS3. 
- **Audio**: Utilize the Web Audio API for synthetic sound generation (oscillators/gain nodes). No external assets.
- **Accessibility**: Use `window.speechSynthesis` for educational narration.
- **Styling**: Modern dark theme (background: #0f172a), neon cyan/amber accents, glassmorphic UI panels (backdrop-filter: blur(10px)), and Inter/sans-serif typography.

### 2. Simulation Visuals & Interaction
- **Canvas Engine**: Use a 2D Canvas loop to render a 3D-perspective "Structural Gallery." 
- **Draggable Elements**: Allow students to drag and drop different steel sections (I-Beam, Hollow Structural Section, Angle Iron) onto a 3D structural joint model.
- **Real-Time Physics/Graphics**: 
    - When an element is placed, display a **Vector Overlay** representing the internal axial force.
    - Animate the vector length using CSS transitions or frame-based animation logic to show stress magnitude (Euler’s Buckling formula).
    - Render a live **Equation Plotter** (e.g., $P = \pi^2 EI / (KL)^2$) in a side-panel, plotting the relationship between Length and Buckling Load as the user drags a slider.

### 3. User Interface (UI) Components
- **Dashboard**: A "Glassmorphism" control panel on the right with:
    - **Sliders**: To adjust member length (L) and K-factor (effective length factor).
    - **Buttons**: "Inspect Connection," "Calculate Load," "Narrate Concept."
    - **Dynamic Labels**: Display updated stress values (in kN) near the member in the canvas.
- **Drag-and-Drop**: Implementing a `mousedown`/`mousemove`/`mouseup` system to move "Structural Components" from a side tray to the main simulation viewport.

### 4. Audio & Narration Logic
- **Sound Design**:
    - **Snap Effect**: Use a square-wave oscillator with a short decay envelope when a member snaps into a connection joint.
    - **Hover Effect**: A subtle, low-frequency sine-wave pulse (filtered) when the mouse passes over a structural node.
- **Narrator**:
    - Implement a function `speakText(text)` that uses `window.speechSynthesis`. 
    - Trigger "Auto-Narrate" when the user clicks a component for the first time, explaining: *"This is a HSS compression member; notice how the connection distributes the axial load."*

### 5. Step-by-Step Execution Plan
- **Phase 1 (Setup)**: Initialize the Canvas and CSS variables for the dark/neon theme.
- **Phase 2 (Interaction)**: Map mouse coordinates to the Drag-and-Drop system and collision detection with "Slot" regions.
- **Phase 3 (Calculations)**: Write the JS function for the buckling load formula; wire it to the slider input to update the visual graph.
- **Phase 4 (Audio/TTS)**: Implement the Web Audio oscillator logic for snaps and the synthesis trigger for educational explanations.
- **Phase 5 (Refinement)**: Ensure smooth transitions (`requestAnimationFrame`) for vector growth and UI fade-ins.

### 6. Code Architecture Expectation
- Organize code into a modular structure: `SimulationEngine`, `AudioSystem`, `UIController`, and `MathLibrary`.
- Ensure all calculations are reactive: changes in slider inputs must immediately trigger updates in the Canvas diagram, the Equation plotter, and the speech-to-text narration.

**Constraints**: You must provide the complete, functional, single-file HTML/JS structure. The code must be self-contained within one code block. Include comments explaining how the Web Audio API and Speech Synthesis API are integrated.
