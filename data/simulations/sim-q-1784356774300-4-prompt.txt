**Simulation Blueprint: "The Bolted Joint Sandbox"**

Build a high-performance, web-based engineering playground using HTML5 Canvas, WebGL, and GSAP for fluid animations.

**1. Aesthetic Framework:**
Use a "Dark-Cyber" aesthetic: obsidian background, neon cyan/purple glowing UI panels, and semi-transparent glass-morphism overlays. Use a 100vh grid layout to prevent scrollbars. Canvas must support High-DPI scaling.

**2. Core Mechanics (ELI5 Gamification):**
*   **Narrator**: Use `window.speechSynthesis` to explain concepts like "Tension as a tug-of-war" and "Bolts as super-strong metal glue."
*   **Audio Synth**: Map load variables (e.g., tension force) to a Web Audio `OscillatorNode`. Increasing the load increases the pitch frequency, providing an "audio-tension" feedback loop.
*   **Gestures**: Enable pointer-tracking. A right-to-left sweep across the canvas applies a "virtual pull" on the structural connection, visualizing displacement.

**3. Interactive Simulation Elements:**
*   **The Joint Canvas**: A central interactive cross-section of a 2-ISA section connected to a Gusset plate. 
*   **Drag-and-Drop Slots**: Create "Input Chips" (e.g., Bolt M20, Grade 4.6, Load 150kN). Users must drag these into the "Problem Slot" on the Gusset plate. Correct placements trigger a green "pulse" glow, a satisfying chime, and unlock the next design phase.
*   **Physics Visualization**: As the user drags the "Tension Force" slider, visualize force vectors in real-time. Show the bolt shanks deforming (scaling/skewing) as tension increases. 
*   **Reference Book**: Include an interactive, clickable "IS 800:2007" digital flipbook widget. Users must "open" to Clause 10.2 (pg 73) to verify bolt edge/end distance requirements before the simulation allows a "Final Load Test."

**4. Design Steps (Step-by-Step):**
1.  **Identify**: Clicking problem text highlights variables (b, D, thickness) in bright neon. 
2.  **Assemble**: Snap ISA angles onto the Gusset plate via drag-and-drop.
3.  **Bolting**: "Stamp" bolt holes by clicking/dragging the bolt chip; animate holes forming on the plate.
4.  **Simulate**: Once configured, press "Apply Tension." Watch the joint stretch, hear the pitch rise, and see the failure stress-heat-map glow red if capacity is exceeded.
