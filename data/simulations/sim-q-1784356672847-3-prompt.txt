Act as an expert Educational Software Developer and Prompt Engineer. Your objective is to create a high-fidelity, interactive HTML5/JS simulation of an **RCC Beam Engineering Workspace**. The simulation is designed for students to master IS 456:2000 codal provisions regarding reinforcement detailing.

### **CORE ARCHITECTURE & DESIGN SYSTEM**
- **Aesthetics**: Use a "Cyber-Engineering" theme. Dark background (`#0f172a`), neon glowing UI elements (Cyan for interactions, Amber for warnings, Emerald for success), and glassmorphism panels (`backdrop-filter: blur(10px)`).
- **Layout**: Utilize CSS Grid/Flexbox with `100vh` containment. No scrollbars allowed. Use a responsive canvas for the engineering workspace.
- **Interactivity**: Everything must be manipulatable. Drag-and-drop mechanics for structural parameters and "Codebook" references.

---

### **STEP-BY-STEP INSTRUCTIONAL BLUEPRINT**

#### **Step 1: Workspace Initialization**
- Initialize a full-screen application with two primary panels:
    - **Left Panel (Control Center)**: A scrollable, glass-morphism checklist of the three required criteria (Max Diameter, Max Spacing, Min Reinforcement). Use a "Pending" (Red) to "Verified" (Green) status switch.
    - **Right Panel (Canvas)**: A responsive HTML5 Canvas rendering a cross-section of an RCC beam. Include initial "ghost" outlines for steel rebars and concrete cover.

#### **Step 2: Gamified Codal Reference System**
- Create a "Digital IS 456 Library" button. Upon clicking, a sub-window opens displaying simulated "Codebook Page" cards.
- The student must drag the correct "Clause Number Card" (e.g., Clause 26.5.1) and snap it onto the corresponding "Interactive Parameter" text in the Control Center.
- **Success Trigger**: Use `window.speechSynthesis` to narrate the clause explanation once snapped, accompanied by a satisfying chime sound.

#### **Step 3: Interactive Beam Drafting & Visualization**
- Implement **Growth Animations**: When a student interacts with the "Reinforcement" parameter, the canvas must animate the rebar diameter and spacing dynamically.
- **Dynamic Leaders/Callouts**: As the mouse hovers over rebars, display floating, animated neon leaders pointing to the concrete edge, explicitly labeling 'b' (width), 'D' (depth), and 'c' (clear cover).
- **Stress Blocks & Profiles**: Provide a toggle to overlay the "Parabolic Stress Block" and "Strain Profile" on the beam section. The Neutral Axis (NA) must be a draggable horizontal line that updates the associated stress intensity values in real-time.

#### **Step 4: The Logic Engine (Constraint Validation)**
- If a student tries to select a rebar diameter exceeding the IS 456 limits (e.g., > 1/8 of total beam depth), trigger a **"Structural Warning"**:
    - The beam glows red, a low-frequency warning tone plays, and the UI highlights the specific Clause Number in the codebook that was violated.
- Implement **Constraint Sliders**: Users drag numerical chips onto "Formula Slots" (e.g., `Ast > 0.85*bd/fy`) to check if the design is compliant. Snap-to-grid visuals are required.

#### **Step 5: Visual Polish & Sound**
- **Pour & Glow**: Use additive blending modes for "Concrete Pour" animations (a slow, semi-transparent liquid flow into the formwork shape) and "Steel Pulse" glows (breathe effect) for the tension rebars.
- **Sound Design**:
    - *Success*: High-pitched harmonic chime.
    - *Error*: Low-frequency, pulsing bass-thud with a screen-shake animation.
    - *Action*: Mechanical "click" sounds for UI buttons and drags.
- **Accessibility**: Ensure `speechSynthesis` is used to explain why a design choice is "Safe" or "Unsafe" based on the selected clause.

### **TECHNICAL CONSTRAINTS FOR THE GENERATOR**
1. **Viewport**: Use `canvas.width = window.innerWidth` and `canvas.height = window.innerHeight`. Use `requestAnimationFrame` for all motion.
2. **State Management**: Keep a JSON object representing the beam state (`{b, D, c, Ast, fck, fy, currentClause}`) and update all visuals whenever this object changes.
3. **No Clutter**: Absolutely no text-heavy exam sheets. Only represent information through interactive tags, dynamic callouts, and the "IS 456" visual library interface.
4. **Drawing**: Use high-DPI scaling (Canvas `getContext('2d').scale(window.devicePixelRatio)`) for crisp, professional-grade vector rendering.

**Final Output Requirement:** Write the code as a single-file implementation (HTML/CSS/JS) that launches this simulation environment immediately.
