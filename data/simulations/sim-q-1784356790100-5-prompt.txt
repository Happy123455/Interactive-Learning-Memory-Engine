### **Simulation Instruction Prompt**

**Objective:** Build a single-page, web-based simulation that calculates and visualizes the compressive strength of an angle strut (ISA 75x75x10 to 100x100x10). The simulation must follow Indian Standard (IS 800) principles for eccentrically loaded, single-bolted struts.

#### **1. Core Visual Strategy**
*   **Engine:** Use a 2D HTML5 Canvas for the physics/diagram rendering and a secondary overlay for UI.
*   **The Model:** Render a 3D-perspective-view angle strut (ISA section) that responds to user inputs.
*   **Force Vectors:** Implement dynamic vector arrows representing the axial load ($P$) and eccentricity ($e$). As the load magnitude changes, arrow length and thickness must scale proportionally using a requestAnimationFrame loop.
*   **Structural Animation:** Use a spring-mass visual representation to show the strut buckling/deflection curve under load.

#### **2. Interactive Dashboard Components**
*   **Section Selector:** A "Glassmorphic" dropdown or slider to choose ISA sizes (75x75x10 to 100x100x10).
*   **Dynamic Inputs:** Sliders for Length ($L$) and Applied Load ($P$).
*   **Interactive Drag:** Allow the user to "drag" the bolt connection point at the ends to visualize eccentricity change.
*   **Real-time Graphing:** Use a Chart.js or D3 canvas overlay to plot "Load vs. Deflection" and "Compressive Strength vs. Slenderness Ratio" curves that update instantly as variables shift.

#### **3. Web Audio API Synthesis**
Do not use external files. Use the native `AudioContext`:
*   **Parameter Change:** Trigger a low-frequency oscillator "click" (short sine wave sweep) when a slider is moved.
*   **Error State:** If the strut exceeds the design capacity (Failure condition), trigger a low-frequency sawtooth pulse (Warning sound).
*   **Calculation Success:** A soft, harmonic 3-note arpeggio (triad) when the load is within safe limits.

#### **4. Text-to-Speech (TTS) Integration**
*   **Narrative Mode:** Include a "Read Guide" toggle.
*   **Implementation:** Use `window.speechSynthesis`.
*   **Trigger Logic:** Create an "Auto-Narrate" system that speaks the explanation of each variable (e.g., "Increasing the leg length increases the radius of gyration, thereby reducing the slenderness ratio") when a user hovers over specific control labels or changes a critical variable.

#### **5. Aesthetics & UI Guidelines**
*   **Theme:** Dark mode aesthetic with `#121212` background.
*   **Accents:** Neon cyan (`#00f2ff`) for active structural lines; neon amber (`#ffb400`) for warning zones.
*   **Glassmorphism:** Use `backdrop-filter: blur(15px); background: rgba(255, 255, 255, 0.05);` for all control panels.
*   **Typography:** Modern sans-serif (Inter or Roboto) with subtle glows via `text-shadow`.

#### **6. Programming Requirements**
*   **Structure:** Single-file HTML (embedded CSS in `<style>`, JS in `<script>`).
*   **Code Quality:** Use ES6 classes for the Strut object.
*   **Calculation Logic:** Integrate a logic block that computes:
    1.  Radius of gyration ($r_{vv}$).
    2.  Effective length ($KL$).
    3.  Slenderness ratio ($\lambda = KL/r$).
    4.  Design compressive strength ($P_d$) based on IS 800 standards for eccentrically loaded struts.
*   **Responsiveness:** Ensure all canvases resize fluidly within a flexible layout.
