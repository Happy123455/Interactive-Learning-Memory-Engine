### Prompt for Gemini: Educational Simulation Development

**Role:** You are an expert educational software engineer and frontend developer specializing in interactive physics simulations.

**Objective:** Create a high-fidelity, single-file HTML/JS/CSS simulation that explains the "Advantages of Modified Bituminous Binder" in Transportation Engineering. The goal is to visually demonstrate how polymer modification improves binder performance under stress.

**1. Visual Simulation Strategy:**
*   **Core Concept:** A split-screen 2D canvas simulation. 
    *   **Left side:** A "Load Application" zone showing a bitumen sample under a wheel load (represented by a weighted block).
    *   **Right side:** A dynamic real-time plot using Chart.js or a custom Canvas animation showing the "Stress-Strain" behavior or "Viscoelastic Recovery" curve.
*   **Mechanism:** Use a requestAnimationFrame loop to animate a "Stress" vector (an arrow pointing down) and a "Recovery" vector (showing how the binder returns to shape).
*   **Comparison:** Allow a toggle between "Plain Bitumen" (high deformation, slow recovery) and "Modified Binder" (elastic, high fatigue resistance).

**2. Interactive Elements:**
*   **Drag & Drop:** Implement a drag-and-drop mechanism where the user drags a "Temperature Slider" (changing the binder's state from rigid to fluid) and a "Modification Percentage Slider" (0% to 10%).
*   **Controls:** A glassmorphic side panel containing:
    *   "Apply Load" Button: Triggers a force pulse animation.
    *   "Reset" Button: Returns simulation to initial state.
    *   "Parameter Toggles": Switches between Rutting Resistance, Fatigue Life, and Temperature Susceptibility simulations.

**3. Sound Design (Web Audio API):**
*   **Constraints:** Use ONLY native `AudioContext` oscillators. No external MP3/WAV files.
*   **Events:** 
    *   "Load Application": A low-frequency thud (Oscillator: Sine, 60Hz, sharp gain envelope).
    *   "Modification Success": A rising frequency sweep (Oscillator: Triangle, 440Hz to 880Hz) when the user increases the polymer percentage.
    *   "Error/Limit Reached": A soft pulse (Oscillator: Square, 100Hz).

**4. Narrative Text-to-Speech:**
*   Integrate the Web Speech API (`window.speechSynthesis`).
*   Include a "Narrate" button. When clicked, it should read the active description of the advantage currently displayed on the dashboard.
*   Implement automatic narration triggers when a student modifies the "Polymer Percentage" slider (e.g., "Increasing polymer content enhances the elastic recovery of the binder, reducing rutting.").

**5. Diagram Animations & Math:**
*   Display real-time formulas on the canvas (e.g., `G* = |τ| / |γ|`). 
*   Use vector arrows: As the user drags the "Force" input, dynamically scale the force vector arrow on the binder sample.
*   Show a grid overlay on the binder sample that distorts under load; for modified binders, the grid should retain shape more effectively after the load is released.

**6. Aesthetics & UI/UX:**
*   **Theme:** Dark mode aesthetic. Background: `#0a0a0c`.
*   **Accents:** Glowing neon blue (for Plain) and neon magenta (for Modified) for paths and vectors.
*   **Components:** Glassmorphism for control boxes (background: `rgba(255, 255, 255, 0.05)`, backdrop-filter: `blur(10px)`).
*   **Typography:** Inter or Roboto, sans-serif, clean and legible.
*   **Transitions:** Smooth CSS transitions for all UI states and smooth easing for the force animations.

**7. Technical Requirements:**
*   Code must be contained in a single HTML file including `<style>` and `<script>` tags.
*   Use clean, commented, ES6+ JavaScript.
*   Ensure the simulation is responsive and adapts to window resizing.

**Task:** Write the complete code implementation now.
