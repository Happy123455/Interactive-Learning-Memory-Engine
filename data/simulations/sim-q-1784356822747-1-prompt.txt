**Role:** You are an expert Educational Software Engineer and Computational Designer. Your task is to build a high-fidelity, interactive browser-based simulation for a Structural Engineering tutorial on "Combined Flexure, Shear, and Torsion in RCC Beams."

**Objective:** Create a single-file HTML/CSS/JS application that enables students to visualize and solve the design of a rectangular RCC beam.

### 1. Visual Simulation Strategy
*   **Core View:** Use a 2D HTML5 `<canvas>` to render a high-quality cross-section and side-elevation view of an RCC beam. 
*   **Vector Overlays:** Render active force vectors (Moment $M_u$, Shear $V_u$, Torsion $T_u$) as dynamic, colored arrows emanating from the beam's center of gravity. As users adjust input values, the arrow lengths (via vector math) and colors must scale proportionally.
*   **Real-time Plotting:** Include a side-panel graph using a lightweight JS library (like Chart.js or D3) that plots the "Interaction Diagram" or "Required Area of Steel" vs. "Applied Forces."

### 2. Interactive Elements
*   **Input Controls:** Implement a "Glassmorphic" control panel on the right with range sliders for:
    *   `Beam Width (b)`: 150mm – 500mm
    *   `Effective Depth (d)`: 300mm – 1000mm
    *   `Bending Moment (Mu)`: 0 – 100 kNm
    *   `Shear Force (Vu)`: 0 – 50 kN
    *   `Torsion (Tu)`: 0 – 30 kNm
*   **Drag & Drop:** Allow users to drag "Load Markers" on the beam diagram to re-position the point of application, which triggers a recalculation of the Equivalent Shear and Bending Moment.
*   **Live Math:** Use KaTeX or MathJax to display the governing limit state equations (e.g., $M_e = M_u + T_u(1+D/b)/1.7$) that update their variables in real-time as the sliders move.

### 3. Sound Design (Web Audio API)
*   **Interaction Feedback:** Use a `Web Audio API` oscillator node to create a soft "click" sound (a short 20ms sine wave envelope) when sliders move.
*   **Warning Tones:** Use a low-frequency sawtooth oscillator (set to 150Hz) that triggers if the entered dimensions result in a "Section Failure" or "Inadequate Reinforcement."
*   **Success Sweep:** A high-frequency sine sweep (upward, 400Hz to 800Hz) when the design meets limit state criteria.

### 4. Narrative Text-to-Speech
*   **Feature:** Include a "Narrate" button next to every major step.
*   **Logic:** Use `window.speechSynthesis`. Create a function `speakStep(text)` that narrates the specific structural principle being applied (e.g., "The addition of torsion increases the equivalent shear stress on the concrete section"). 
*   **Automation:** Trigger a brief explanation when the user hovers over the "Result" output fields.

### 5. Aesthetics & UI/UX
*   **Theme:** Dark mode aesthetic with `#0f172a` background.
*   **Glassmorphism:** Use `backdrop-filter: blur(10px)` with semi-transparent white overlays for control panels (`rgba(255, 255, 255, 0.05)`).
*   **Typography:** Clean, sans-serif fonts (e.g., Inter or Roboto). 
*   **Accents:** Glowing neon borders (cyan for input, magenta for output, amber for warnings) using CSS `box-shadow` transitions.

### 6. Technical Requirements
*   **Structure:** Everything must be contained in a single `.html` file.
*   **Math Logic:** Implement the standard Limit State Design equations (IS 456:2000 or equivalent) to calculate the `Equivalent Bending Moment (Me)` and `Equivalent Shear (Ve)`.
*   **Responsive:** Ensure the canvas and side panels adjust gracefully to screen width.

### 7. Implementation Workflow for the Model:
1.  **Setup:** Define the CSS variables for the dark theme and glassmorphic components.
2.  **Engine:** Build a `requestAnimationFrame` loop to handle the drawing of the beam and force vectors on the Canvas.
3.  **Calculation Layer:** Create a JS object to store current state and compute structural requirements based on the input sliders.
4.  **Audio/Speech:** Initialize the `AudioContext` and `speechSynthesis` instance. Ensure audio starts only after the first user interaction.
5.  **Output:** Display the final calculated required reinforcement (Ast) in a large, glowing neon indicator box at the bottom of the dashboard.
