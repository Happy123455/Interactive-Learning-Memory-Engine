You are an expert educational software developer. Your task is to build a high-fidelity, interactive HTML/JS/CSS simulation for a college-level "Theory of Architecture" course, specifically focusing on **Principles of Architectural Composition**.

### Objective
Create a single-file, browser-based pedagogical simulation that allows students to explore and manipulate three core principles: **Contrast**, **Balance (Symmetry/Asymmetry)**, and **Rhythm**.

### 1. Visual & Technical Strategy
*   **Canvas Framework:** Use a full-screen HTML5 Canvas for the simulation workspace.
*   **Aesthetics:** Utilize a "Midnight Architect" theme—deep charcoal background (#121212), glassmorphic control panels (backdrop-blur: 10px), neon cyan/amber accents, and clean Inter/sans-serif typography.
*   **Real-time Math:** Use requestAnimationFrame loops to calculate and render the geometric relationships.
*   **Responsiveness:** Elements should be draggable using pointer events; vector overlays should visually represent the "axis of balance" or "rhythmic intervals."

### 2. Interactive Modules
Create a UI with three tab-swappable modes:
*   **Contrast Module:** Allow the user to drag and resize geometric shapes. Display an "Contrast Ratio" dynamic readout based on the difference in surface area (Mass) and color tone (HSL values).
*   **Balance Module:** Provide an axis of reference. Users drag mass objects (rectangles/circles) onto a grid. Show a real-time "Center of Mass" vector arrow that updates as objects are moved to demonstrate the difference between *Symmetrical*, *Nearly Symmetrical*, and *Asymmetrical* states.
*   **Rhythm Module:** Implement a slider-controlled generator that places a series of columns/forms. Users can adjust the interval (spacing) and growth rate (sequencing). Draw vector lines indicating the rhythm interval.

### 3. Audio & Narrative (Web Audio API & Synthesis)
*   **Web Audio Synth:** Use the Web Audio API to generate procedural sound feedback. Create a "thud" or "tap" sound using a `GainNode` and `OscillatorNode` (low-frequency square wave) when objects are dropped or aligned.
*   **Narrative TTS:** Implement a global "Narrator" button. When clicked, use `window.speechSynthesis` to read a concise, pre-defined explanation of the active principle. 
    *   *Example:* "You are observing Symmetrical Balance. Notice how the center of mass vector remains zero when elements are perfectly mirrored."

### 4. Code Architecture Requirements
*   **State Management:** Maintain a central `state` object that holds current UI values (e.g., `activePrinciple`, `shapes[]`, `isNarrating`).
*   **Input Handling:** Implement `PointerDown`, `PointerMove`, and `PointerUp` for smooth dragging of architectural elements. 
*   **Visual Overlays:** 
    *   Draw the "Axis of Reference" as a pulsing dashed neon line in the Balance module.
    *   Display live equations on screen (e.g., $Area = L \times W$ or $Balance = \sum(mass \times distance)$).
*   **Animation:** Use easing functions (e.g., `cubic-bezier` equivalents in JS) for transitions between UI states and moving elements.

### 5. Detailed Steps for Implementation
1.  **Structure:** Build a `<header>` for navigation (tabs), a `<main>` section for the canvas, and a `<aside>` glass-panel for interactive parameters/sliders.
2.  **Logic:**
    *   For **Balance**, calculate the moment of force: $\tau = d \cdot F$. Show an equilibrium bar that tilts based on the current configuration.
    *   For **Rhythm**, create an array of objects rendered based on an arithmetic sequence: $pos_n = initial + (n \times interval)$.
    *   For **Contrast**, use `context.globalCompositeOperation` or simple HSL manipulation to emphasize the difference between light and shadow.
3.  **UI Feedback:** Ensure the UI shows tooltips on hover and highlights draggable elements with a subtle neon glow.
4.  **Speech:** Bind `speechSynthesis.speak(new SpeechSynthesisUtterance(...))` to the "Explain" button, ensuring the script is loaded only after a user gesture.

### 6. Deliverable Constraints
*   **No External Dependencies:** Write all code in vanilla HTML5, CSS3, and JavaScript. 
*   **Self-Contained:** All logic, styling, and base-64 assets (if any) must be in one file.
*   **Code Quality:** Use ES6 classes for the `Shape` objects and `Simulation` engine. Include detailed code comments for pedagogical clarity.
