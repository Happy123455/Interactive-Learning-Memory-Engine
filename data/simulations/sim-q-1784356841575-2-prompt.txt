You are an expert educational software developer. Your task is to build a high-fidelity, interactive "Pan Evaporation Simulation" dashboard for a college-level Engineering Hydrology course.

### 1. Visual Simulation Strategy
*   **Core Engine**: Use a high-performance HTML5 Canvas for the simulation and CSS/Tailwind for the UI.
*   **The Scene**: Render a 2D side-view cross-section of a Pan (IS Standard/Class A/Colorado).
*   **Visual Elements**: 
    *   **Water Level**: Represent water as a blue, semi-transparent liquid body with a wave-displacement shader animation.
    *   **Evaporation Particles**: Emit upward-moving, fading semi-transparent particles from the water surface. Adjust emission rate based on user-defined environmental factors.
    *   **Environment**: Render icons or gauges for Sun (radiation), Wind (vector arrow speed), and Humidity (background glow intensity).

### 2. Interactive Controls & UI
*   **Dashboard**: A glassmorphic, dark-themed sidebar.
*   **Inputs**: Use responsive sliders for:
    *   `Temperature (10°C - 50°C)`
    *   `Wind Speed (0 - 20 km/h)`
    *   `Humidity (0% - 100%)`
    *   `Surface Area/Pan Type` (Dropdown with selection: Class A, IS, Colorado)
*   **Drag & Drop**: Allow the user to drag a "thermometer" or "anemometer" tool onto the scene to view local readings.
*   **Real-time Math**: Display a dynamic, LaTeX-formatted readout: `E = Cp × Ep`, where `E` updates instantly as the user manipulates environmental variables.

### 3. Real-time Graphing
*   Implement a `Chart.js` or `Canvas-based` live line graph that plots `Evaporation Rate (mm/day)` on the Y-axis vs. `Time (hours)` on the X-axis. 
*   Ensure the graph line changes color/thickness based on the current Pan Coefficient (Cp) of the selected pan type.

### 4. Audio Engine (Web Audio API)
*   **Do NOT use external files.** Use `AudioContext` and `OscillatorNode`.
*   **Events**:
    *   **Ambient Wind**: Create a soft, low-frequency white noise generator with a `BiquadFilterNode` that increases in volume/cutoff as Wind Speed increases.
    *   **Interaction Beeps**: A high-frequency, short-decay sine wave (10ms) triggered on slider movement.
    *   **Success Tone**: A harmonic sweep (rising pitch) triggered when the user correctly observes a standard evaporation cycle.

### 5. Educational Narration (Web Speech API)
*   Include a "Narrate Concept" button. Use `window.speechSynthesis` to trigger a sequential audio guide:
    *   *Step 1*: Define Pan Evaporation as a physical process of liquid to gas transition.
    *   *Step 2*: Explain the relationship between the chosen pan coefficient (Cp) and the reservoir.
    *   *Step 3*: Walk the user through how their specific input changes affect the evaporation rate particle speed.

### 6. Technical & Aesthetic Specifications
*   **Aesthetics**: Use a deep charcoal background (#121212) with neon cyan (#00f2ff) and amber (#ffcc00) accents. 
*   **Typography**: Clean, sans-serif font (Inter or Roboto).
*   **Animations**: All transitions must be `cubic-bezier(0.4, 0, 0.2, 1)` for a premium, fluid feel.
*   **Code Structure**: Keep logic in a single file or clearly modularized script tags.
*   **Responsiveness**: Ensure the Canvas and UI stack vertically on mobile but side-by-side on desktop.

### 7. Simulation Logic Requirements
*   Implement the Pan Coefficient (Cp) logic:
    *   Class A: 0.70
    *   IS Standard: 0.80
    *   Colorado Sunken: 0.78
*   The water level in the pan must visually decrease over a time-loop simulation, with the rate determined by the `Evaporation = f(Temp, Wind, Humidity)` logic provided in the reference notes.
