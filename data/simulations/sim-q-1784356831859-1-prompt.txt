You are an expert educational software developer. Your task is to build a high-fidelity, interactive HTML5/JavaScript simulation environment that teaches "One-Way and Two-Way Shear in Footing Design" using a gamified, studio-based pedagogy.

### **TECHNICAL REQUIREMENTS**
- **Environment**: Single-file solution (HTML/CSS/JS). Use Tailwind CSS for layout.
- **Canvas Engine**: Use native HTML5 Canvas for all structural diagrams and animation sequences.
- **Audio/Speech**: Use `window.speechSynthesis` for pedagogical narration and the Web Audio API for UI interaction sounds (sine wave beeps for success, low-frequency hums for errors/warnings).
- **Aesthetics**: Dark mode studio theme (Slate-900 background, neon accents: Cyan for UI, Crimson for active force vectors, Emerald for successes).

### **BUILD STEPS**

#### **1. Layout & Architecture**
- **Studio Interface**: Create a 3-panel dashboard.
  - **Left (Data Panel)**: Problem text with "Click-to-Identify" interactivity.
  - **Center (Simulation Stage)**: The core Canvas workspace.
  - **Right (Control & Logic)**: A dynamic "Formula Assembly" workbench with slots for variables and codebook references.

#### **2. Pedagogical Interaction Loop**
- **Phase 1: Data Extraction**: Display the footing problem text. As the user clicks variables (e.g., $B$, $D$, $P_u$, $f_{ck}$), animate the canvas drawing a 3D isometric foundation footing. Use growth animations for the footing dimensions, drawing the column stump, the footing slab, and the critical sections (distance $d$ from the column face for one-way, $d/2$ for two-way).
- **Phase 2: Codebook Challenge**: Include a virtual "IS 456:2000" icon. When clicked, it opens a sidebar showing the relevant clauses for shear check. The user must drag the correct clause card into the "Equation Validator" slot.
- **Phase 3: Drag-and-Drop Formula Assembly**: Provide interactive chips containing mathematical variables ($V_u$, $\tau_c$, $k$, $d$). The user must drag these into the correct position in the shear equations ($ \tau_v = V_u / (b \cdot d) $).
  - Use snap-to-target logic with green glow on success and a "shake" effect on error.
- **Phase 4: Focus Zoom & Animation**:
  - **One-Way Shear**: Upon validation, trigger a 150% camera zoom onto the section plane at distance $d$. Animate a red "shear failure plane" line sliding through the footing.
  - **Two-Way Shear (Punching)**: Animate the critical perimeter at $d/2$ around the column. Pulse this perimeter in neon crimson. Show a "punching cone" visualization to illustrate the failure mode.

#### **3. Visual Simulation & Physics**
- **Force Vectors**: Draw active vertical downward force (Column load) and upward reaction force (Soil pressure) as translucent vectors that update in real-time as the user changes footing thickness.
- **State Verification**: Create a "Capacity vs. Demand" stacked bar chart. As the user adjusts footing depth ($D$), the capacity bar must grow in real-time. If the demand exceeds capacity, the footing element in the canvas should trigger a "warning pulse" sound and red border.

#### **4. Voice and Sound Strategy**
- **Narration**: Use `speechSynthesis` to provide brief, punchy explanations (e.g., "One-way shear check ensures the slab doesn't fail as a wide beam.") when a student hovers over or completes a section.
- **Audio Feedback**: 
  - **Drop Success**: High-pitched harmonic chime. 
  - **Constraint Check**: Deep mechanical "clunk" sound.
  - **Warning**: Low-frequency oscillating pulse.

#### **5. Technical Polish**
- Ensure all SVG/Canvas drawing utilizes `requestAnimationFrame` for fluid movement.
- Use CSS transitions for the panel layouts.
- Implement an "Exploded View" toggle that separates the footing and the column to show internal reinforcement callouts clearly.

### **DESIGN CONSTRAINTS**
- **NO STATIC TEXTBOXES**: The problem text and equations must be part of the interactive experience (clickable/draggable).
- **NO OVERLAYS**: Use intelligent dynamic leader-line placement to prevent text collision.
- **UI GUIDELINES**: Use a frosted glass effect (`backdrop-filter: blur(10px)`) for all panels. Keep the center stage uncluttered, focusing purely on the structural diagram.
