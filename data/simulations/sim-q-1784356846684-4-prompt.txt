**Phase 3: Method-Specific Calculation & Visualization**

***CRITICAL NOTE: As the problem is about Hydrology, the RCC Beam Design & Structural Engineering Style Guide (Point 8 in the prompt) is NOT applicable here. Do NOT generate any code or instructions related to beam design, concrete, rebar, stress-strain, IS 456, or camera zooms for this specific simulation.***

**A. Arithmetic Mean Method (ELI5: "Simple Average Fun!")**

1.  **Narrate:** `narrate("This is the simplest way! We just add up all the sprinkles from all our buckets and share them equally! Ready? Watch closely!")`
2.  **Calculation:**
    *   Sum all `rainfall` values from `gaugesData`.
    *   Divide by the number of gauges.
    *   `P_avg = (P1 + P2 + ... + Pn) / n`.
3.  **Visual Animation:**
    *   On canvas: Temporarily show each gauge's rainfall value visually "flowing" into a central, glowing "summation" circle.
    *   The "summation" circle then visually "divides" its contents, and the entire catchment area changes to a uniform shade of blue, representing the average rainfall, with the value floating in the center.
    *   **Real-time Updating Graph (Results Panel):** Display a simple bar chart: individual gauge rainfall values (small bars) vs. the average rainfall (a single, larger bar).
4.  **Narrate Result:** `narrate("Wow! Our average rainfall using the Arithmetic Mean method is <P_avg> millimeters! See how all the sprinkles spread out evenly?")`

**B. Thiessen Polygon Method (ELI5: "Fair Share Zones!")**

1.  **Narrate:** `narrate("This method is like giving each sprinkle catcher its own special 'fair share' zone on our cookie! Some buckets have bigger zones!")`
2.  **User Interaction (Optional, for advanced control):** Allow users to slightly drag rain gauge positions. As gauges move, the Thiessen polygons update dynamically.
3.  **Calculation & Visualization:**
    *   **Dynamic Polygon Generation:** On canvas, use Delaunay triangulation and Voronoi diagram (Thiessen polygons) to divide the catchment area. Each gauge should be the center of its polygon.
    *   **Animation:** Slowly "grow" the Thiessen polygon boundaries outwards from the gauges with a neon purple glow.
    *   Calculate the area of each polygon within the catchment (`A_i`).
    *   Calculate `P_avg = Σ (P_i * A_i) / Σ A_i`.
    *   On canvas: Each polygon segment takes on a shade of blue corresponding to its gauge's rainfall, with the polygon border highlighting.
4.  **Narrate Result:** `narrate("Look! Each bucket has its own special zone! The average rainfall, considering these zones, is <P_avg> millimeters! Pretty cool, huh?")`
5.  **Real-time Updating Graph (Results Panel):** Display a pie chart showing the percentage contribution of each gauge's rainfall *multiplied by its area* to the total, or a bar chart of `P_i * A_i`.

**C. Isohyetal Method (ELI5: "Rainfall Contour Lines!")**

1.  **Narrate:** `narrate("This is like drawing lines on our cookie to show where the rain was heavy and where it was light, just like hills and valleys!")`
2.  **User Interaction (Gamified Drawing):**
    *   **Hand Motion Gesture Control:** `narrate("Now, use your mouse like a magic crayon! Sweep your hand over the canvas to draw lines where you think the rainfall amounts are the same!")`
    *   Allow users to `mousemove` while holding down the mouse button to "draw" approximate isohyetal lines. The line drawing should be bouncy and have a trailing particle effect.
    *   **Assisted Isohyet Placement:** Alternatively, provide draggable "Isohyet Value" markers (e.g., a "15 mm Isohyet" marker) which, when dragged to a point on the canvas, draw a smooth contour line passing through nearby gauges with similar rainfall values, or create an interpolated line. The user must place at least 3-4 isohyets.
    *   **Visual Feedback:** Isohyetal lines should be drawn on the canvas, perhaps with varying shades of blue/green to indicate different rainfall intensities, glowing neon green.
3.  **Calculation & Visualization:**
    *   **Area Calculation:** For each "band" between two isohyets (or between an isohyet and the catchment boundary), calculate its area (`a_i`).
    *   The average rainfall for that band is the average of the two bounding isohyet values (`(P_i + P_i+1) / 2`).
    *   `P_avg = Σ (a_i * (P_i + P_i+1) / 2) / Σ a_i`.
    *   On canvas: Fill the areas between isohyets with color gradients corresponding to the rainfall range, creating a smooth visual transition.
4.  **Narrate Result:** `narrate("Wow, you drew those rainfall lines beautifully! Our average rainfall using the Isohyetal method is <P_avg> millimeters! You're a rainfall artist!")`
5.  **Real-time Updating Graph (Results Panel):** A gradient bar showing the range of rainfall values across the catchment, or a stacked bar showing the contribution of each isohyetal band's area-weighted rainfall.

**Phase 4: Final Results & Exploration**

1.  **Overall Result Presentation:**
    *   `narrate("You did it! You've figured out the average rainfall!")`
    *   Display the final calculated `P_avg` prominently in the `results-display-panel`.
    *   Play `cheer_sound()`.
2.  **Comparison (Optional):** If multiple methods were tried, display a simple bar chart comparing the `P_avg` from each method.
3.  **Reset/Explore:** A prominent "Try Again!" button with a bouncy animation allows the user to clear all data and restart the simulation, `narrate("Want to try another rainfall riddle? Click here to play again!")`

    const rainfallValueCardsContainer = document.getElementById('rainfall-value-cards-container');

    // --- Global State ---
    let gauges = []; // [{ id: 'G1', x: 100, y: 150, rainfall: null, area: null }]
    let rainfallValues = [10, 12, 15, 18, 20, 22, 25, 28, 30]; // Available rainfall values for cards
    let currentMethod = null;
    let audioContext;
    let oscillator, gainNode;

    // --- Canvas Setup & Responsiveness ---
    const resizeCanvas = () => {
        const dpr = window.devicePixelRatio || 1;
        canvas.width = canvas.offsetWidth * dpr;
        canvas.height = canvas.offsetHeight * dpr;
        ctx.scale(dpr, dpr);
        drawCatchment(); // Redraw everything on resize

    };
    window.addEventListener('resize', resizeCanvas);
    resizeCanvas(); // Initial resize

    // --- Audio Synthesis ---
    const initAudio = () => {
        audioContext = new (window.AudioContext || window.webkitAudioContext)();
        oscillator = audioContext.createOscillator();
        gainNode = audioContext.createGain();

        oscillator.type = 'sine'; // Or 'square', 'sawtooth', 'triangle'
        oscillator.connect(gainNode);
        gainNode.connect(audioContext.destination);
        oscillator.start();
        gainNode.gain.value = 0; // Start muted
    };
    initAudio();

    const playSound = (frequency, duration, volume = 0.5) => {
        if (!audioContext) return;
        oscillator.frequency.setValueAtTime(frequency, audioContext.currentTime);
        gainNode.gain.setValueAtTime(volume, audioContext.currentTime);
        gainNode.gain.exponentialRampToValueAtTime(0.00001, audioContext.currentTime + duration);
    };

    const click_sound = () => playSound(880, 0.1); // A4
    const drop_success_chime = () => {
        playSound(980, 0.08, 0.6); // B5
        setTimeout(() => playSound(1100, 0.1, 0.6), 100); // C#6
    };
    const warning_buzz = () => playSound(220, 0.3, 0.7); // A3
    const cheer_sound = () => {
        // More complex synth sequence for cheering
        playSound(1046.5, 0.1, 0.7); // C6
        setTimeout(() => playSound(1318.5, 0.1, 0.7), 100); // E6
        setTimeout(() => playSound(1568, 0.2, 0.7), 200); // G6
    };

    const updatePitchWithRainfall = (avgRain) => {
        if (!audioContext || !oscillator) return;
        // Map average rainfall (e.g., 0-50mm) to frequency range (e.g., 200-1000Hz)
        const minRain = 0;
        const maxRain = 50;
        const minFreq = 200;
        const maxFreq = 1000;
