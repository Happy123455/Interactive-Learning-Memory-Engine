Act as an expert Educational Software Developer and Frontend Engineer. Create a highly interactive, web-based simulation for a college-level "RCC T-Beam Ultimate Moment of Resistance" analysis. Use HTML5, CSS3 (with Tailwind-like utility styling), and Vanilla JavaScript.

### 1. Visual Simulation Strategy
*   **Core Architecture**: Use a `<canvas>` element for a cross-sectional view of the T-beam. The beam must render in 2D with a cross-hatch pattern for concrete and distinct circles for the 4-25mm reinforcing bars.
*   **Overlay Layer**: A secondary transparent overlay canvas should draw the Stress-Block diagram (rectangular-parabolic stress distribution) directly over the beam cross-section.
*   **Physics Loop**: Use a `requestAnimationFrame` loop to handle smooth transitions when parameters are changed.

### 2. Interactive Elements
*   **Dynamic Inputs**: Include range sliders for `Effective Depth (d)` and `Width of Web (bw)`.
*   **Drag-and-Drop**: Allow the user to "drag" the effective depth indicator line on the diagram; as the line moves vertically, the `d` value in the calculation logic must update in real-time.
*   **Calculation Hub**: A glassmorphic side panel displaying the formula for $M_u$. As values change, show the equation values updating with a "scrolling numbers" animation effect.
*   **Control Panel**: Add a "Lock/Unlock" toggle to fix the neutral axis calculation, allowing students to explore hypothetical scenarios.

### 3. Web Audio API (Native Synth)
*   **Interaction Feedback**: Implement a function using `AudioContext` with an `OscillatorNode` (type: 'sine' or 'triangle') to generate a short 50ms pitch-shifted "click" sound when sliders are moved.
*   **Data Validation**: Trigger a low-frequency, soft "thud" if the user inputs an impossible geometric value (e.g., $b_w >$ flange width).
*   **Sweep Effect**: Generate a rising sine-wave sweep when the "Calculate" button is pressed, signaling the processing of the Moment of Resistance.

### 4. Narrative Text-to-Speech (TTS)
*   **Integration**: Use `window.speechSynthesis`.
*   **Triggers**: Add a "Narrate Step" button that reads the current calculation step (e.g., "Step 1: Calculating the compressive force in the flange...") and an "Explain Concept" toggle that automatically narrates the structural theory when the mouse hovers over the Stress-Block diagram.

### 5. Diagram Animations & Math Rendering
*   **Real-time Plotting**: Use a coordinate grid on the side to plot the Stress distribution curve. As the Neutral Axis ($x_u$) shifts, animate the parabola and rectangle boundaries on the plot using a smooth CSS transition or canvas interpolation.
*   **Math Formatting**: Use `MathJax` or `KaTeX` (via CDN) to render the equations beautifully. Ensure that as the user changes variables, the variables within the formulas pulse with a glowing neon highlight.

### 6. Aesthetics & UI/UX
*   **Dark Theme**: Use a deep charcoal background (`#0f172a`) with a subtle grid-dot pattern.
*   **Glassmorphism**: Apply `backdrop-filter: blur(10px)` with a semi-transparent border-light (1px white/neon-blue) for all control panels.
*   **Typography**: Use 'Inter' or 'Roboto' for a clean, professional, academic feel.
*   **Accents**: Use electric cyan (`#06b6d4`) for UI active states and hot pink (`#f472b6`) for the reinforcing bars and vector arrows.
*   **Transitions**: Ensure all UI changes involve 300ms ease-in-out transitions to provide a premium, non-jittery experience.

### Technical Requirement
*   The entire project must be contained in a single HTML file (with embedded CSS and JS).
*   Include error handling for the calculation logic to ensure the `Ultimate Moment of Resistance` remains physically consistent with the `Effective Depth` and `Web Width`.
*   Structure the code modularly: `CanvasRenderer`, `AudioEngine`, `MathEngine`, and `Narrator`.
